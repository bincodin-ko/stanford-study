# 26. 지식·디지털 상품·외주 서비스 팔기

재고도 서버 개발도 거의 필요 없이, **내가 아는 것과 할 줄 아는 것**을 파는 사업들이에요.

---

## 1. 세 가지 형태

| 형태 | 예 | 한 번 만들면? | 규모 키우기 |
|---|---|---|---|
| **디지털 상품** | 노션·엑셀 템플릿, 전자책, PPT 템플릿, 폰트, 사진, 일러스트 | **계속 팔림** | 쉬움 |
| **온라인 강의·코칭** | VOD 강의, 라이브 클래스, 1:1 코칭, 유료 스터디 | VOD는 계속 팔림, 코칭은 매번 내 시간 | 중간 |
| **외주·에이전시** | 웹사이트 제작, 디자인, 영상 편집, 마케팅 대행, 번역 | **매번 새로 일해야 함** | 어려움 (사람을 늘려야 함) |

> 💡 흔한 발전 경로: **외주로 일하며 노하우를 쌓음 → 그 노하우를 강의·템플릿으로 만들어 팜** (내 시간과 수익을 분리)

---

## 2. 디지털 상품

### 어디서 파나
| 채널 | 특징 |
|---|---|
| 재능·지식 마켓 (크몽, 탈잉 등) | 손님이 있음, 수수료 |
| 전자책·템플릿 판매 플랫폼 | 다운로드 판매 기능 제공 |
| 내 사이트 + 결제 | 수수료 낮음, 손님을 직접 모아야 함 |

### 운영 포인트
| 항목 | 내용 |
|---|---|
| **환불 규정** | 디지털 상품은 다운로드 후 반품이 어려워요. 전자상거래법상 청약철회 예외로 하려면 **미리 알리고, 맛보기(미리보기)를 제공하는 등** 조건이 필요 → 상품 페이지에 명확히 |
| **불법 복제** | 워터마크, 구매자별 링크, 다운로드 횟수 제한 |
| **업데이트** | 템플릿 버전 관리(v1.2), 구매자에게 업데이트 무료 제공하면 신뢰 ↑ (7장 버전 번호) |
| **라이선스** | "개인용 / 상업용" 사용 범위 명시 |
| **저작권** | 남의 폰트·이미지를 넣어 팔면 침해 → 상업용 허락된 소스만 |

## 3. 온라인 강의·코칭

### 만드는 순서 (4장 기획과 같음)
```
① 누가 무엇을 못 해서 답답한가 → ② 무료 콘텐츠로 반응 보기(블로그·유튜브)
→ ③ 사전 신청(얼리버드)으로 수요 확인 → ④ 촬영 → ⑤ 출시 → ⑥ 수강 후기로 개선
```
- ③ **"만들기 전에 먼저 팔아 보기"**: 강의 소개 페이지 + 사전 신청을 받아 보고, 충분히 모이면 제작. (23장 크라우드펀딩과 같은 원리)

### 운영 지표
| 지표 | 뜻 |
|---|---|
| **완강률** | 끝까지 들은 비율. 낮으면 후기·재구매 ↓ |
| 후기 평점 | 다음 판매를 좌우 |
| 환불률 | 기대와 내용이 다른지 |

### 주의
- **오프라인 학원처럼 운영**하거나 특정 형태의 교습을 하면 학원법 등 교육 관련 규제가 적용될 수 있어요(29장). 성인 대상 온라인 VOD와는 다를 수 있으니 형태가 애매하면 관할 교육청에 확인.
- "수익 보장", "100% 합격" 같은 표현은 **허위·과장 광고** 위험.

## 4. 외주·에이전시 운영

웹사이트 제작 외주를 예로 들면, 이 자료의 1~10장 지식이 그대로 **상품**이 돼요.

### 일 진행 순서
```
상담 → 견적 → 계약 → 착수금 → 기획(4장) → 디자인 → 개발 → 검수 → 잔금 → 인수인계 → 유지보수
```

### 분쟁을 막는 4가지
| 항목 | 내용 |
|---|---|
| **계약서** | 작업 범위, 일정, 금액, **수정 횟수**(예: 디자인 수정 2회까지), 저작권 귀속 |
| **착수금·중도금·잔금** | 보통 나눠 받음. 잔금 미지급 분쟁이 흔함 |
| **범위 밖 요청** | "이것도 해 주세요"는 **추가 견적**으로 (스코프 크립 막기) |
| **인수인계** | 도메인·호스팅·관리자 계정을 **고객 명의**로 넘기기 (5장: 도메인은 주인 명의로) + 운영 매뉴얼 |

### 유지보수 계약 = 반복 수익
- 제작 후 **월 유지보수비**(보안 업데이트, 백업 확인, 간단 수정)를 받으면 매달 들어오는 수입이 생겨요.
- 이때 하는 일이 바로 **8장 백업, 9장 모니터링, 14장 점검표**입니다.

### 프리랜서 세금
- 외주 대금에서 **3.3% 원천징수**를 떼고 받는 경우가 많아요(사업소득). 5월 종합소득세 신고 때 정산.
- 사업자등록을 하면 세금계산서를 발행할 수 있어 B2B 거래가 편해져요.

---

### 이 장 요약
1. **디지털 상품**은 한 번 만들어 계속 팔고, **외주**는 매번 내 시간을 판다.
2. 강의·상품은 **만들기 전에 사전 신청으로 수요부터** 확인.
3. 외주는 **계약서(범위·수정 횟수·저작권)와 인수인계**가 분쟁을 막는다. 유지보수 계약은 반복 수익.
