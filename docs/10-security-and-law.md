# 10. 보안과 법

> ⚠️ **법·세금 내용은 2026년 10월 기준으로 조사했고, 바뀔 수 있습니다.**
> 실제로 시작할 때는 아래 공식 사이트에서 꼭 다시 확인하세요.
> - 사업자등록·세금: **국세청 홈택스**
> - 통신판매업 신고: **정부24** 또는 관할 시·군·구청
> - 개인정보: **개인정보보호위원회**, **개인정보 포털(privacy.go.kr)**
> - 법 원문: **국가법령정보센터(law.go.kr)**
> - 전자상거래 규칙: **공정거래위원회**

## 1부. 보안 — 작은 사이트도 공격당합니다

해커는 "큰 회사"만 노리지 않아요. 자동 프로그램이 인터넷의 **모든 사이트**를 돌아다니며 약한 곳을 찾습니다.

### 꼭 해야 할 보안 10가지

| # | 할 일 | 왜 |
|---|---|---|
| 1 | 관리자 계정에 **2단계 인증(2FA)** | 비밀번호가 털려도 로그인 불가 |
| 2 | **비밀번호 관리자** 사용, 서비스마다 다른 비밀번호 | 하나가 털려도 줄줄이 털리지 않게 |
| 3 | 플러그인·테마·서버 프로그램 **최신 업데이트** | 알려진 구멍을 막음 |
| 4 | 직원에게 **필요한 권한만** (최소 권한) | 실수·내부 유출 피해를 줄임 |
| 5 | 퇴사자 계정 **바로 삭제** | 의외로 사고가 많은 곳 |
| 6 | **HTTPS** 사용 | 오가는 정보 암호화 |
| 7 | **카드 번호를 직접 저장하지 않기** → PG사(결제 대행사)에 맡기기 | 저장하지 않은 정보는 유출될 수도 없음 |
| 8 | 회원 비밀번호는 **복원 불가능하게 암호화(해시)** 저장 | DB가 털려도 비밀번호는 안전 |
| 9 | **백업을 다른 곳에** (8장 3-2-1) | 랜섬웨어 대비 |
| 10 | 로그인 기록·관리자 작업 **로그 남기기** | 사고 때 무슨 일이 있었는지 추적 |

### 자주 당하는 공격, 쉬운 설명

| 공격 | 쉬운 설명 | 막는 법 |
|---|---|---|
| **피싱** | "결제 오류, 여기서 로그인하세요" 가짜 메일 | 링크 말고 직접 주소 입력, 2FA |
| **무차별 대입** | 비밀번호를 수만 번 자동으로 넣어 봄 | 로그인 실패 횟수 제한, 2FA |
| **SQL 인젝션** | 입력창에 이상한 명령을 넣어 DB를 훔침 | 검증된 프레임워크·빌더 사용, 업데이트 |
| **XSS** | 게시판 글에 몰래 악성 코드를 심음 | 입력값 필터링(대부분 빌더가 처리) |
| **DDoS** | 가짜 접속을 한꺼번에 퍼부어 사이트를 멈춤 | CDN·보안 서비스(예: Cloudflare) |
| **랜섬웨어** | 서버 파일을 잠그고 돈 요구 | 오프사이트·변경 불가 백업 |

## 2부. 한국에서 온라인 사업을 할 때의 기본 절차

### 순서 한눈에 (온라인 쇼핑몰 기준)

```
① 사업자등록 (홈택스/세무서)
   ↓
② 사업자 통장·카드 만들기
   ↓
③ PG(결제 대행사) 계약 + 구매안전서비스(에스크로) 가입
   ↓
④ 통신판매업 신고 (정부24/구청)
   ↓
⑤ 사이트에 사업자 정보·약관·개인정보처리방침 게시
   ↓
⑥ 영업 시작 → 부가세·종합소득세 신고
```

### ① 사업자등록
- 국세청 **홈택스**에서 온라인 신청 가능. 법에서는 사업을 시작한 날부터 **20일 이내** 신청하도록 정하고 있어요.
- **간이과세자 / 일반과세자** 중 선택. 간이과세는 연 매출이 일정 기준(2024년 7월부터 약 1억 400만 원) 미만인 개인사업자가 고를 수 있고, 부가세 부담이 낮은 대신 세금계산서 발행 등에 제약이 있습니다. **업종에 따라 간이과세가 안 되는 경우도 있으니** 홈택스에서 확인하세요.
- **업종**: 온라인 판매는 보통 "전자상거래 소매업".

### ③ PG 계약 + 구매안전서비스
- **PG(결제 대행사)**: 토스페이먼츠, KG이니시스, NHN KCP 등. 빌더를 쓰면 빌더 안에서 신청하는 경우가 많아요.
- **구매안전서비스(에스크로)**: 손님 돈을 잠시 맡아 두었다가 배송 후 판매자에게 주는 장치. 통신판매업 신고할 때 **"구매안전서비스 이용 확인증"** 을 내야 하는 경우가 많아 먼저 준비합니다.

### ④ 통신판매업 신고
- 근거: **전자상거래법 제12조**. 온라인으로 물건·서비스를 파는 사업자는 원칙적으로 신고해야 합니다.
- **정부24**에서 온라인 신청하거나 관할 시·군·구청에 신청. 등록면허세(지역·규모에 따라 다름)가 나옵니다.
- **면제 기준**: 공정거래위원회 고시에 "직전 연도 거래 횟수 50회 미만" 또는 "간이과세자"면 신고를 안 해도 된다는 기준이 있는 것으로 조사됐습니다. 다만 **예전에 기준이 여러 번 바뀌었고 자료끼리 서로 다른 내용도 있어서**, 원문을 직접 확인하지는 못했습니다. → **신고 전 정부24나 구청에 꼭 확인**하세요. 그리고 신고가 면제돼도 **소비자 보호 의무(청약철회 등)는 그대로** 적용돼요.

### ⑤ 사이트에 꼭 보여 줘야 할 것
사이트 맨 아래(푸터)에 보통 이렇게 표시합니다.

```
상호: 마이쇼핑 | 대표자: 홍길동 | 사업자등록번호: 123-45-67890
통신판매업신고: 제2026-서울○○-0000호 | 주소: 서울시 ...
전화: 02-000-0000 | 이메일: help@myshop.com
[이용약관] [개인정보처리방침]
```

## 3부. 개인정보 — 가장 조심해야 할 법

**개인정보보호법**의 핵심은 5가지예요.

| 원칙 | 쉬운 뜻 | 실제로 할 일 |
|---|---|---|
| **최소 수집** | 필요한 것만 받기 | 쇼핑몰에 주민등록번호 받지 않기(원칙적으로 금지) |
| **동의** | 받기 전에 묻기 | 필수/선택 항목을 나눠 동의받기. **마케팅 수신 동의는 따로** |
| **공개** | 어떻게 쓰는지 알리기 | **개인정보처리방침**을 사이트에 항상 게시 |
| **안전 보관** | 털리지 않게 | 암호화, 접근 권한 제한, 접속 기록 보관 |
| **파기** | 다 쓰면 지우기 | 탈퇴·보관 기간이 끝나면 삭제 |

### 개인정보처리방침에 들어가는 내용 (대표 항목)
- 무엇을 수집하는지, 왜 쓰는지, 얼마나 보관하는지
- 다른 회사에 주는지(제3자 제공), 맡기는지(위탁: 택배사, PG사, 문자 발송 업체 등)
- 손님이 열람·삭제를 요청하는 방법
- 개인정보 보호책임자 연락처
- 안전하게 지키기 위해 하는 일

> 💡 개인정보 포털 등에서 **처리방침 작성 도구/예시**를 제공합니다. 처음부터 혼자 쓰지 말고 이를 바탕으로 내 사업에 맞게 고치세요.

### 유출 사고가 나면
- 손님(정보주체)에게 **알리고**, 일정 규모 이상이면 **개인정보보호위원회 또는 한국인터넷진흥원(KISA)에 신고**해야 합니다. 법에 기한이 정해져 있으니(조사 시점 기준 "알게 된 때부터 72시간 이내"), 사고 즉시 공식 안내를 확인하세요.
- 그래서 [9장](09-operations.md)의 장애 등급에서 "개인정보 유출 의심"은 **1급**입니다.

## 4부. 전자상거래 소비자 보호 — 자주 부딪히는 규칙

| 규칙 | 내용 (요약) |
|---|---|
| **청약철회(반품)** | 원칙적으로 상품을 받은 날부터 **7일 이내** 소비자가 취소·반품 가능. 예외(사용해서 가치가 크게 떨어진 경우 등)는 **미리 고지**해야 인정 |
| **환불 기한** | 반품 상품을 돌려받은 뒤 정해진 기간 안에 환불 |
| **거래 기록 보관** | 계약·결제 기록 등은 법에서 정한 기간(예: 5년) 보관 |
| **상품 정보 표시** | 상품 종류별로 원산지, 제조일, 소재 등 필수 표시 항목(상품정보제공고시) |
| **광고 표시** | 협찬·체험단 후기는 "광고", "협찬" 등 **대가를 받았다는 사실 표시** (일명 뒷광고 금지) |
| **약관 변경** | 손님에게 불리하게 바꿀 때는 미리 공지 |

> ⚠️ **보관 의무(거래 기록 5년 등)** 와 **파기 의무(개인정보는 다 쓰면 삭제)** 가 부딪힐 때는, 법이 보관하라고 정한 정보만 **따로 분리해서** 기간 동안 보관하고 나머지는 지우는 게 일반적인 방법입니다.

## 5부. 세금 달력 (개인사업자 기본)

| 시기 | 무엇 |
|---|---|
| **1월** | 부가가치세 확정 신고 (일반과세자: 지난해 7~12월분 / 간이과세자: 지난 1년분) |
| **5월** | 종합소득세 신고 (지난해 1년 소득) |
| **7월** | 부가가치세 확정 신고 (일반과세자: 1~6월분) |

> 처음 1년은 **세무사**나 홈택스 상담을 이용하는 것을 추천해요. 매출·비용 증빙(카드 내역, 세금계산서)은 처음부터 모아 두세요.

---

### 이 장 요약
1. 보안은 **2FA · 업데이트 · 최소 권한 · 카드정보 저장 안 하기 · 다른 곳에 백업**.
2. 쇼핑몰 시작 순서: **사업자등록 → PG/에스크로 → 통신판매업 신고 → 사이트 표시**.
3. 개인정보는 **최소 수집, 동의, 공개, 안전 보관, 파기**. 법은 바뀌니 공식 사이트에서 재확인.
