# 34. 도메인 이름 — 사이트 주소의 모든 것

5장에서 도메인을 **"가게 간판 이름"**, DNS를 **"간판 이름으로 주소를 찾아 주는 지도 앱"** 이라고 배웠어요.
이 장은 실제로 도메인을 **고르고, 사고, 연결하고, 지키고, 옮기고, 사고파는** 방법이에요.

> ⚠️ 가격·규칙은 2026년 10월 조사 기준이에요. 등록 업체마다 다르고 자주 바뀌니, 살 때는 업체의 안내를 꼭 확인하세요. ([참고 자료 모음](sources.md))

---

## 1. 도메인 주소 읽는 법

```
https://shop.granolalab.co.kr/products
└┬──┘   └┬─┘ └────┬───┘ └─┬─┘ └──┬───┘
 │       │        │       │      └ 경로 (사이트 안의 페이지)
 │       │        │       └ 최상위 도메인 (TLD) — .kr / .co.kr
 │       │        └ 내가 고른 이름 (2차 도메인)
 │       └ 서브도메인 — 같은 도메인 안에서 내가 마음대로 만드는 이름
 └ 통신 방식 (HTTPS = 암호화)
```

| 부분 | 쉬운 뜻 | 예 |
|---|---|---|
| **TLD (최상위 도메인)** | 맨 끝 꼬리. 종류·나라를 나타냄 | `.com`, `.kr`, `.co.kr`, `.shop`, `.io` |
| **도메인 이름** | 내가 사서 갖는 이름 | `granolalab` |
| **서브도메인** | 산 도메인 앞에 붙여 마음대로 만드는 이름 (추가 비용 없음) | `shop.`, `blog.`, `help.`, `api.` |
| **루트 도메인** | 서브도메인 없는 맨 주소 | `granolalab.co.kr` |
| **www** | 오래된 관례의 서브도메인 | `www.granolalab.co.kr` → 보통 루트로 자동 이동 설정 |

## 2. TLD 종류 — 무엇을 고를까

| 종류 | 예 | 특징 |
|---|---|---|
| **일반 최상위(gTLD)** | `.com`, `.net`, `.org` | 전 세계에서 가장 익숙함. `.com`이 신뢰도·기억하기 가장 좋음 |
| **국가 최상위(ccTLD)** | `.kr`, `.jp`, `.us` | 나라 표시. 한국 손님에게 친숙 |
| **.kr 아래 2단계** | `.co.kr`(회사), `.or.kr`(비영리), `.pe.kr`(개인), `.ac.kr`(학교), `.go.kr`(정부) | `.ac.kr`·`.go.kr`은 해당 기관만 등록 가능 |
| **새 gTLD** | `.shop`, `.store`, `.app`, `.dev`, `.ai` | 주제를 드러내기 좋음. **첫해만 싸고 갱신비가 비싼 경우**가 많음 |
| **한글 도메인** | `그래놀라랩.한국`, `그래놀라랩.kr` | 기억하기 쉬우나, 입력·공유가 불편할 때가 있어 보조용으로 많이 씀 |

### .kr 등록 자격
- `.kr` 계열은 **한국인터넷진흥원(KISA)** 이 관리해요.
- 국내 주소·국내 사업자 정보가 필요하다는 안내가 많고, 해외 거주자는 대리 등록 서비스를 써야 한다는 설명도 있어요. (출처마다 설명이 달라서, 정확한 자격은 KISA 공식 안내나 국내 등록 업체에서 확인하세요.)

### 고르는 기준
1. **한국 손님 위주**: `.kr` 또는 `.co.kr` (+ `.com`도 가능하면 같이)
2. **해외 손님도**: `.com` 우선
3. **개발·AI 서비스**: `.io`, `.dev`, `.ai`도 흔함 (갱신비 확인!)
4. **짧고, 말로 불러 줘도 헷갈리지 않게**: 하이픈(-), 숫자, 헷갈리는 철자(ph/f) 피하기
5. **상표 확인**: 남의 브랜드와 같거나 비슷하면 분쟁 위험 (6절)

> 💡 **방어 등록**: `granolalab.co.kr`을 쓴다면 `granolalab.kr`, `granolalab.com`도 같이 사 두는 곳이 많아요. 다른 사람이 사서 사칭·피싱에 쓰는 걸 막기 위해서예요. 사 둔 주소는 메인 주소로 **자동 이동(리디렉트)** 시키면 돼요.

## 3. 도메인 생태계 — 누가 무엇을 하나

```
ICANN (전 세계 도메인 규칙을 정하는 국제 기관)
  └ 레지스트리 (TLD 하나를 운영하는 곳)     예: .com = Verisign, .kr = KISA
       └ 등록 대행 업체(레지스트라)          예: 가비아, 후이즈, 카페24, Cloudflare, Namecheap 등
            └ 나 (등록자)                    도메인을 "1년~10년 단위로 빌려 쓰는" 사람
```

> ⚠️ 도메인은 **사는 게 아니라 기간을 정해 빌리는 것**이에요. 갱신을 안 하면 남의 것이 됩니다.

### 가격 감각
| 항목 | 내용 |
|---|---|
| `.com` 원가 | 레지스트리(Verisign)가 등록 업체에 받는 도매가가 **2026년 11월 1일부터 10.26달러 → 10.97달러로 인상**된다고 발표됐어요. 여기에 업체 이윤이 붙어 소비자 가격이 정해져요 |
| 앞으로 | 계약상 남은 기간 동안 매년 최대 7%까지 올릴 수 있다는 분석이 있어요 → **도메인 비용은 조금씩 오른다**고 생각하기 |
| 첫해 할인 | "첫해 몇백 원" 이벤트는 **갱신 가격**을 꼭 확인. 갱신비가 몇 배인 경우가 흔해요 |
| 프리미엄 도메인 | 짧고 좋은 이름은 업체나 개인이 비싸게 팔기도 해요 (7절) |

## 4. 사고 연결하기 — 실전 순서

```
1. 이름 후보 5개 → 등록 업체에서 사용 가능 여부 검색
2. 상표 검색 (특허청 키프리스) — 남의 상표와 겹치지 않는지
3. 구매: 반드시 "내 명의, 내 이메일, 내 결제 카드" (외주 업체 명의 ✕)
4. 자동 갱신 ON, 등록자 정보 보호(WHOIS 개인정보 보호) ON
5. 등록 업체 계정에 2단계 인증
6. DNS 설정: 사이트 연결 (아래 표)
7. 이메일 연결: MX · SPF · DKIM · DMARC (30장)
8. HTTPS 인증서 확인 (대부분 호스팅이 자동 발급)
9. www ↔ 루트, 방어 등록 주소 → 메인 주소로 리디렉트
10. 계정 목록 문서에 기록 (어디서 샀는지, 만료일) (9장)
```

### DNS 레코드 종류 (5·30장 복습 + 추가)
| 레코드 | 하는 일 | 예 |
|---|---|---|
| **A** | 도메인 → IPv4 주소 | `@ → 123.45.67.89` |
| **AAAA** | 도메인 → IPv6 주소 | |
| **CNAME** | 도메인 → **다른 도메인 이름**으로 연결 (별명) | `shop → myshop.cafe24.com` (빌더 연결에 자주 씀) |
| **MX** | 메일 받을 서버 | 30장 |
| **TXT** | 글자 정보 (소유 확인, SPF, DMARC 등) | `google-site-verification=...` |
| **NS** | 이 도메인의 DNS를 **어느 곳이 관리하는지** | 등록 업체 → Cloudflare로 바꿀 때 변경 |

- **TTL** = DNS 정보를 다른 컴퓨터들이 얼마나 오래 기억해 두는지(초). 바꾼 내용이 전 세계에 퍼지는 데 **몇 분~하루 이상** 걸릴 수 있어요. 큰 변경 전엔 TTL을 미리 짧게.
- 빌더(카페24·아임웹·쇼피파이 등)는 **"연결할 때 넣을 A·CNAME 값"** 을 안내해 줘요 → 그대로 넣기.

## 5. 도메인을 잃는 사고와 막는 법

### 만료되면 바로 사라질까? — 단계별 (gTLD 기준, 업체마다 다름)
| 단계 | 기간 (대략) | 상태 |
|---|---|---|
| 만료일 | — | 사이트·메일이 멈출 수 있음 |
| **갱신 유예 기간** | 최대 약 45일 (업체가 정함) | 원래 가격으로 갱신 가능한 경우가 많음 |
| **복구 유예 기간(Redemption)** | 약 30일 | DNS에서 빠짐. **비싼 복구 수수료**를 내야 되살릴 수 있음 |
| **삭제 대기** | 약 5일 | 되살릴 수 없음 |
| 공개 | — | **누구나 등록 가능** — 이걸 노리는 업자들이 바로 사 가기도 해요 |

> `.kr` 같은 국가 도메인은 기간이 다를 수 있어요.

### 사고 유형과 예방
| 사고 | 예방 |
|---|---|
| 갱신 카드 만료로 자동 갱신 실패 | 매월 카드 만료일 점검 (14장), 여러 해 미리 갱신 |
| 갱신 안내 메일을 못 받음 (퇴사자 메일·스팸함) | 등록 이메일을 **회사 공용 주소**로, 등록 업체 메일 주소를 스팸 예외로 |
| 외주 업체 명의로 등록돼 연락 두절 | 처음부터 **내 명의**, 이미 그렇다면 지금 명의 이전 (26장 인수인계) |
| 등록 업체 계정 해킹 → 도메인 탈취 | 2단계 인증, **도메인 잠금(전송 잠금) ON** |
| DNS 실수로 사이트·메일 다운 | 바꾸기 전 **현재 설정 캡처·백업**, 하나씩 바꾸기 (6·8장 원칙) |

## 6. 도메인 분쟁 — 상표와 이름이 겹칠 때

| 개념 | 설명 |
|---|---|
| **사이버스쿼팅** | 남의 유명 상표와 같은 도메인을 먼저 사 두고 비싸게 팔려는 행위 → 분쟁에서 빼앗길 수 있음 |
| **UDRP** | ICANN의 국제 분쟁 해결 절차. 상표권자가 ① 상표와 같거나 혼동될 만큼 비슷하고 ② 등록자에게 정당한 이익이 없고 ③ 부정한 목적으로 등록·사용됨을 입증하면 도메인 **이전·취소**. 손해배상은 안 됨 |
| **국내 제도** | 국내에는 인터넷주소자원법과 **인터넷주소분쟁조정위원회**가 있고, 법원 소송(상표법·부정경쟁방지법)도 가능 |

### 실전 팁
- 브랜드 이름을 정하면 **상표 출원**도 같이 고려 (특허청). 도메인만 있다고 이름의 권리가 생기지 않아요.
- 남의 브랜드가 들어간 도메인(`쿠팡할인.com` 등)은 사지 마세요. 분쟁·사칭 문제가 생겨요.

## 7. 도메인 옮기기 · 사고팔기

### 등록 업체 옮기기 (이전, Transfer)
```
1. 지금 업체에서 도메인 잠금 해제
2. 인증 코드(EPP/Auth 코드) 받기
3. 새 업체에서 "도메인 이전" 신청 + 코드 입력 (보통 1년 연장 비용 포함)
4. 이메일 승인 → 며칠 안에 완료
5. DNS 설정이 그대로인지 확인
```
- gTLD는 **새로 등록했거나, 이전했거나, 등록자 정보를 크게 바꾼 뒤 60일 동안** 다른 업체로 이전이 막히는 규칙이 있다는 안내가 많아요(조건은 정책 원문 확인).
- **만료 직전·직후에는 이전하지 않기** — 비용이 이중으로 들거나 실패할 수 있어요.

### 도메인 사고팔기
- 이미 누가 가진 이름이 꼭 필요하면: 도메인 거래 사이트, 또는 등록자에게 연락(WHOIS 정보가 가려져 있으면 업체의 중개 서비스)
- **에스크로(중간 보관)** 서비스로 거래 — 돈을 먼저 보내고 도메인을 못 받는 사기 방지
- 사이트를 통째로 팔 때 도메인은 **가장 중요한 자산** (22장 사이트 매매)

## 8. 도메인 관리 체크리스트

- [ ] 내 명의 · 내 공용 이메일 · 2단계 인증
- [ ] 자동 갱신 ON + 결제 카드 만료일 확인 (매월)
- [ ] 도메인 잠금(전송 잠금) ON
- [ ] 등록자 정보 보호(WHOIS 프라이버시) ON
- [ ] 방어 등록 주소들 → 메인 주소로 리디렉트
- [ ] DNS 설정 캡처를 문서로 보관 (바꿀 때마다)
- [ ] 계정 목록에 등록 업체·만료일 기록
- [ ] 상표 출원 검토

---

### 이 장 요약
1. 도메인은 **기간을 정해 빌리는 것**. `.com`·`.kr`·`.co.kr` 중 손님 기준으로 고르고, 짧고 부르기 쉽게, 방어 등록.
2. 사면 바로 **내 명의 · 자동 갱신 · 2단계 인증 · 잠금**. DNS는 A·CNAME·MX·TXT·NS, 바꾸기 전 캡처.
3. 만료 후에도 단계가 있지만 **복구비는 비싸고 결국 남이 가져간다**. 남의 상표가 들어간 도메인은 분쟁 대상.
