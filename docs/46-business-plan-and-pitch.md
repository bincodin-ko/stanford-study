# 46. 사업계획서·발표 자료(IR) 쓰기

지원사업(45장)·투자·대출·공동 창업자 설득 모두 **사업계획서**와 **발표 자료**가 필요해요.
이 장은 **심사하는 사람이 읽기 쉬운** 사업계획서와 발표 자료 구성법이에요.

> ⚠️ 정부 지원사업은 **공고마다 정해진 양식**이 있어요. 아래는 대부분의 양식에 공통으로 들어가는 내용이고, 실제로는 그해 공고의 양식과 평가 항목을 그대로 따르세요. ([참고 자료 모음](sources.md))

---

## 1. 심사위원이 확인하는 4가지

| 질문 | 쓰는 내용 | 이 자료에서 |
|---|---|---|
| **문제가 진짜인가?** | 누가, 얼마나 불편한가 + **증거**(인터뷰, 검색량, 사전 신청 수) | 42장 |
| **해결책이 좋은가?** | 내 서비스가 어떻게 푸는지, 경쟁 서비스와 뭐가 다른지 | 4·22장 |
| **돈이 되나?** | 손님 수, 가격, 수익 모델, 1명당 이익 | 2·43장 |
| **이 팀이 해낼 수 있나?** | 경험, 지금까지 만든 것, 일정, 돈 쓰는 계획 | 53장 |

> 💡 가장 강한 문장은 **"이미 해 봤더니 이랬다"** 예요. "사전 신청 200명", "베타 사용자 30명 중 12명 재구매" 같은 숫자 하나가 형용사 열 개보다 강해요.

## 2. 사업계획서 기본 구성

```
1. 요약 (한 페이지) — 문제·해결·시장·성과·필요한 돈과 쓰임
2. 문제 인식 — 손님의 불편 + 증거
3. 해결책 — 서비스 설명, 핵심 기능, 화면 (스크린샷)
4. 시장 — 목표 손님, 규모(TAM·SAM·SOM, 3장), 경쟁 분석 표
5. 사업 모델 — 가격, 수익 구조, 단위 경제(1명당 이익)
6. 실적·검증 — 지금까지 한 것 (MVP, 사용자, 매출, 인터뷰)
7. 실행 계획 — 마케팅·판매 채널 (32·33장), 일정표(마일스톤)
8. 팀 — 역할, 경험, 앞으로 필요한 인력
9. 자금 계획 — 얼마가 필요하고, 어디에 쓰고, 그 결과 무엇을 달성하나
10. 위험과 대응 — 법·규제(29장), 경쟁, 기술 위험
```

### 잘 쓰는 요령
| 요령 | 예 |
|---|---|
| **숫자로** | "많은 사람이" ✕ → "월 검색량 2만 건, 인터뷰 12명 중 9명이 같은 불편" ○ |
| **표와 그림** | 경쟁 비교표, 일정표, 화면 캡처 |
| **평가 항목에 맞춰 제목** | 공고문의 평가 기준 단어를 그대로 소제목으로 |
| **돈 쓰는 계획은 구체적으로** | "마케팅 1,000만 원" ✕ → "인스타 광고 월 50만 원 × 6개월, 목표 가입 600명(CAC 5천 원)" ○ |
| **경쟁자가 없다고 쓰지 않기** | "경쟁자 없음"은 시장이 없다는 뜻으로 읽힐 수 있음 → 대체재까지 포함해 비교 |
| **전문용어는 풀어서** | 심사위원이 그 분야 전문가가 아닐 수 있음 |

## 3. 발표 자료(피치 덱) — 10~15장 구성

| # | 슬라이드 | 한 줄 메시지 |
|---|---|---|
| 1 | 표지 | 서비스 이름 + 한 줄 설명 ("○○를 위한 ○○") |
| 2 | 문제 | 손님의 불편을 장면으로 |
| 3 | 해결책 | 우리가 푸는 방법 (화면 1장) |
| 4 | 시연·제품 | 실제 화면, 짧은 데모 |
| 5 | 시장 | 누구에게, 얼마나 |
| 6 | 사업 모델 | 어떻게 돈을 버나 |
| 7 | **성과(트랙션)** | 사용자·매출·성장 그래프 ← 가장 중요 |
| 8 | 경쟁 | 비교표 (우리가 다른 점) |
| 9 | 성장 전략 | 손님 데려오는 방법 |
| 10 | 팀 | 왜 우리가 할 수 있나 |
| 11 | 재무·자금 | 필요한 돈과 쓰임, 달성 목표 |
| 12 | 마무리 | 한 줄 요약 + 연락처 |

- **한 장에 메시지 하나** (이 자료의 PPT처럼).
- 발표는 보통 시간이 짧아요(5~10분) → 연습할 때 **시간을 재고**, 예상 질문 10개 답변 준비.
- 자주 받는 질문: "경쟁사가 따라 하면?", "왜 지금인가?", "손님 1명 데려오는 비용은?", "돈을 다 쓰면 그다음은?"

## 4. AI(Claude)와 함께 쓰는 법

| 단계 | Claude에게 |
|---|---|
| 뼈대 | "이 공고문의 평가 항목에 맞춰 사업계획서 목차를 만들어 줘" (공고문 붙여 넣기) |
| 초안 | "내가 준 사실(인터뷰 결과·숫자)만 써서 각 항목 초안을 써 줘. 모르는 건 빈칸으로" |
| 비판 | "심사위원 입장에서 이 계획서의 약점 10가지를 지적해 줘" |
| 발표 | "이 내용을 12장 발표 자료 구성으로 바꾸고, 예상 질문과 답을 만들어 줘" |

> ⚠️ AI가 **숫자·실적을 지어내지 않게** "내가 준 사실만"을 꼭 넣으세요. 허위 기재는 선정 취소·환수 사유가 될 수 있어요. 최종 문장은 **내 말로** 다듬기.

---

## 5. 사업계획서 체크리스트

- [ ] 공고문 양식·분량·평가 항목 확인
- [ ] 한 페이지 요약을 따로 써 봤다 (이게 안 되면 생각이 정리 안 된 것)
- [ ] 문제의 **증거**(인터뷰·검색량·사전 신청)가 있다
- [ ] 경쟁 비교표 (대체재 포함)
- [ ] 1명당 이익 계산 (43장)
- [ ] 돈 쓰는 계획 = 항목·금액·결과 목표
- [ ] 일정표(월별 마일스톤)
- [ ] 다른 사람에게 읽혀 보고 "무슨 사업인지" 한 문장으로 말하는지 확인

---

### 이 장 요약
1. 심사위원은 **문제가 진짜인가·해결책·돈이 되나·팀이 해낼 수 있나**를 본다.
2. 형용사 대신 **숫자와 증거**(검증 결과·트랙션), 공고의 **평가 항목 순서** 그대로.
3. 발표 자료는 **10~15장, 한 장에 메시지 하나**, 성과 슬라이드가 핵심. AI는 뼈대·비판에 쓰되 **사실은 내가** 넣는다.
