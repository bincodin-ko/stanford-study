# 32. 마케팅 시작하기 — 채널별 실전 (인스타그램 중심)

11장에서는 마케팅의 **개념**(퍼널, 전환율, A/B 테스트)을 배웠어요.
이 장은 **"내일 당장 계정을 만들고 뭘 올리지?"** 에 답하는 실전편이에요. 다음 장(33장)에서는 분야별 시작법과 실제 회사들의 사례를 봅니다.

> ⚠️ SNS 알고리즘·광고 정책은 아주 자주 바뀌어요. 아래는 **2026년 10월 조사 기준**이고, 숫자 상당수는 공식 발표가 아니라 광고 대행사·업계 기사에서 확인한 것이에요. ([참고 자료 모음](sources.md))

## 0. 시작 전에 정할 3가지

| 질문 | 예 (그래놀라 쇼핑몰) |
|---|---|
| **누구에게?** (4장 페르소나) | 아침을 거르는 30대 직장인 |
| **그 사람은 어디에 있나?** | 인스타그램, 네이버 검색("무설탕 그래놀라"), 직장인 커뮤니티 |
| **무엇을 보여 줄까?** | "3분 아침" 레시피 영상, 성분 비교, 실제 후기 |

> 💡 채널을 처음부터 5개씩 하지 마세요. **손님이 가장 많이 있는 채널 1~2개**를 3개월 꾸준히 하는 게 5개를 2주 하다 지치는 것보다 훨씬 효과적이에요.

### 채널 고르기 한눈에
| 채널 | 어울리는 사업 | 잘 먹히는 콘텐츠 |
|---|---|---|
| **인스타그램** | 쇼핑몰, 음식, 뷰티, 인테리어, 크리에이터, 동네 가게 | 짧은 영상(릴스), 사진 묶음(캐러셀), 후기 |
| **네이버 (블로그·플레이스·검색광고)** | 동네 가게, 병원·학원, 정보 사이트, 쇼핑몰 | 검색했을 때 나오는 후기·정보 글 |
| **유튜브 / 쇼츠** | 크리에이터, 강의, 게임, 리뷰 | 설명·리뷰 영상, 짧은 영상 |
| **스레드** | 지식·정보, 크리에이터, 1인 사업, IT 서비스 | 짧은 글, 대화·답글 |
| **당근** | 동네 가게, 동네 서비스(청소·과외·수리) | 동네 소식, 쿠폰 |
| **카카오톡 채널** | 이미 손님이 있는 가게·쇼핑몰 | 재방문 쿠폰, 예약 안내 |
| **커뮤니티(카페·디스코드·레딧 등)** | 게임, 앱, 니치 정보, B2B 도구 | 진짜 도움이 되는 글 (홍보 글은 대부분 금지) |
| **뉴스레터·이메일** | 정보·지식, B2B, 재구매 쇼핑몰 | 정기적인 정리·소식 |
| **검색 광고 (네이버·구글)** | 이미 찾는 사람이 있는 상품·서비스 | 검색어에 딱 맞는 광고 |

## 1. 인스타그램 — 계정 만들기부터 첫 30일까지

### ① 계정 설정 (첫날)
| 할 일 | 이유 |
|---|---|
| **프로페셔널 계정**(비즈니스/크리에이터)으로 전환 | 인사이트(통계), 연락처 버튼, 광고 사용 가능 |
| 사용자 이름 = 브랜드 이름 (짧고 검색 쉽게) | `granolalab_official` 보다 `granolalab` |
| **프로필 사진**: 로고 또는 대표 얼굴 | 작은 동그라미에서도 알아보게 |
| **소개 글 3줄 공식**: 누구를 위한 / 무엇을 / 지금 할 행동 | "아침 거르는 직장인을 위한 무설탕 그래놀라 🥣 / 3분 아침 레시피 매주 업로드 / 👇 첫 구매 10% 할인" |
| **링크**: 쇼핑몰 또는 링크 모음 페이지 | 링크에 UTM 꼬리표 붙이기 (11장) → 인스타에서 온 손님을 따로 셈 |
| **하이라이트**(프로필 아래 동그라미): 후기 / FAQ / 이벤트 / 배송 | 처음 온 사람이 바로 신뢰를 확인 |
| 2단계 인증 켜기 | 계정 해킹 방지 (10장) |

### ② 무엇을 올릴까 — 콘텐츠 3종류 비율
| 종류 | 목적 | 예 | 비율 감각 |
|---|---|---|---|
| **도움 되는 것** | 저장·공유 → 새 사람에게 퍼짐 | "편의점 재료로 3분 아침 5가지" | 절반 정도 |
| **믿음을 주는 것** | 신뢰 | 만드는 과정, 실제 후기, 대표 이야기 | 1/3 정도 |
| **사게 만드는 것** | 판매 | 신제품, 할인, 마감 임박 | 나머지 조금 |

> 💡 판매 글만 올리는 계정은 팔로우할 이유가 없어요. **"이 계정을 팔로우하면 나에게 뭐가 좋지?"** 에 답이 있어야 해요.

### ③ 형식별 특징
| 형식 | 특징 | 언제 |
|---|---|---|
| **릴스(짧은 세로 영상)** | 팔로워가 아닌 사람에게도 추천되어 **새 사람을 데려오기**에 가장 강함 | 주력 |
| **캐러셀(사진 여러 장 묶음)** | 정보형 콘텐츠, **저장**이 잘 됨 | "5가지 방법" 같은 정리 |
| **스토리(24시간)** | 이미 팔로우한 사람과 친해지기, 투표·질문 스티커 | 매일 가볍게 |
| **라이브** | 실시간 질문·판매 | 신제품 출시, Q&A |
| **DM** | 1:1 상담, 문의 (30장) | 답장은 빠르게 |
| **협업 게시물** | 다른 계정과 공동 게시 → 양쪽 팔로워에게 동시에 노출 | 협업·협찬 (광고 표시!) |

### ④ 알고리즘이 보는 것 (조사 기준)
인스타그램 책임자 애덤 모세리(Adam Mosseri)는 2025년 1월 **가장 중요한 3가지 신호**로 아래를 꼽았다고 보도됐어요.

| 신호 | 뜻 | 인사이트에서 볼 숫자 |
|---|---|---|
| **시청 시간** | 영상을 얼마나 오래 봤나 | 평균 시청 시간 |
| **좋아요** | 좋아요를 누른 비율 | 도달 대비 좋아요 |
| **보내기(공유)** | DM으로 친구에게 보낸 비율 | **도달 대비 보내기** |

- 업계 해설에 따르면, **좋아요는 이미 팔로우한 사람**에게, **보내기는 아직 모르는 사람**에게 퍼지는 데 조금 더 중요하다고 해요.
- 그래서 **"친구에게 보내고 싶은 콘텐츠"** (공감, 꿀팁, 웃긴 것)가 새 손님을 데려와요.

### ⑤ 영상 만드는 실전 팁
- **첫 1~2초에 결론이나 궁금증**: "이거 하나로 아침 끝" / "편의점에서 3천 원으로"
- 자막 필수 (소리 끄고 보는 사람이 많음)
- 세로(9:16), 짧게. 한 영상 = 한 메시지
- 마지막에 행동 유도: "저장해 두세요", "아침 안 먹는 친구에게 보내 주세요"
- 같은 주제를 여러 방식으로 반복 → **반응 좋은 주제를 찾을 때까지 실험** (A/B 테스트, 11장)

### ⑥ 해시태그
- **2025년 12월부터 게시물당 해시태그가 5개로 제한**됐다는 보도가 여러 매체에서 나왔어요(이전엔 30개).
- 해시태그보다 **캡션 첫 줄과 영상 속 문구에 검색될 단어**를 넣는 게 더 중요해졌다는 의견이 많아요.
- 5개는 **내 주제를 정확히 설명하는 것** 위주로: `#그래놀라 #무설탕간식 #직장인아침 #아침대용 #그래놀라랩`

### ⑦ 첫 30일 계획 (예시)
| 주차 | 할 일 |
|---|---|
| 1주 | 계정 세팅, 하이라이트, 첫 게시물 6~9개 (프로필이 비어 보이지 않게) |
| 2주 | 릴스 주 3개 + 스토리 매일. 같은 업계 계정 20곳에 **진심 담긴 댓글** |
| 3주 | 인사이트 확인: 시청 시간·보내기가 높은 주제 찾기 → 그 주제 더 만들기 |
| 4주 | 반응 좋은 릴스 1개에 **소액 광고**로 테스트 (2절), 작은 크리에이터 1~2명과 협업 |

> ⚠️ **하지 말 것**: 팔로워 구매, 좋아요·댓글 자동화 프로그램, 남의 사진·영상 무단 사용. 계정 정지·신뢰 하락의 지름길이에요.

## 2. 메타(인스타그램·페이스북) 광고 — 처음 시작하는 법

### 기본 구조
```
캠페인 (목표: 판매 / 트래픽 / 인지도 / 리드)
 └ 광고 세트 (누구에게, 얼마를, 언제)
     └ 광고 (실제 영상·이미지·문구)
```

### 처음 세팅 순서
1. **메타 비즈니스 계정** 만들기 → 인스타그램 계정 연결
2. 쇼핑몰에 **픽셀/전환 추적** 설치 (구매·장바구니를 메타가 알 수 있게, 빌더는 보통 연동 메뉴 제공)
3. 목표 고르기: 처음 판매라면 보통 **"판매(전환)"**
4. 타겟: 처음엔 너무 좁히지 않기 (나이·지역 정도). 요즘은 메타 자동 타겟이 잘 찾는 편이라는 의견이 많아요
5. 광고 소재: **이미 반응 좋았던 릴스**를 광고로 쓰는 게 가장 안전한 출발
6. 1주일은 자주 건드리지 않기 → 학습 기간

### 예산 감 잡기 (국내 광고 대행사들이 많이 쓰는 계산법)
- 메타 광고는 광고 세트당 **약 7일 동안 최적화 이벤트(예: 구매) 50회** 정도가 쌓여야 "학습"이 끝난다고 흔히 안내돼요.
- 그래서 하루 예산을 이렇게 거꾸로 계산하는 방법이 많이 쓰여요.
```
하루 예산 ≈ 목표 전환 1건 비용 × 50 ÷ 7

예) 구매 1건을 1만 원에 얻고 싶다 → 10,000 × 50 ÷ 7 ≈ 하루 7만 원
```
- 이 예산이 부담되면: 목표를 "구매"보다 앞 단계(장바구니 담기, 상세 페이지 보기)로 잡거나, 광고 세트를 하나로 합쳐서 데이터를 모으는 방법을 써요.
- ⚠️ 위 숫자는 공식 규칙이 아니라 업계 경험칙이에요. **작게 시작해서 ROAS(광고비 대비 매출, 3장)를 보며 늘리세요.**

## 3. 네이버 — 한국에서 "검색하면 나오는" 자리 잡기

### ① 네이버 스마트플레이스 (동네 가게·병원·학원 필수)
- **네이버 지도·검색에 가게 정보**가 뜨게 하는 무료 등록. 영업시간, 메뉴, 사진, 예약, 리뷰.
- 실전 포인트 (국내 마케팅 자료 공통):
  - 사진·메뉴·가격을 **최신으로**
  - **실제 방문 손님의 리뷰가 꾸준히** 쌓이게 (영수증 리뷰 안내, 리뷰에 사장님 답글)
  - 2025년부터 네이버가 **최신 리뷰를 AI로 요약해 보여 준다**는 업계 설명이 있어서, 구체적인 리뷰가 많을수록 유리하다는 의견이 많아요
- ⚠️ **리뷰·저장·알림을 돈 주고 사는 "어뷰징"** 은 적발되면 순위가 떨어질 수 있고, 가짜 후기는 법적으로도 문제(표시광고법)가 될 수 있어요.

### ② 네이버 블로그
- 사람들이 **"지역 + 업종"**, **"제품 + 후기"** 를 검색하면 블로그 글이 많이 나와요.
- 내 블로그: 제품 만드는 과정, 사용법, FAQ를 꾸준히 (17장 정보 사이트 운영법과 같음)
- **체험단(블로거에게 무료 제공 후 후기 작성)**: 국내 소상공인이 가장 많이 쓰는 방법 중 하나
  - 실전 팁: 처음부터 큰 키워드("홍대맛집")보다 **검색량이 적은 세부 키워드**("합정 조용한 브런치")를 노려 단계적으로
  - 반드시 **"제품(서비스)을 제공받아 작성"** 표시 (뒷광고 금지, 18장)
  - 체험단 대행사 중에는 섭외만 하고 키워드 전략은 없는 곳도 있다는 지적이 있어요 → 어떤 키워드로 쓸지 내가 정하기

### ③ 네이버 검색광고 (파워링크 등)
- **검색어에 돈을 걸어** 검색 결과 위쪽에 노출. 클릭할 때만 비용(CPC).
- 실전: 비싼 큰 검색어보다 **구체적인 긴 검색어**("무설탕 그래놀라 대용량")부터. 키워드 도구로 검색량 확인.

## 4. 그 밖의 채널 실전 요약

### 유튜브 / 쇼츠
- 쇼츠: 인스타 릴스와 같은 영상을 함께 올려 재활용
- 긴 영상: **"검색되는 제목"** — "그래놀라 만드는 법", "○○ 사용 후기 3개월"
- 크리에이터 사업이라면 24장 참고

### 스레드 (Threads)
- 메타가 만든 **글 중심 SNS**. 국내 이용자가 빠르게 늘고 있다는 조사가 여러 개 있어요 (2026년 7월 국내 사용자 약 800만 명, 1년 새 약 30% 증가라는 앱 분석 업체 조사 등 — 조사마다 숫자 차이 큼).
- 국내 스레드는 **글만 있는 게시물과 답글 대화**의 비중이 높다는 분석이 있어요 → 짧은 경험담, 질문, 정보 정리가 잘 맞아요.
- 인스타그램 계정으로 바로 시작할 수 있어서 **인스타를 하고 있다면 추가 부담이 적어요.**

### 당근 (동네 장사)
- **비즈프로필**을 만들어 동네 이웃에게 가게 소식·쿠폰 발행
- 광고: 비즈프로필 광고 / 소식 광고 등이 있고, **클릭할 때 충전금에서 차감**되는 방식이라는 안내가 많아요. 최소 금액·정책은 당근 비즈니스 공식 안내로 확인.
- 청소·수리·과외·꽃집·미용실처럼 **동네 단위 서비스**에 특히 잘 맞아요.

### 카카오톡 채널
- 이미 온 손님을 **다시 부르는** 도구: 예약 확인, 재방문 쿠폰, 신메뉴 소식
- 친구 추가 혜택("채널 추가 시 음료 무료")으로 손님을 채널에 모으기
- 광고 메시지는 **수신 동의·(광고) 표시 규칙** 적용 (30장)

### 커뮤니티 (카페, 디스코드, 레딧, 개발자 커뮤니티 등)
- 대부분 **홍보 글을 금지**해요. 규칙을 먼저 읽기.
- 실전: 몇 주 동안 **진짜 도움 되는 답변·정보**를 올리며 신뢰를 쌓고, 허용된 게시판(홍보 게시판, 자기 프로젝트 소개 요일 등)에서만 소개
- "회원인 척" 홍보(바이럴 알바)는 금지 — 들키면 브랜드가 크게 다쳐요 (16장)

### 뉴스레터·추천 프로그램
- 사이트 방문자를 **이메일 구독자로** 바꿔 두면, 알고리즘 변화에 덜 흔들려요 (18장)
- **추천 프로그램**: "친구 3명 초대하면 선물" — 33장 사례(모닝 브루, 드롭박스) 참고

## 5. 성과 보는 법 — 숫자 5개만

| 숫자 | 어디서 | 뜻 |
|---|---|---|
| **도달** | 인스타 인사이트 | 몇 명에게 보였나 |
| **도달 대비 보내기·저장** | 인스타 인사이트 | 퍼질 만한 콘텐츠인가 |
| **프로필 방문 → 링크 클릭** | 인사이트 + UTM | 관심이 행동으로 이어지나 |
| **채널별 매출·가입** | GA4 + UTM (11장) | 어느 채널이 돈이 되나 |
| **ROAS / CAC** | 광고 관리자 + 매출 | 광고비 대비 남는가 (2·3장) |

> 💡 팔로워 수는 **결과**지 목표가 아니에요. 팔로워 1만 명이어도 매출이 0이면 실패, 팔로워 500명이어도 단골 100명이 생기면 성공이에요.

### 이 장 요약
1. 채널은 **손님이 있는 곳 1~2개**만, 3개월 꾸준히. 인스타는 **프로필 정리 → 도움 되는 릴스 → 인사이트 → 소액 광고** 순서.
2. 인스타는 **시청 시간·좋아요·보내기**를 본다(2025년 1월 발표 기준). 해시태그는 5개로 줄었다는 보도 → 캡션 첫 줄과 영상 속 단어가 더 중요.
3. 한국 동네 장사는 **네이버 플레이스(진짜 리뷰) + 당근 + 카카오 채널**, 모든 협찬엔 **광고 표시**.
