# 28. AI 서비스 사업

ChatGPT·Claude 같은 AI 모델이 나오면서, **AI를 활용한 서비스**가 새로운 인터넷 사업 분류로 자리 잡았어요.
대부분의 작은 회사는 AI 모델을 직접 만들지 않고, **AI 회사의 API(기능 창구)를 빌려 와서** 서비스를 만듭니다.

> ⚠️ AI 관련 법·요금·정책은 매우 빠르게 바뀝니다. 2026년 10월 조사 기준입니다.

---

## 1. AI 서비스의 종류

| 종류 | 예 | 특징 |
|---|---|---|
| **특정 업무용 AI 도구** | 상세페이지 문구 작성기, 회의록 요약, 계약서 검토 보조 | 좁은 문제를 확실히 풀어 줌 (가장 흔함) |
| **AI 기능을 넣은 기존 서비스** | 쇼핑몰 상품 추천, 고객센터 챗봇 | 기존 사업(1~13장)에 AI를 더함 |
| **AI 에이전트·자동화** | 반복 업무를 대신 처리 | B2B에서 많이 씀 |
| **AI 콘텐츠 서비스** | 이미지·음성·영상 생성 | 저작권·초상권 이슈가 큼 |
| **AI 교육·컨설팅** | AI 활용법 강의, 기업 도입 컨설팅 | 26장 지식 판매와 같음 |

> 💡 흔히 "AI 래퍼(wrapper)"라고 부르는, **남의 AI 모델 위에 화면만 씌운 서비스**는 만들기 쉽지만 따라 하기도 쉬워요. 오래 살아남는 서비스는 보통 **특정 업무 흐름, 나만의 데이터, 손님과의 관계**를 갖고 있어요.

---

## 2. AI 서비스의 비용 구조 — 일반 SaaS와 다른 점

일반 SaaS는 손님이 늘어도 비용이 조금만 늘지만, AI 서비스는 **손님이 쓸 때마다 AI 사용료(API 비용)가 나가요.**

```
월 구독료                10,000원
− AI API 사용료 (사용량 따라) −3,000원 ~ −15,000원 (!)
− 서버·결제 수수료           −1,000원
= 남는 돈                  6,000원 ~ 적자
```

→ **많이 쓰는 손님일수록 손해**가 날 수 있어요. 그래서
| 대응 | 설명 |
|---|---|
| **사용량 제한** | 요금제별 월 사용 횟수 |
| **사용량 과금** | 쓴 만큼 내게 (2장) |
| **작은 모델 우선 사용** | 쉬운 일은 저렴한 모델, 어려운 일만 비싼 모델 |
| **캐시** | 같은 질문엔 저장된 답 재사용 |
| **원가 모니터링** | 손님별 AI 비용을 매일 보기 (9장 모니터링에 추가) |

---

## 3. AI 서비스 운영에서만 생기는 일

| 이슈 | 설명 | 대응 |
|---|---|---|
| **틀린 답(환각)** | AI가 그럴듯하게 틀린 말을 함 | "AI 답변은 틀릴 수 있음" 안내, 중요한 분야는 사람이 확인 |
| **모델 업데이트** | AI 회사가 모델을 바꾸면 답변 품질·말투가 달라짐 | 업데이트 전 **테스트 질문 세트**로 비교 (7장 스테이징과 같은 원리) |
| **API 장애** | AI 회사 서버가 멈추면 내 서비스도 멈춤 | 다른 모델로 넘기는 대비책, 장애 공지 (9장) |
| **개인정보** | 손님이 입력한 내용이 외부 AI 회사로 전송됨 | 개인정보처리방침에 **위탁·국외 이전** 내용 명시 (10장), 민감 정보 입력 주의 안내 |
| **악용** | 불법 콘텐츠 생성 요청, 프롬프트로 규칙 우회 시도 | 이용 규칙, 필터, 신고 |
| **저작권** | 생성물이 남의 저작물과 비슷할 수 있음 | 이용약관에 책임 범위 명시 |

## 4. 한국 AI 기본법 (2026년 1월 22일 시행)

조사 결과 정리 (세부 기준은 과학기술정보통신부 공식 안내로 확인하세요):
- **직접 AI 모델을 만들지 않고 외부 API를 써서 서비스하는 회사도** "AI 이용사업자"로 적용 대상이 될 수 있다는 해석이 있어요.
- **생성형 AI 표시 의무**: AI로 서비스한다는 사실을 **미리 알리고**, AI가 만든 결과물임을 **표시**하는 등 투명성 의무가 있어요. 특히 실제와 구분하기 어려운 이미지·음성·영상은 더 엄격해요.
- **고영향 AI**(채용, 대출 심사, 의료 등 사람의 삶에 큰 영향을 주는 분야): 위험 관리, 설명 등 추가 의무.
- 위반 시 **과태료**가 있을 수 있고, 정부가 일정 기간 계도(안내) 기간을 두고 있다는 보도가 있어요. 다만 "준비 기간이지 의무가 없는 기간이 아니다"라는 해설도 있으니 처음부터 지키는 게 안전합니다.

## 5. AI 서비스 지표

| 지표 | 뜻 |
|---|---|
| **사용자 1명당 AI 비용** | 원가. 구독료보다 작아야 함 |
| **매출총이익률** | (매출 − AI 비용 − 서버비) ÷ 매출 |
| **작업 성공률** | AI가 손님의 일을 제대로 끝낸 비율 |
| **재사용률** | 다음 주에도 쓰나 (신기해서 한 번 써 보고 떠나는 사람이 많음) |
| 응답 시간 | 느리면 이탈 |

---

### 이 장 요약
1. 작은 회사의 AI 서비스는 대부분 **외부 AI API + 특정 업무 흐름**.
2. **쓸 때마다 원가(API 비용)가 나간다** → 사용량 제한·과금, 원가 모니터링이 필수.
3. **틀린 답, 모델 변경, 개인정보, AI 기본법 표시 의무**를 운영 체크리스트에 넣는다.
