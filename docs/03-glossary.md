## A. 사업·전략

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **BM (비즈니스 모델)** | 누구에게 무엇을 팔아 어떻게 돈을 버는지 정리한 것 |
| ★ **MVP** | 최소 기능 제품. 핵심 기능만 넣어 빨리 내놓고 반응을 보는 첫 버전 |
| ★ **PMF** | 제품-시장 적합성. "손님이 알아서 찾아오고, 없어지면 아쉬워하는" 상태 |
| **피벗(Pivot)** | 반응이 없어서 방향을 크게 바꾸는 것 |
| **TAM / SAM / SOM** | 전체 시장 / 내가 닿을 수 있는 시장 / 현실적으로 차지할 시장 크기 |
| **페르소나** | "29세 직장인 김OO"처럼 대표 손님을 가상 인물로 만든 것 |
| **USP / 차별점** | 경쟁사 대신 나를 골라야 하는 이유 |
| **부트스트래핑** | 투자 없이 내 돈과 매출로만 키우는 것 |
| **런웨이(Runway)** | 지금 돈으로 몇 달 버틸 수 있는지 |
| **번 레이트(Burn rate)** | 한 달에 나가는 돈 |

## B. 숫자·지표 (KPI)

> ★ **KPI** = 핵심 성과 지표. "우리가 잘하고 있나?"를 판단하는 몇 개의 숫자.

| 용어 | 쉬운 뜻 | 계산 |
|---|---|---|
| ★ **DAU / MAU** | 하루 / 한 달 동안 1번 이상 쓴 사람 수 | — |
| ★ **전환율(CVR)** | 방문자 중 실제로 구매(가입)한 비율 | 구매자 ÷ 방문자 |
| ★ **이탈률(Churn)** | 구독을 끊은 비율 | 이번 달 해지 ÷ 월초 구독자 |
| **바운스율(Bounce rate)** | 한 페이지만 보고 바로 나간 비율 | — |
| ★ **CAC** | 손님 1명 데려오는 데 쓴 돈 | 마케팅비 ÷ 신규 고객 수 |
| ★ **LTV** | 손님 1명이 평생 내 주는 돈 | (대략) 월 객단가 ÷ 월 이탈률 |
| **LTV / CAC** | 데려온 값어치가 있는가. 흔히 3배 이상을 건강하다고 봄 | — |
| **ARPU** | 사용자 1명당 평균 매출 | 매출 ÷ 사용자 수 |
| **AOV / 객단가** | 주문 1건당 평균 금액 | 매출 ÷ 주문 수 |
| ★ **MRR / ARR** | 매달(매년) 반복해서 들어오는 구독 매출 | ARR ≈ MRR × 12 |
| **NRR** | 기존 손님에게서 1년 뒤 매출이 몇 %로 남았나(업그레이드 포함) | — |
| **GMV** | 플랫폼에서 오간 총 거래액 | — |
| **Take rate** | 거래액 중 플랫폼이 가져가는 비율 | 수수료 매출 ÷ GMV |
| ★ **ROAS** | 광고비 1원당 매출 | 광고 매출 ÷ 광고비 |
| **CTR** | 광고/링크를 본 사람 중 클릭한 비율 | 클릭 ÷ 노출 |
| **CPC / CPM** | 클릭 1번당 / 노출 1,000번당 광고비 | — |
| **리텐션(Retention)** | 시간이 지나도 계속 쓰는 비율(이탈의 반대) | — |
| **코호트(Cohort)** | "1월 가입자", "2월 가입자"처럼 같은 시기 손님 묶음 | — |
| **퍼널(Funnel)** | 방문 → 장바구니 → 결제처럼 단계별로 줄어드는 깔때기 | — |

## C. 마케팅·성장

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **SEO** | 검색 엔진 최적화. 네이버·구글 검색에서 위에 뜨게 만드는 것 |
| **SEM / 검색 광고** | 돈 내고 검색 결과 위에 광고를 거는 것 |
| ★ **퍼포먼스 마케팅** | 숫자(클릭·구매)로 효과를 바로 재는 광고 |
| **그로스 해킹** | 실험을 빨리 반복해서 성장시키는 방식 |
| ★ **A/B 테스트** | 화면 A와 B를 반씩 보여 주고 어느 쪽이 더 잘 팔리는지 비교 |
| **CTA** | "지금 구매하기"처럼 행동을 유도하는 버튼/문구 |
| **랜딩 페이지** | 광고를 누르면 처음 도착하는 페이지 |
| **리타겟팅** | 한 번 왔다 간 사람에게 다시 광고를 보여 주는 것 |
| **UTM** | 링크 뒤에 붙이는 꼬리표. "이 손님이 인스타 광고에서 왔다"를 알 수 있음 |
| **CRM** | 고객 관리. 고객 정보·구매 기록을 모아 관리하고 문자·메일을 보내는 것 |
| **온보딩** | 처음 가입한 사람이 제품을 잘 쓰게 안내하는 과정 |
| **바이럴** | 손님이 손님을 데려오는 입소문 |

## D. 기술 기본 (자세한 건 [5장](05-how-websites-work.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **도메인** | 사이트 주소. `myshop.com` |
| ★ **DNS** | 주소(도메인)를 실제 서버 위치(IP)로 바꿔 주는 전화번호부 |
| ★ **서버** | 사이트 파일과 프로그램이 돌아가는, 24시간 켜진 컴퓨터 |
| ★ **호스팅** | 서버를 빌려 쓰는 것 |
| **클라우드** | AWS·구글 클라우드처럼 필요한 만큼 빌리고 쓴 만큼 내는 서버 |
| ★ **DB (데이터베이스)** | 회원·주문·상품 정보를 저장하는 창고 |
| **프론트엔드** | 사용자가 보는 화면 부분 |
| **백엔드** | 보이지 않는 뒤쪽. 로그인 확인, 주문 저장 등 |
| ★ **SSL / HTTPS** | 주소창 자물쇠. 오가는 정보를 암호화 |
| **CDN** | 전국/전 세계 여러 곳에 사진 등을 복사해 두고 가까운 곳에서 빨리 보내 주는 것 |
| **CMS** | 코딩 없이 글·상품을 올리는 관리 프로그램 (워드프레스 등) |
| **쇼핑몰 빌더** | 카페24, 아임웹, 쇼피파이처럼 쇼핑몰을 조립해 만드는 서비스 |
| **PG** | 결제 대행사. 카드 결제를 대신 처리해 주는 회사 (토스페이먼츠 등) |
| **API** | 프로그램끼리 정보를 주고받는 창구 |
| **트래픽** | 사이트에 몰리는 방문량/데이터 양 |

## E. 개발·운영 (자세한 건 [6~9장](06-environments-and-git.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **운영 서버(Production, 프로덕션)** | 진짜 손님이 쓰는 실제 사이트 |
| ★ **스테이징(Staging)** | 운영과 똑같이 꾸민 "리허설 무대". 여기서 먼저 테스트 |
| **개발 환경(Dev / Local)** | 내 컴퓨터에서 고치고 실험하는 곳 |
| ★ **Git / 버전 관리** | 파일의 모든 변경 이력을 저장해서 언제든 예전으로 되돌릴 수 있게 하는 도구 |
| **커밋(Commit)** | "이 시점을 저장" 버튼. 메모와 함께 기록이 남음 |
| **브랜치(Branch)** | 원본을 건드리지 않고 따로 작업하는 갈래 |
| **PR / 코드 리뷰** | "이 변경 합쳐도 될까요?" 하고 다른 사람이 검토하는 것 |
| ★ **배포(Deploy)** | 고친 내용을 실제 사이트에 반영하는 것 |
| ★ **롤백(Rollback)** | 배포했다가 문제가 생기면 이전 버전으로 되돌리는 것 |
| **핫픽스(Hotfix)** | 급한 버그를 바로 고치는 긴급 수정 |
| **CI/CD** | 테스트와 배포를 자동으로 돌려 주는 장치 |
| **릴리스 노트 / 변경 이력** | 이번 업데이트에서 바뀐 점 정리 |
| **기능 플래그(Feature flag)** | 기능을 배포해 두고 스위치로 켜고 끄는 것 |
| **마이그레이션** | DB 구조를 바꾸는 작업 (예: "전화번호" 칸 추가) |
| ★ **백업** | 만일을 위해 데이터를 복사해 다른 곳에 두는 것 |
| ★ **RPO / RTO** | 최대 몇 분치 데이터를 잃어도 되나 / 몇 분 안에 다시 살려야 하나 |
| **스냅샷** | 서버·디스크 전체를 사진 찍듯 통째로 저장한 것 |
| ★ **모니터링** | 사이트가 살아 있는지, 느린지 계속 지켜보는 것 |
| **업타임(Uptime)** | 사이트가 정상 작동한 시간 비율. 99.9% = 한 달에 약 43분 멈춤 허용 |
| ★ **장애(Incident)** | 사이트가 멈추거나 주요 기능이 고장 난 상황 |
| **로그(Log)** | 서버가 남기는 일기장. 언제 누가 무엇을 했는지 기록 |
| **SLA** | "가동률 99.9% 보장, 못 지키면 요금 일부 환불" 같은 서비스 약속 (주로 B2B) |
| **포스트모템** | 장애가 끝난 뒤 원인과 재발 방지책을 정리한 보고서 |

| **랜섬웨어** | 파일을 잠가 놓고 돈을 요구하는 악성 프로그램 (백업이 유일한 해독제인 경우가 많음) |

## G. 커뮤니티·트래픽·게임 (자세한 건 [16~20장](16-community-sites.md))

| 용어 | 쉬운 뜻 |
|---|---|
| **모더레이터(모더)** | 커뮤니티 글을 관리하는 관리자 |
| **1-9-90 법칙** | 1%는 글 쓰고, 9%는 댓글 달고, 90%는 읽기만 한다는 경험칙 |
| **임시조치** | 권리침해 신고가 들어온 글을 최대 30일 동안 가려 두는 것 |
| ★ **PV / UV** | 페이지가 열린 횟수 / 중복 없이 센 방문자 수 |
| ★ **RPM** | 페이지뷰 1,000번당 번 광고 수익 |
| **무효 클릭(부정 클릭)** | 내가 누르거나 누르게 시킨 광고 클릭. 광고 계정 정지 사유 |
| **어필리에이트(제휴)** | 내 링크로 물건이 팔리면 수수료를 받는 것 |
| **E-E-A-T** | 구글이 보는 품질 기준: 경험·전문성·권위·신뢰 |
| **제로 클릭 검색** | 검색 결과(AI 요약 등)만 보고 링크를 누르지 않는 것 |
| **CCU** | 동시 접속자 수 |
| **D1 / D7 / D30 리텐션** | 처음 온 사람이 1일·7일·30일 뒤에도 오는 비율 |
| **레이팅(Elo)** | 이기면 오르고 지면 내려가는 실력 점수 |
| **매칭** | 비슷한 실력의 상대를 자동으로 연결해 주는 것 |
| **웹소켓** | 서버와 화면이 계속 연결돼 있어 실시간으로 주고받는 기술 |
| **치팅** | 게임 부정행위 (AI 프로그램 대신 두기 등) |
| **등급분류** | 게임을 서비스하기 전 받는 이용 연령 등급 |
| **확률형 아이템(가챠)** | 돈 내고 사면 무작위로 결과가 나오는 아이템. 확률 공개 의무 |
| **환전** | 게임머니·포인트를 현금으로 바꾸는 것. 게임에서는 불법 |
| **사행성** | 우연에 돈을 걸어 이익을 노리게 만드는 성질 (도박성) |

## H. 셀러·크리에이터·앱·플랫폼·AI (자세한 건 [22~29장](22-business-map.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **오픈마켓** | 여러 판매자가 입점해 파는 큰 장터 (스마트스토어, 쿠팡 등) |
| **위탁판매** | 재고 없이 상품을 올리고, 주문이 오면 도매처가 직접 배송 |

| **사입** | 도매로 상품을 사서 재고로 두고 파는 것 |
| **PB** | 내 브랜드로 만든 상품 (Private Brand) |
| **통합 관리 솔루션** | 여러 마켓의 상품·주문·재고를 한 화면에서 관리하는 서비스 |
| **크라우드펀딩** | 만들기 전에 먼저 주문(후원)을 받고 생산하는 것 |
| ★ **크리에이터 이코노미** | 개인이 만든 콘텐츠로 팬에게서 돈을 버는 구조 |
| **YPP** | 유튜브 파트너 프로그램. 광고 수익을 나눠 받는 조건 |
| **PPL / 협찬** | 돈을 받고 콘텐츠 안에 제품을 소개하는 것 (광고 표시 의무) |
| **ASO** | 앱스토어 안에서 검색에 잘 뜨게 하기 |
| **단계적 출시** | 새 앱 버전을 일부 사용자부터 순서대로 배포 |
| **CPI** | 앱 설치 1건당 광고비 |
| **PWA** | 웹사이트를 앱처럼 설치해 쓰게 하는 방식 |
| **스코프 크립** | 외주 작업 중 요청이 계속 늘어나는 것 |
| **원천징수 3.3%** | 프리랜서 대금에서 세금을 미리 떼고 주는 것 |
| ★ **O2O** | 온라인에서 예약·결제하고 오프라인 가게에서 서비스 받기 |
| **통신판매중개자** | 판매자와 손님을 연결만 해 주는 온라인 장터 운영자 |
| **탈중개** | 플랫폼에서 만난 뒤 수수료를 피해 밖에서 직거래하는 것 |
| **유동성(플랫폼)** | 손님이 원할 때 공급자가 있는 정도 |

## K. 도메인 이름 (자세한 건 [34장](34-domain-names.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **TLD (최상위 도메인)** | 주소 맨 끝 꼬리. `.com`, `.kr`, `.co.kr` 등 |
| **ccTLD / gTLD** | 나라 도메인(.kr) / 일반 도메인(.com) |
| **서브도메인** | 산 도메인 앞에 붙이는 이름 (`shop.`, `blog.`) |

| **WHOIS** | 도메인 등록자 정보 조회. 개인정보 보호 옵션으로 가릴 수 있음 |

| **TTL** | DNS 정보를 다른 컴퓨터가 기억하는 시간. 바꾼 내용이 퍼지는 속도에 영향 |
| **리디렉트** | 한 주소로 들어오면 다른 주소로 자동 이동 |

| **복구 유예 기간** | 만료된 도메인을 비싼 수수료를 내고 되살릴 수 있는 기간 (약 30일) |
| **도메인 잠금 / 인증 코드** | 무단 이전을 막는 잠금 / 다른 업체로 옮길 때 쓰는 비밀 코드 |
| **사이버스쿼팅** | 남의 상표 도메인을 먼저 사 두고 비싸게 팔려는 행위 |
| **UDRP** | 국제 도메인 분쟁 해결 절차 |

## M. 호스팅·보안·출시 준비 (자세한 건 [36~38장](36-choosing-hosting.md))

| 용어 | 쉬운 뜻 |
|---|---|
| **정적 사이트** | 서버 프로그램·DB 없이 파일만으로 된 사이트 |
| **PaaS** | 코드만 올리면 서버 관리를 대신해 주는 플랫폼 |
| **리전** | 클라우드 데이터센터가 있는 지역 (서울 리전 등) |
| **락인** | 한 업체에 묶여 다른 곳으로 옮기기 어려운 상태 |
| **국외 이전** | 개인정보를 해외로 보내거나 해외에 보관·위탁하는 것 (처리방침 고지 필요할 수 있음) |
| ★ **OWASP Top 10** | 가장 흔하고 위험한 웹 보안 취약점 10가지 목록 |
| **보안 헤더** | 브라우저에 보안 규칙을 알려 주는 설정 (HSTS, CSP 등) |
| **HSTS** | "이 사이트는 항상 HTTPS로만 접속해"라는 규칙 |
| **CSP** | 허락한 곳의 스크립트만 실행하게 하는 규칙 (XSS 방어) |
| **속도 제한(rate limit)** | 짧은 시간에 너무 많은 요청을 막는 장치 |
| **접속기록** | 누가·언제·어디서·무엇을 했는지 남긴 기록 (개인정보 시스템은 보관 의무) |
| ★ **CTA** | "구매하기"처럼 행동을 유도하는 버튼·문구 |
| **스크롤 전 첫 화면(Above the fold)** | 스크롤하지 않고 처음 보이는 화면 영역 |
| **고정 CTA** | 스크롤해도 화면에 붙어 있는 버튼 |
| ★ **title 태그 / meta description** | 검색 결과에 보이는 제목 / 설명 |
| **alt (대체 텍스트)** | 이미지를 글로 설명한 것 (화면 낭독기·검색용) |
| **내부 링크** | 내 사이트 안의 다른 페이지로 가는 링크 |
| ★ **robots.txt** | 검색 로봇에게 수집하지 말 곳을 알려 주는 파일 (숨기기 도구는 아님) |
| **noindex** | "이 페이지를 검색 결과에 넣지 마"라는 태그 |
| **sitemap.xml** | 내 사이트 페이지 목록 파일 |
| **canonical** | 같은 내용의 여러 주소 중 대표 주소 표시 |
| ★ **구조화된 데이터** | 검색 엔진이 내용의 종류(상품·가격 등)를 알게 하는 표시 (JSON-LD) |
| **리치 결과** | 별점·가격 등이 함께 보이는 검색 결과 |
| **소프트 404** | 화면은 "없음"인데 서버는 정상(200)이라고 보내는 실수 |
| ★ **OG 태그 (오픈 그래프)** | SNS·메신저 공유 시 보이는 제목·설명·썸네일 설정 |
| **파비콘** | 브라우저 탭의 작은 아이콘 |
| **핵심 이벤트(GA4)** | GA4에서 구매·문의처럼 중요한 행동 (예전 이름 "전환") |
| ★ **코어 웹 바이탈** | 구글의 사용자 경험 속도 지표: LCP·INP·CLS |
| **접근성** | 장애가 있는 사람도 사이트를 쓸 수 있게 하는 것 |

## N. 결제 연동·게임 서버·어뷰징 (자세한 건 [39~41장](39-payments-and-settlement.md))

| 용어 | 쉬운 뜻 |

| ★ **웹훅** | 상태가 바뀌면 외부 서비스가 내 서버로 자동으로 보내는 알림 |

| ★ **틱 레이트** | 게임 서버가 1초에 세상을 계산하는 횟수 (발로란트 128틱) |
| **클라이언트 예측 / 서버 보정** | 내 입력을 화면에 먼저 반영 / 서버 결과로 다시 맞추기 |
| **엔티티 보간** | 다른 플레이어 위치를 지난 위치 사이로 부드럽게 이어 보여 주기 |

| **롤백 넷코드** | 상대 입력을 예측해 진행하고 틀리면 되감아 다시 계산 (격투 게임) |
| **매치메이킹** | 실력·지역이 비슷한 플레이어를 모아 한 판을 만드는 것 |

## Q. 설계·데이터베이스·API (자세한 건 [58~60장](58-architecture-and-modules.md))

| 용어 | 쉬운 뜻 |

| ★ **응집도 / 결합도** | 한 모듈 안이 같은 일에 모인 정도(높을수록 좋음) / 모듈끼리 엉킨 정도(낮을수록 좋음) |
| **기능별 폴더** | 주문·상품·회원처럼 기능 단위로 폴더를 나누는 방식 |
| **모듈러 모놀리스** | 하나의 프로그램이지만 기능 경계가 분명하게 나뉜 구조 |
| **계층 (입구·규칙·저장)** | 요청 받기(route) → 업무 규칙(service) → 데이터 저장(repository) |
| **어댑터 (감싸기)** | 결제·이메일 같은 외부 서비스를 한 모듈에 감싸 갈아 끼우기 쉽게 하는 것 |
| **ADR** | 설계 결정과 그 이유를 남기는 짧은 문서 |
| **리팩터링** | 동작은 그대로 두고 코드 구조만 개선하는 것 |
| ★ **기본 키 / 외래 키** | 행을 구분하는 값 / 다른 표의 행을 가리키는 값 |
| **정규화** | 같은 정보를 한 곳에만 두도록 표를 나누는 것 |
| **중간 표** | 다 대 다 관계를 연결하는 표 (예: 주문 항목) |
| **인덱스** | 자주 찾는 칸을 빨리 찾게 하는 목록. 쓰기는 조금 느려짐 |
| ★ **마이그레이션** | DB 구조 변경을 번호 붙은 파일로 기록·적용하는 방법 |
| **timestamptz** | PostgreSQL의 시간대 있는 시각 타입 |
| **상태 코드** | API 결과를 알리는 숫자 (2xx 성공, 4xx 요청 문제, 5xx 서버 문제) |
| **RFC 9457** | API 에러 응답 모양의 국제 표준 (application/problem+json) |
| ★ **페이지네이션** | 긴 목록을 나눠서 주는 것 (번호 방식 / 커서 방식) |
| ★ **멱등성 키** | 같은 요청이 여러 번 와도 한 번만 처리되게 붙이는 고유 값 |
| **OpenAPI** | API 설명을 적는 표준 형식. 문서·테스트 자동 생성 |
| **API 버전** | 기존 앱이 깨지지 않게 /v1, /v2로 나누는 것 |

## T. 관문·등록·규칙·개발 도구 (자세한 건 [75~79장](75-desktop-app-code-signing.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **코드 서명** | 프로그램 파일에 찍는 디지털 도장. 누가 만들었는지 + 바뀌지 않았음을 증명 |
| **SmartScreen** | 윈도우가 처음 보는 프로그램에 경고를 띄우는 기능 |
| **OV / IV / EV 인증서** | 회사 확인 / 개인 확인 / 더 엄격한 확인을 거친 코드 서명 인증서 |
| **타임스탬프** | 서명한 시각 기록. 인증서가 만료돼도 서명이 유효하게 해 줌 |
| **오탐** | 정상 프로그램을 백신이 악성으로 잘못 판단하는 것 |
| **공증 (Notarization)** | 애플이 맥 앱을 검사하고 확인해 주는 절차 |
| ★ **비공개 테스트 (12명·14일)** | 구글 플레이 신규 개인 계정이 공개 출시 전에 해야 하는 테스트 |
| **데이터 보안 양식 / 개인정보 라벨** | 앱이 어떤 정보를 수집하는지 스토어에 신고하는 양식 |
| **앱 접근권한 고지** | 카메라·위치 등 접근 전에 필수·선택을 나눠 알리고 동의받는 것 |
| **앱 검증 (OAuth)** | 구글 민감 정보 접근 앱이 받아야 하는 구글 심사 |
| **비즈 앱** | 사업자 정보를 등록한 카카오 디벨로퍼스 앱 |
| **원클릭 수신거부** | 메일에서 한 번 눌러 바로 해지되는 기능 |
| **발신번호 사전 등록** | 문자를 보내기 전에 보내는 번호를 등록하는 제도 |
| ★ **KC 인증** | 전기·생활·어린이 제품 등의 국가 안전 인증 (여러 인증을 합친 이름) |

| **BM 특허** | 기술로 구체화된 영업 방법의 특허 |

| **기업부설연구소** | 인정받은 기업 연구 조직 (세액공제 등) |
| **ISMS / ISMS-P** | 정보보호(·개인정보) 관리체계 인증. 일정 규모 이상은 의무 |
| ★ **다크패턴 6유형** | 숨은 갱신·순차공개 가격·사전 선택·잘못된 계층·취소 방해·반복 간섭 (2025.2 법으로 금지) |
| **숨은 갱신** | 무료 체험을 몰래 유료로, 정기 결제 금액을 몰래 올리는 것 |
| **청약철회 제한 (디지털)** | "철회 불가" 표시 + 미리보기 제공을 했을 때만 가능한 환불 제한 |
| ★ **정규식** | 글자 패턴을 짧은 기호로 적어 찾고 검사하는 방법 |
| ★ **도커 / 이미지 / 컨테이너** | 프로그램을 환경째 담는 도구 / 완성된 상자 / 실행 중인 상자 |
| **잠금 파일** | 설치한 라이브러리 버전을 고정해 두는 파일 (package-lock.json 등) |
| **타이포스쿼팅** | 유명 패키지와 이름이 비슷한 가짜 패키지 |

## U. 최적화와 안정화 (자세한 건 [81장](81-optimization-and-stabilization.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **안정화 기간 (하이퍼케어)** | 출시 직후 새 기능을 멈추고 버그·성능·문의에만 집중하는 기간 |
| **기능 동결** | 정해진 기간 동안 새 기능 배포를 멈추는 것 |
| ★ **SLI / SLO / SLA** | 무엇으로 잴까 / 목표 / 손님과의 약속 |
| ★ **에러 예산** | 100% − 목표 = 실패해도 되는 양. 다 쓰면 기능보다 안정화 |
| **타임아웃** | 정해진 시간 안에 답이 없으면 포기하는 것 |
| **지수 백오프 + 지터** | 재시도 간격을 2배씩 늘리고 무작위로 흩뜨리는 것 |
| **서킷 브레이커 (차단기)** | 연속 실패하면 잠시 그곳을 아예 부르지 않는 장치 |
| **기능 축소 운영** | 일부가 고장 나도 핵심 기능은 살려 두는 것 |
| ★ **카나리 배포** | 새 버전을 일부 손님에게 먼저 내보내고 점점 늘리는 방법 |
| **기능 스위치 (피처 플래그)** | 코드는 배포하되 설정으로 기능을 켜고 끄는 것 |
| **용량 계획** | 몰릴 사람 수를 미리 계산해 대비하는 것 |
| **프로파일러** | 프로그램의 어느 부분이 시간을 쓰는지 보여 주는 도구 |
| **실행 계획 (EXPLAIN)** | DB가 쿼리를 어떻게 실행할지 보여 주는 것 (인덱스 사용 여부) |
| ★ **N+1 쿼리** | 목록 1번 + 항목마다 1번씩 DB를 부르는 실수 |
| **상태 확인 주소 (헬스 체크)** | 서버가 살아 있는지 확인하는 주소 (예: /health) |
| **안전한 종료** | 끌 때 진행 중인 요청을 마치고 종료하는 것 |

## V. AI 코드 보안 점검 (자세한 건 [82장](82-ai-code-security-review.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **SAST (정적 분석)** | 코드를 실행하지 않고 읽어서 위험한 패턴을 찾는 검사 |
| **DAST (동적 검사)** | 실행 중인 사이트를 밖에서 실제로 찔러 보는 검사 |
| ★ **IDOR** | 번호만 바꾸면 남의 데이터가 보이는 취약점 (권한 확인 누락) |
| **CSRF** | 다른 사이트가 사용자 몰래 내 사이트로 요청을 보내게 하는 공격 |
| **CSP (콘텐츠 보안 정책)** | 브라우저에게 어떤 스크립트·스타일만 허용할지 알려 주는 헤더 |

| **가짜 경보 (false positive)** | 문제가 아닌데 문제라고 보고하는 것 |
| **CWE** | 소프트웨어 약점 종류에 붙인 번호 목록 |
| **Gitleaks / Semgrep / Trivy / ZAP** | 비밀 키 검사 / 코드 패턴 검사 / 의존성·이미지 검사 / 실제 공격 검사 오픈소스 |
| **CodeShield** | AI가 생성한 코드를 실시간으로 검사하는 메타의 오픈소스 |
| **보안 회귀 테스트** | 고친 취약점이 다시 생기지 않는지 확인하는 테스트 |

## W. 보안 전체 지도·사고 사례 (자세한 건 [83장](83-security-map-all-layers.md)·[84장](84-security-incident-cases.md))

## X. 프록시·동적 딜레이·브라우저 자동화 (자세한 건 [85장](85-proxy-delay-browser-automation.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **프록시** | 요청을 대신 전달해 주는 중간 서버 |
| **포워드 / 리버스 프록시** | 요청하는 쪽 편(회사 게이트웨이) / 서비스 쪽 편(내 서버 앞단, 클라우드플레어 등) |
| **주거용 프록시** | 일반 가정의 인터넷 주소를 빌려 쓰는 프록시. 동의 없이 모은 기기인 경우가 많아 위험 |
| ★ **동적 딜레이** | 상대 반응(429·응답 속도)을 보고 요청 간격을 스스로 늘리거나 줄이는 것 |

| ★ **브라우저 자동화** | 프로그램이 진짜 브라우저를 열어 클릭·입력을 대신하는 것 (Playwright 등) |

| **E2E 테스트** | 손님처럼 처음부터 끝까지 이용해 보는 자동 테스트 |
| **합성 모니터링** | 정해진 손님 경로를 주기적으로 자동 실행해 고장을 찾는 감시 |
| **봇 관리** | 좋은 봇은 허용하고 나쁜 봇은 막는 기능 (리버스 프록시·WAF) |

## Y. 인터넷 동작 원리 (자세한 건 [86장](86-internet-fundamentals.md))

| 용어 | 쉬운 뜻 |
|---|---|
| ★ **IP 주소 (IPv4·IPv6)** | 인터넷의 집 주소. IPv4는 부족, IPv6는 사실상 무한 |
| **공인 / 사설 주소** | 인터넷에서 닿는 주소 / 집·회사 안에서만 쓰는 주소 |
| ★ **NAT / CGNAT** | 여러 기기·가입자가 공인 주소 하나를 나눠 쓰게 하는 것 (통신사 단위는 CGNAT) |
| **루프백 (127.0.0.1)** | 내 컴퓨터 자신을 가리키는 주소 |
| **TTL (DNS)** | DNS 결과를 기억해 두는 시간 |
| ★ **포트** | 한 컴퓨터 안의 문 번호 (443 = HTTPS) |
| **TCP / UDP** | 연결하고 순서·완전성 보장 / 연결 없이 빠르게 보냄 |
| **QUIC (HTTP/3)** | UDP 위에서 동작하는 빠른 웹 연결 방식 |
| ★ **TLS·인증서** | HTTPS의 암호화와 "진짜 그 사이트" 확인 |
| **SNI** | HTTPS 연결 초기에 보내는 사이트 이름 (암호화 전이라 보임) |
| **TLS 가로채기** | 믿도록 설정된 인증서로 프록시가 HTTPS를 풀어 검사하는 것 |
| **CONNECT 터널** | 포워드 프록시에게 "이 주소까지 길을 뚫어 줘"라고 하는 요청 |
| ★ **X-Forwarded-For** | 프록시가 붙여 주는 원래 손님 IP (믿는 프록시가 붙인 것만 신뢰) |
| **헤더** | 요청·응답에 붙는 추가 정보 줄들 |
| ★ **쿠키 (HttpOnly·Secure·SameSite)** | 서버가 손님을 기억하게 하는 기억표와 그 안전 설정 |
| **제3자 쿠키** | 방문한 사이트가 아닌 다른 회사의 쿠키 (사이트 간 추적) |
| ★ **ETag·304** | 내용의 버전 표시 / "안 바뀌었으니 갖고 있는 거 써" |
| **Cache-Control** | 얼마나·어디에 저장해도 되는지 정하는 헤더 (private·no-store) |
| ★ **같은 출처 정책·CORS** | 다른 사이트 데이터를 브라우저가 막는 규칙 / 그걸 허락하는 헤더 (서버 보안 아님) |
| **DOM** | 브라우저가 HTML로 만든 화면 구조 |
| **SSR / SPA** | 서버가 완성된 화면을 보냄 / 브라우저가 자바스크립트로 화면을 채움 |
| **브라우저 지문** | 여러 정보를 합쳐 같은 기기인지 추정하는 것 |
| **지연 시간(RTT) / 대역폭** | 갔다 오는 시간 / 한 번에 보낼 수 있는 양 |
