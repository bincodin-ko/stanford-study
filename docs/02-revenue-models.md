# 02. 돈 버는 방법 — 수익 모델

**수익 모델** = "어떤 방식으로 돈이 들어오는가". 사업 유형(1장)과 짝을 이룹니다.

---

## 1. 대표 수익 모델 8가지

| 모델 | 어떻게 버나 | 예 | 장점 | 단점 |
|---|---|---|---|---|
| **판매(커머스)** | 물건을 팔고 차익을 남김 | 쇼핑몰 | 이해하기 쉬움 | 재고·배송 부담 |
| **구독** | 매달/매년 정기 결제 | 넷플릭스, SaaS | 매달 수입이 예측됨 | 해지(이탈)를 계속 막아야 함 |
| **프리미엄(Freemium)** | 기본은 무료, 고급 기능은 유료 | 노션, 캔바 | 사용자를 빨리 모음 | 무료 사용자 대부분은 돈을 안 냄 |
| **수수료(중개)** | 거래가 일어나면 몇 % 떼어 감 | 배달앱, 에어비앤비 | 내 재고가 없음 | 판매자·구매자 양쪽 모으기 어려움 |
| **광고** | 방문자에게 광고를 보여 주고 광고주에게 받음 | 블로그, 뉴스, 유튜브 | 사용자는 무료 | 방문자가 아주 많아야 의미 있음 |
| **라이선스/사용량 과금** | 쓴 만큼 냄 | 클라우드 서버, 문자 발송 API | 큰 손님일수록 많이 냄 | 매달 수입이 들쭉날쭉 |
| **리드 판매** | 관심 고객 정보를 업체에 소개하고 대가를 받음 | 보험·이사 비교 사이트 | 상품을 직접 안 다룸 | 개인정보 동의 관리가 까다로움 |
| **제휴 마케팅(어필리에이트)** | 내 링크로 남이 사면 일정 % 받음 | 쿠팡 파트너스, 리뷰 블로그 | 시작이 쉬움 | 수익률 낮고 "광고 표시" 의무 |

> **API** = 프로그램끼리 대화하는 창구. "문자 보내 줘"라고 요청하면 대신 보내 주는 식.
> **리드(Lead)** = "관심을 보인 잠재 고객"의 연락처.

## 2. 가격을 정하는 방법

| 방법 | 설명 | 예 |
|---|---|---|
| **원가 기반** | 원가 + 내가 남길 이익 | 원가 7천 원 → 1만 원 |
| **경쟁 기반** | 비슷한 상품 가격을 보고 맞춤 | 경쟁사 9,900원 → 9,500원 |
| **가치 기반** | 손님이 얻는 이익을 보고 정함 | "월 50만 원 아껴 주니까 월 5만 원" |
| **단계형(티어)** | 베이직 / 프로 / 엔터프라이즈 | SaaS에서 거의 표준 |
| **좌석제(Per seat)** | 사용자 1명당 얼마 | B2B 협업툴 |

> **엔터프라이즈(Enterprise)** = 대기업용 최상위 요금제. 가격표 대신 "문의하기" 버튼이 있는 경우가 많아요.

## 3. 꼭 알아야 할 "남는 돈" 계산

매출이 커도 **남는 돈**이 없으면 망합니다. 이 4가지는 꼭 구분하세요.

```
매출(Revenue)          손님에게 받은 돈 전부
 − 매출원가(COGS)       상품 원가, 결제 수수료, 서버비처럼 "팔 때마다 드는 돈"
 = 매출총이익(Gross Profit)
 − 판매관리비(SG&A)     광고비, 인건비, 사무실, 각종 툴 구독료
 = 영업이익(Operating Profit)   ← 사업 자체로 번 돈
```

**예시: 1만 원짜리 간식 1개를 팔면**

| 항목 | 금액 |
|---|---|
| 판매가 | 10,000원 |
| 재료·포장 | −3,500원 |
| 택배비 | −3,000원 |
| 결제 수수료(약 3% 가정) | −300원 |
| **1개당 남는 돈(공헌이익)** | **3,200원** |

→ 광고비로 손님 1명 데려오는 데 5,000원이 든다면, **첫 구매만으로는 손해**입니다.
그래서 "재구매"와 "객단가(1회 결제 금액) 올리기"가 중요해져요. (자세한 건 [11장](11-growth-and-data.md))

> **공헌이익** = 1개 팔 때마다 실제로 남는 돈. 이게 마이너스면 많이 팔수록 더 손해.

---

## 4. 모델별로 "가장 중요한 숫자"

| 모델 | 제일 먼저 보는 숫자 |
|---|---|
| 쇼핑몰 | 전환율, 객단가, 재구매율 |
| 구독/SaaS | MRR(월 반복 매출), 이탈률(Churn) |
| 플랫폼 | GMV(총 거래액), 수수료율(Take rate) |
| 광고 | 방문자 수, 페이지뷰, 광고 단가 |

이 단어들은 [3장 용어 사전](03-glossary.md)에서 하나씩 설명합니다.

---

### 이 장 요약
1. 수익 모델은 판매·구독·수수료·광고가 4대장.
2. 매출이 아니라 **1개 팔 때 남는 돈**부터 계산한다.
3. 모델마다 매일 지켜볼 숫자가 다르다.
