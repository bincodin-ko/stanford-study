# 29. 허가·신고가 필요한 업종 지도

인터넷 사업은 대부분 **사업자등록 + 통신판매업 신고**(10장)로 시작할 수 있어요.
하지만 일부 분야는 **추가 허가·등록·신고가 없으면 시작 자체가 불법**이고, 일부 상품은 **온라인 판매가 금지·제한**돼 있어요.

> ⚠️ 이 장은 "이런 분야는 따로 확인해야 한다"는 **지도**예요. 구체적인 요건은 업종·사업 구조마다 다르고 자주 바뀌니, 시작 전에 **관계 기관·변호사·세무사**에게 꼭 확인하세요. (2026년 10월 조사 기준)

---

## 1. 신호등으로 보는 규제 강도

| 신호 | 의미 | 예 |
|---|---|---|
| 🟢 | 사업자등록 + 통신판매업 신고 정도면 시작 가능 | 일반 의류·잡화 쇼핑몰, 정보 블로그, 디지털 템플릿 |
| 🟡 | **추가 신고·등록**이 필요 | 건강기능식품 판매, 유료 직업소개, 위치 기반 서비스, 게임 등급분류 |
| 🔴 | **허가·라이선스**가 필요하거나 진입이 매우 어려움 | 결제·송금(전자금융), 투자자문, 가상자산 거래, 의료 |
| ⛔ | **온라인 판매 자체가 금지·제한** | 의약품, 담배, 주류(일부 예외), 도수 있는 콘택트렌즈 |

---

## 2. 분야별 지도

### 💰 금융·결제·투자
| 사업 | 왜 조심? |
|---|---|
| **결제 대행·송금·선불 충전금(포인트를 현금처럼)** | 전자금융거래법상 등록 대상일 수 있음. 직접 하지 말고 **PG사를 이용**하는 게 일반적 (10장) |
| **주식·코인 "종목 추천" 유료 서비스** | 유사투자자문업은 금융당국 **신고** 대상이고, 2024년 법 개정으로 단톡방처럼 **양방향 소통**하며 하는 투자 조언(일명 리딩방)은 **투자자문업 등록** 없이 못 하도록 바뀌었다고 알려져 있어요 |
| **가상자산(코인) 거래·보관** | 특정금융정보법상 신고, 높은 보안 요건. 개인이 시작하기 매우 어려움 |
| **대출 중개·비교** | 대출 모집·중개 관련 등록 규제 |
| **보험 비교·추천** | 보험 모집 규제 |

### 🏥 건강·의료
| 사업 | 왜 조심? |
|---|---|
| **건강기능식품 판매** | **건강기능식품 판매업 영업 신고** 필요. "질병 치료·예방" 같은 효능 광고 금지 |
| **의료기기 판매** | 의료기기 판매업 신고 (종류에 따라) |
| **병원 예약·후기 플랫폼** | 의료법상 의료 광고 규제, 환자 소개·알선 금지 |
| **비대면 진료·처방 연결** | 별도 제도·시범사업 기준에 따라야 함 |
| **식품 판매 (직접 만든 음식)** | 식품 제조·가공업 등 **영업 신고**, 위생 기준 |

### ⛔ 온라인 판매가 금지·제한되는 대표 상품
| 상품 | 내용 (요약) |
|---|---|
| **의약품** | 약국에서만 판매하도록 정해져 있어 일반 의약품도 온라인 판매가 원칙적으로 금지 (약사법) |
| **담배** | 담배 소매인의 온라인(전자거래)·우편 판매가 금지되는 것으로 알려져 있음 (담배사업법) |
| **주류** | 원칙적으로 통신판매 제한. **전통주** 등 일부 예외, 온라인 주문 후 매장 수령(스마트오더) 같은 방식만 허용되는 식 |
| **도수 있는 콘택트렌즈** | 안경사가 안경업소에서만 판매 |
| **총포·도검·화약류, 동물 등** | 별도 허가·제한 |

> 쿠팡·스마트스토어 같은 마켓도 자체 **판매 불가 목록**을 운영해요(23장). 법보다 더 엄격한 경우도 있어요.

### 🎓 교육
| 사업 | 왜 조심? |
|---|---|
| 학생 대상 교습, 학원 형태 운영 | 학원법상 **학원·교습소 등록** 대상일 수 있음 |
| 원격 평생교육 | 형태에 따라 신고 |
| 자격증 발급 | **민간자격 등록** 없이 "자격증"을 발급하면 문제 |

### 🤝 사람을 연결하는 사업 (27장)
| 사업 | 확인할 법 |
|---|---|
| 유료 직업소개 | 직업안정법 (등록) |
| 직업 정보 게시 | 직업안정법 (신고) |
| 결혼 중개 | 결혼중개업법 (신고·등록) |
| 부동산 중개 | 공인중개사법 — **자격 있는 중개사**만 중개 가능 |
| 여행 상품 판매 | 관광진흥법 — 여행업 등록 |
| 위치 정보 사용 | 위치정보법 — 신고 |

### 🎮 콘텐츠·게임
| 사업 | 확인할 법 |
|---|---|
| 게임 서비스 | 게임산업진흥법 — 등급분류, 환전 금지, 확률 공개 (20장) |
| 성인 콘텐츠 | 청소년 보호 — 성인 인증, 유해 표시 |
| 도박·베팅 | **사실상 불법** (19·20장) |

### 🤖 AI·데이터
| 사업 | 확인할 법 |
|---|---|
| AI 서비스 | AI 기본법 — 생성물 표시, 고영향 AI 의무 (28장) |
| 대량 개인정보 처리 | 개인정보보호법 — 규모에 따른 추가 의무 (10장) |
| 커뮤니티·SNS 대형화 | 불법촬영물 유통 방지 조치 (16장) |

## 3. 새 사업을 시작하기 전 확인 순서

```
1. 내가 파는 것이 "판매 금지·제한 상품"인가?        → 위 ⛔ 표
2. 돈을 맡거나 보내는가? 투자·대출·보험 조언인가?     → 💰 금융
3. 건강·의료·식품과 관련 있는가?                   → 🏥
4. 사람을 소개하고 돈을 받는가?                    → 🤝
5. 학생을 가르치거나 자격증을 주는가?                → 🎓
6. 게임·도박성·성인 요소가 있는가?                  → 🎮
7. AI 생성물을 제공하거나 개인정보를 많이 다루는가?     → 🤖
```
하나라도 "예"라면 → **정부24에서 업종 이름으로 인허가 검색**, 관계 부처·지자체 문의, 또는 전문가 상담.

> 💡 "다른 사람도 하던데요?"는 이유가 되지 않아요. 앞 장에서 본 로또 예측 사이트, 무등록 직업소개, 리딩방처럼 **많이 보이는 사업 중에도 처벌 사례가 많은 분야**가 있습니다.

---

### 이 장 요약
1. 대부분은 🟢이지만, **금융·의료·식품·사람 소개·교육·게임·AI** 분야는 추가 신고·허가를 확인한다.
2. **의약품·담배·주류(일부 예외)·도수 렌즈**는 온라인 판매가 금지·제한된다.
3. 시작 전 **7가지 질문**으로 점검하고, 애매하면 관계 기관·전문가에게 묻는다.
