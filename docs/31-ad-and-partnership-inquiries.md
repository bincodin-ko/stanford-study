# 31. 광고·제휴 문의 받기

사이트에 사람이 모이면 **"광고하고 싶어요", "협찬할게요", "제휴합시다"** 같은 연락이 오기 시작해요.
반대로, 처음에는 **내가 먼저 광고주를 찾아가야** 하는 경우가 더 많아요. 이 장은 광고 문의를 **받는 준비**, **가격 정하기**, **계약과 진행**, **거절해야 할 제안 거르기**를 다룹니다.

> 광고 네트워크(애드센스 등)로 자동으로 광고를 붙이는 방법은 [18장](18-traffic-monetization.md)에 있어요. 이 장은 **광고주와 직접 거래하는 광고(직접 광고·협찬)** 이야기예요.

---

## 1. 광고·제휴 문의의 종류

| 종류 | 예 | 주로 오는 분야 |
|---|---|---|
| **배너 광고** | 사이트 상단·옆에 일정 기간 배너 | 정보 사이트, 커뮤니티, 게임 사이트 |
| **협찬 콘텐츠(브랜디드 콘텐츠)** | 제품 리뷰 글·영상, 소개 글 | 블로그, 크리에이터, 뉴스레터 |
| **뉴스레터 광고** | 메일 본문 중간에 광고 한 칸 | 뉴스레터 |
| **제휴(어필리에이트)** | 판매 수수료 계약 | 리뷰·비교 사이트 |
| **이벤트·공동구매** | 회원 대상 할인 판매 | 커뮤니티, 쇼핑몰 |
| **입점·노출 광고** | 플랫폼 안 상단 노출 | 예약·중개 플랫폼, 오픈마켓 |
| **B2B 제휴** | 서비스 연동, 공동 마케팅 | SaaS, AI 서비스 |
| **스폰서** | 대회·행사 후원 | 게임, 커뮤니티 |

---

## 2. 광고 문의를 받기 위한 준비물

### ① "광고 문의" 페이지 + 전용 주소
- 사이트 하단 메뉴에 **"광고·제휴 문의"** 링크 → 광고 문의 페이지
- 전용 주소 `ads@` 또는 `partnership@` (30장)
- 문의 폼에서 받을 것: 회사명, 담당자, 연락처, 광고할 제품, **희망 기간·예산**, 원하는 광고 상품

### ② 미디어킷 (광고 소개서)
**미디어킷** = "우리 사이트에 광고하면 이런 사람들에게 이렇게 보입니다"를 정리한 1~5쪽짜리 소개서(PDF나 웹페이지).

| 들어갈 내용 | 예 |
|---|---|
| 우리 사이트 한 줄 소개 | "2030 직장인을 위한 재테크 계산기 사이트" |
| **방문자 숫자** | 월 방문자(UV), 페이지뷰(PV), 구독자 수 — **분석 도구 기준, 기간 명시** (11장) |
| **방문자 특징** | 연령대·성별·관심사·지역 (분석 도구가 추정하는 범위에서) |
| 광고 상품과 위치 | 메인 상단 배너, 글 중간 배너, 뉴스레터 광고, 리뷰 콘텐츠 |
| **가격표** (또는 "문의") | 상품별 단가, 기간 |
| 지난 광고 사례 | 클릭 수, 반응 (광고주 동의를 받은 것만) |
| 광고 원칙 | "광고 표시를 합니다", "받지 않는 업종" |
| 연락처 | `ads@…` |

> ⚠️ **숫자를 부풀리지 마세요.** 광고주는 결과를 확인해요. 부풀린 숫자는 재계약 실패 → 평판 하락으로 돌아와요.

## 3. 광고 가격 정하는 법

| 방식 | 뜻 | 어울리는 곳 |
|---|---|---|
| **기간 고정** | "메인 배너 1주 ○○만 원" | 작은 사이트, 가장 단순 |
| **CPM** | 노출 1,000번당 가격 | 방문자가 많은 사이트 |
| **CPC** | 클릭 1번당 가격 | 클릭 추적이 가능할 때 |
| **CPA / 수수료** | 구매·가입 1건당 가격 | 제휴 마케팅 (18장) |
| **건당 고정** | "리뷰 글 1편 ○○만 원" | 블로그, 크리에이터, 뉴스레터 |

### 가격 감 잡기 (계산 연습용 예시)
```
월 페이지뷰 30만, 메인 배너가 전체 노출의 50%를 차지한다고 가정
→ 한 달 배너 노출 15만 번
→ CPM 3,000원으로 판다면: 150,000 ÷ 1,000 × 3,000 = 45만 원/월
```
- 비교 기준: 지금 붙어 있는 **광고 네트워크 수익(RPM, 18장)보다는 높아야** 직접 광고를 할 이유가 있어요.
- 주제가 좁고 독자가 확실할수록(예: "치과 개원 준비 정보") 같은 방문자 수라도 **더 비싸게** 팔 수 있어요.

## 4. 광고 진행 순서

```
1. 문의 접수 (폼·메일)
2. 광고주 확인 — 회사가 실제로 있나? 우리 원칙에 맞는 업종인가? (5절)
3. 상품·가격·기간 제안 (미디어킷 전달)
4. 협의 → 견적서 → 계약서 또는 확인 메일
5. 결제 — 선불이 기본. 사업자라면 세금계산서 발행
6. 광고 소재(배너 이미지·원고) 받기 → 검수 (과장 광고·금지 표현 확인)
7. 게재 — "광고"·"협찬" 표시
8. 결과 보고 — 노출 수, 클릭 수, 기간
9. 끝나면 내리고, 재계약 제안
```

### 계약서·확인 메일에 넣을 것
| 항목 | 예 |
|---|---|
| 광고 상품·위치·크기 | 메인 상단 배너 728×90 |
| 기간 | 2026-11-01 ~ 11-14 |
| 금액·결제 시기 | 선불, 세금계산서 발행 |
| 소재 제공 마감 | 게재 3일 전까지 |
| 수정 횟수 | 원고 수정 1회 |
| 결과 보고 방식 | 종료 후 노출·클릭 수 공유 |
| 게재 거절·중단 조건 | 법 위반, 허위 내용 발견 시 |
| 광고 표시 | "광고" 또는 "협찬" 표시함에 동의 |

## 5. 거절해야 할 광고 — 이것만은 받지 않는다

| 거절 | 이유 | 관련 장 |
|---|---|---|
| **불법 도박·토토·카지노** | 형사 처벌 위험, 정상 광고 네트워크도 끊김 | 19장 |
| **성인·불법 촬영물 관련** | 청소년 보호, 사이트 차단 | 16장 |
| **"수익 보장" 투자·코인·리딩방** | 유사투자자문·사기 연루 위험 | 29장 |
| **의약품·불법 건강식품 효능 광고** | 약사법·건강기능식품 광고 규제 | 29장 |
| **로또 번호 예측 유료 서비스** | 사기 연루 위험 | 19장 |
| **"광고 표시 없이 해 달라"** 는 요청 | 뒷광고 → 표시광고법 문제 | 18·24장 |
| **사이트를 통째로 팔라 / 글 몰래 끼워 넣기(백링크 판매)** | 검색 스팸 정책 위반 → 검색에서 사라짐 | 17장 |
| **첨부 파일부터 열어 보라는 협찬 제안** | 계정 탈취 악성 프로그램 수법 | 24·30장 |

### 수상한 광고 제안 구별법
- 회사 이름·사업자등록번호·홈페이지가 **확인되지 않는다**
- 메신저(텔레그램 등)로만 연락하자고 한다
- 시세보다 **터무니없이 높은 금액**을 제시한다
- 광고 내용을 미리 보여 주지 않거나, 링크만 바꿔 달라고 한다
- "선입금해 주면 더 큰 계약을 주겠다" (역으로 내 돈을 노리는 사기)

> 💡 **광고 원칙을 미디어킷에 미리 적어 두세요.** ("도박·성인·투자 수익 보장·의약품 광고는 받지 않습니다.") 이상한 문의가 확 줄고, 거절할 때도 편해요.

## 6. 광고 표시 — 독자의 신뢰를 지키는 법

| 형태 | 표시 예 |
|---|---|
| 배너 | 배너 옆 작은 글씨 "광고" |
| 협찬 글 | 글 **맨 위**에 "이 글은 ○○로부터 제품(원고료)을 제공받아 작성했습니다." |
| 영상 | 유튜브 "유료 광고 포함" 설정 + 영상 앞부분에 말·자막으로 (24장) |
| 뉴스레터 | 광고 칸에 "[광고]" 또는 "스폰서" |
| 제휴 링크 | "이 링크로 구매하면 수수료를 받습니다" (18장) |

> 표시광고법 관련 지침은 독자가 **쉽게 알아볼 수 있는 위치와 크기**로 표시하라고 해요. "더보기"를 눌러야 보이거나, 글 맨 끝 작은 글씨는 문제가 될 수 있어요.

## 7. 분야별 광고·제휴 문의 받는 법

| 분야 | 광고 문의 받는 곳 | 잘 팔리는 광고 상품 |
|---|---|---|
| 정보 사이트·블로그 (17장) | 하단 "광고 문의" + 미디어킷 | 리뷰 콘텐츠, 글 안 배너, 제휴 |
| 커뮤니티 (16장) | 운영자 문의 → 광고 페이지 | 배너, 이벤트·공동구매, 공지 협찬 (회원 반발 주의) |
| 트래픽 사이트 (18장) | 광고 네트워크 + 직접 광고 페이지 | CPM 배너 |
| 로또·운세 정보 (19장) | 광고 문의 폼 | 일반 소비재 배너 (**도박 관련은 거절**) |
| 게임 (20장) | 공식 이메일, 디스코드 운영자 | 대회 스폰서, 게임 안 브랜드 아이템 |
| 크리에이터 (24장) | 채널 정보의 **비즈니스 이메일**, 인플루언서 매칭 플랫폼 | 협찬 영상, PPL, 공동구매 |
| 뉴스레터 | 구독 페이지 하단 "스폰서 문의" | 메일 속 광고 칸 |
| 앱 (25장) | 앱 안 광고 네트워크 + 홈페이지 문의 | 보상형 광고, 제휴 이벤트 |
| 중개 플랫폼 (27장) | 판매자·가게 전용 "광고 센터" | 상단 노출, 추천 배지 (광고 표시 필수) |
| SaaS·AI (12·28장) | "파트너 문의" 폼 | 연동 제휴, 공동 웨비나, 추천 수수료 |

## 8. 내가 먼저 광고주를 찾아가는 법 (처음엔 이게 더 흔해요)

1. 내 독자가 **이미 쓰고 있는 제품** 목록 만들기
2. 그 회사의 마케팅 담당 연락처 찾기 (홈페이지의 "제휴 문의")
3. **짧은 제안 메일**: 우리 사이트 한 줄 소개 + 숫자 + 제안 상품 + 미디어킷 링크
4. 첫 광고는 **할인이나 시범 집행**으로 결과를 만들고, 그 결과를 다음 영업에 활용
5. 인플루언서·광고 매칭 플랫폼에 등록해 두기

### 제안 메일 예
```
제목: [제휴 제안] 2030 직장인 재테크 계산기 '머니계산' 광고 제안드립니다

안녕하세요, '머니계산' 운영자 ○○○입니다.
저희는 연봉 실수령액·대출 이자 계산기를 운영하며
월 방문자 약 8만 명(2026년 9월, GA4 기준)이 이용하고 있습니다.

귀사의 가계부 앱이 저희 독자층과 잘 맞을 것 같아
"계산 결과 아래 추천 칸" 2주 시범 광고를 제안드립니다.
상세 내용은 첨부 미디어킷(링크)을 참고해 주세요.

감사합니다.
○○○ 드림 | ads@moneycalc.kr
```
(사이트 이름과 숫자는 예시예요.)

> ⚠️ 이런 **영업 메일도 광고성 정보**로 볼 수 있어요. 받는 회사의 **공개된 제휴·마케팅 문의 창구**로, 한 번만 정중하게 보내고, 거절 의사에는 다시 보내지 않기. 수집한 이메일 주소로 대량 발송하는 건 금지예요 (30장).

---

### 이 장 요약
1. 광고를 받으려면 **광고 문의 페이지 + 전용 주소 + 미디어킷**을 준비한다.
2. 가격은 **기간 고정·CPM·건당** 중에서 고르고, 광고 네트워크 수익보다 높게. 진행은 **확인 → 계약 → 선불 → 검수 → 표시 → 결과 보고**.
3. **도박·성인·수익 보장·의약품·뒷광고·백링크·수상한 첨부 파일**은 거절. 광고 원칙을 미리 공개한다.
