# 76. 플랫폼 관문 — 앱스토어·확장 프로그램·스팀·로그인·메일·문자의 등록과 심사

> PC 설치 프로그램의 코드 서명은 [75장](75-desktop-app-code-signing.md), 앱 마켓 수수료·업데이트는 [25장](25-mobile-apps.md), 로그인 구현은 [65장](65-auth-and-accounts.md)에 있어요.

내 서비스가 **다른 회사의 플랫폼을 거쳐** 손님에게 갈 때는, 그 회사의 **등록·심사·인증**을 통과해야 해요. 미리 모르면 출시 직전에 몇 주씩 막혀요.

> ⚠️ 플랫폼 정책은 자주 바뀌어요. 2026년 11월 조사 기준이고, 상당수는 개발자 블로그·커뮤니티 정리예요. 각 회사의 공식 개발자 문서를 꼭 확인하세요. ([참고 자료 모음](sources.md))

---

## 한눈에 보기 — 출시 전에 걸리는 관문

| 관문 | 언제 | 미리 안 하면 | 걸리는 시간 (대략) |
|---|---|---|---|
| 구글 플레이 **비공개 테스트 12명·14일** | 개인 계정으로 안드로이드 앱 첫 출시 | 출시 버튼이 안 열림 | **최소 2주 + 심사** |
| 애플·구글 **앱 심사** | 앱 출시·업데이트마다 | 거절 → 수정 → 재심사 | 몇 시간~며칠 |
| 앱 **계정 삭제 기능** | 회원가입이 있는 앱 | 심사 거절 | 개발 며칠 |
| 앱 **접근권한 고지** | 카메라·위치·연락처 등을 쓰는 앱 | 법 위반, 심사 문제 | 화면 하나 |
| **크롬 웹스토어** 등록 | 브라우저 확장 프로그램 | 배포 불가 | 등록 + 심사 |
| **스팀** 출시 | PC 게임 | 출시 불가 | 등록 후 약 30일 + 심사 |
| **구글 로그인 앱 검증** | 구글 계정의 민감한 정보(드라이브·지메일 등) 접근 | "확인되지 않은 앱" 경고, 신규 100명 제한 | 몇 주~몇 달 |
| **카카오 로그인 비즈 앱** | 카카오 로그인으로 이메일 등을 받을 때 | 원하는 정보를 못 받음 | 사업자 등록 + 검수 |
| **Gmail 대량 발송 요건** | 하루 약 5,000통 이상 메일 | 스팸함·차단 | 설정 하루 |
| **문자 발신번호 사전 등록** | 시스템으로 문자 발송 | 발송 차단 | 영업일 1~2일 |
| **카카오 알림톡 템플릿 심사** | 알림톡 발송 | 발송 불가 | 며칠 (64장) |
| **PG 가맹 심사** | 카드 결제 | 결제 불가 | 1~2주 이상 (39장) |
| **애드센스 승인** | 광고 수익 | 광고 안 나옴 | 며칠~몇 주 (18장) |
| **코드 서명** | PC 설치 프로그램 | 바이러스 경고 (75장) | 인증서 발급 며칠~몇 주 |

> 💡 진행표(제품 기획 문서)에서 **출시 6~8주 전**에 이 표를 한 번 보는 스텝을 꼭 넣으세요.

## 1. 모바일 앱 스토어

### 개발자 계정
| 스토어 | 비용 (조사 기준) | 메모 |
|---|---|---|
| **구글 플레이** | 등록비 25달러 (한 번) | 개인 / 조직 계정 구분. 신원 확인 절차 있음 |
| **애플 앱스토어** | 연회비 (애플 공식 페이지 확인) | 개인 / 조직. 조직은 D-U-N-S 번호 등 추가 서류 |

### 구글 플레이 — 신규 개인 계정의 "12명·14일 규칙"
- **2023년 11월 13일 이후 만든 개인 개발자 계정**은 앱을 공개 출시하기 전에 **비공개 테스트**를 해야 해요.
- 기준(개발자 블로그 정리, 구글 공식 도움말 확인 필요): **테스터 12명 이상이 14일 동안 계속 참여**. 처음엔 20명이었다가 2024년 말 12명으로 줄었다고 해요.
- **조직 계정은 이 규칙이 없어요.** 사업자(특히 법인)라면 조직 계정을 검토하세요.
- 내부 테스트는 인원 제한이 없지만 **이 조건에는 포함되지 않아요.**
- 현실 팁: 출시 일정에 **최소 3주**를 더 잡고, 테스터는 지인·소프트 런칭 대상(13장)으로 미리 모아 두세요. 테스터를 돈 받고 모아 주는 서비스도 있지만, 실제로 써 보는 사람이어야 의미가 있어요.

### 회원가입이 있으면 계정 삭제 기능 필수
| 스토어 | 요구 |
|---|---|
| **애플** (심사 지침 5.1.1(v)) | 앱 안에서 회원이 **계정 삭제를 시작**할 수 있어야 함 (2022년 6월 30일부터) |
| **구글** (사용자 데이터 정책) | 앱 안 삭제 + **앱을 지운 사람도 요청할 수 있는 웹 페이지 주소**를 데이터 보안 양식에 등록 |

→ 65장 회원 탈퇴 기능을 **처음부터** 만들어 두세요.

### 개인정보 관련 제출물
- **개인정보처리방침 주소** (두 스토어 모두 필수, 10장)
- 구글 **데이터 보안(Data safety) 양식**, 애플 **앱 개인정보 라벨**: 어떤 정보를 수집·공유하는지 표시. 광고·분석 SDK가 가져가는 정보까지 포함돼요.
- 애플: 다른 앱·웹사이트에 걸친 **추적**(맞춤 광고 등)을 하려면 앱 추적 투명성(ATT) 허용 창으로 동의를 받아야 해요(61장 iOS 추적 제한과 연결).

### 앱 접근권한 고지 (한국 법)
- 정보통신망법(22조의2)에 따라, 스마트폰의 카메라·사진·위치·연락처 등에 접근하려면 **필수 권한과 선택 권한을 나눠** 항목과 이유를 알리고 동의를 받아야 해요.
- **선택 권한을 거부해도 서비스를 막으면 안 돼요.**
- 흔한 위반: 필요 없는 권한(연락처·문자)까지 요청, 선택 권한을 필수로 표시.
- 실무: 앱을 처음 켤 때 **권한 안내 화면** → 실제로 그 기능을 쓸 때 운영체제 권한 창.

### 심사에서 자주 거절되는 이유 (일반적인 경향)
- 앱이 **충돌**하거나 미완성 (빈 화면, "준비 중")
- 로그인이 필요한데 **심사용 계정**을 안 줌
- 개인정보처리방침 없음·내용 부실, 계정 삭제 없음
- 디지털 상품을 **스토어 결제 없이** 판매 (25장 — 국가·상품별 예외 규정 확인)
- 웹사이트를 그냥 감싸기만 한 앱 (앱다운 기능이 없음)
- 설명·스크린샷이 실제 앱과 다름

## 2. 브라우저 확장 프로그램 — 크롬 웹스토어

- **개발자 등록비 5달러**(한 번)를 내야 대시보드를 쓸 수 있어요(2020년 도입, 금액은 구글 재량으로 바뀔 수 있음).
- 올릴 때마다 **심사**가 있어요. 요청하는 권한이 넓을수록(모든 사이트 읽기 등) 심사가 길고 까다로워요 → **필요한 권한만**.
- 개인정보처리방침, 수집 데이터 공개가 필요해요.
- 확장 프로그램은 손님 브라우저 안에서 돌아서 **신뢰가 생명**이에요. 업데이트로 몰래 기능을 바꾸면 정책 위반·삭제 대상이에요.

## 3. PC 게임 — 스팀

- **스팀 다이렉트 등록비: 게임 1개당 100달러.** 환불은 안 되지만, 그 게임의 조정 총매출이 **1,000달러를 넘으면 다음 정산 때 돌려받아요**(스팀웍스 공식 문서).
- 처음 등록하면 **출시 가능해질 때까지 약 30일**의 대기·준비 기간이 있고, 스토어 페이지·빌드 **심사**를 거쳐요(가이드 글 기준).
- 출시 전에 **"찜하기(위시리스트)"를 모으는 기간**이 중요해요 → 스토어 페이지는 출시 몇 달 전에 미리 공개하는 게 일반적이에요.
- 한국에서 서비스하려면 **게임물 등급분류**(20장)도 확인하세요.
- 정산은 달러로 들어와요 → 해외 수익 세금·환전(52·71장).

## 4. 로그인 연동 심사

### 구글 로그인 / 구글 API
- **이름·이메일 정도의 기본 로그인**은 비교적 간단해요.
- 구글 드라이브·지메일·캘린더처럼 **민감하거나 제한된 정보(scope)**에 접근하면 **앱 검증**을 받아야 해요(구글 클라우드 도움말).
  - 검증 전에는 손님에게 **"Google에서 확인하지 않은 앱"** 경고가 뜨고, 경고 이후 **신규 사용자 100명**까지만 쓸 수 있어요.
  - 준비물: **개인정보처리방침 주소**, 서치 콘솔에서 **내 웹사이트 소유 확인**(38장).
  - 정보 종류에 따라 검증에 **몇 주~몇 달**, 제한된 정보는 보안 평가까지 필요할 수 있어요.
- 팁: **꼭 필요한 권한만** 요청하면 검증이 쉬워져요.

### 카카오 로그인 (카카오 디벨로퍼스)
- 기본 앱으로는 받을 수 있는 정보가 제한돼요. **이메일 등 개인정보 동의 항목**을 쓰려면 앱에 **사업자 정보를 등록해 "비즈 앱"**으로 전환해야 한다는 안내가 많아요(커뮤니티 답변 기준).
- 사업자 번호가 없는 **개인 개발자용 비즈 앱**도 있지만, 받을 수 있는 항목이 제한적이에요(예: 이메일까지).
- 전화번호·이름 같은 항목은 **검수**를 거쳐야 하고, 심사는 **내 서비스의 일반 회원가입에서 받는 항목**을 기준으로 해요 → 일반 가입에서 안 받는 정보를 카카오로만 받으려 하면 반려될 수 있어요.
- "필수 동의"로 설정하면 동의하지 않은 사람은 로그인을 못 해요 → 꼭 필요한 것만 필수로.
- 네이버 로그인도 비슷하게 **검수**가 있어요. 출시 전에 일정에 넣으세요.

## 5. 메일·문자를 대량으로 보낼 때

### Gmail·야후 대량 발송 요건 (2024년 2월부터)
하루에 Gmail 주소로 **약 5,000통 이상** 보내면 "대량 발송자"로 보고 아래를 요구해요.

| 요건 | 내용 |
|---|---|
| **SPF·DKIM 통과 + DMARC 기록** | 30장. 보내는 주소의 도메인과 맞아야 함 |
| **원클릭 수신거부** | 광고 메일 헤더에 원클릭 해지 기능, 요청은 **2일 안에** 처리 |
| **스팸 신고율** | **0.3% 미만** 유지, 권장은 0.1% 미만 (구글 포스트마스터 도구로 확인) |

- 주문 확인 같은 **거래 메일은 원클릭 수신거부 대상이 아니에요.** 하지만 인증은 똑같이 필요해요.
- 5,000통이 안 돼도 **같은 기준으로 맞춰 두는 게** 도착률에 좋아요(64장).

### 문자(SMS) 발신번호 사전 등록제
- 전기통신사업법에 따라, 시스템으로 문자를 보내려면 **보내는 번호를 미리 등록**해야 해요. 등록 안 된 번호는 **발송이 막혀요.**
- 문자 발송 서비스에 가입해 번호를 등록하고, **통신사 가입증명원 + 사업자등록증**(명의에 따라 재직증명서·위임장) 등을 내요. 승인은 보통 영업일 1~2일이라고 안내돼요.
- 2026년에는 문자 발송 사업자 쪽 등록 요건이 강화되고 **새 식별코드·전송자격인증** 제도가 적용됐다는 안내가 있어요. 내가 쓰는 문자 발송 서비스의 공지를 확인하세요.
- 광고 문자는 별도로 30장 규칙((광고) 표시, 수신거부, 야간 동의).

## 6. 출시 일정에 넣는 법 (예: 안드로이드 앱 + 카카오 로그인 + 결제)

```
출시 8주 전  PG 가맹 신청 (39장), 카카오 비즈 앱 전환·검수 신청
출시 6주 전  구글 플레이 개발자 계정, 문자 발신번호 등록, 알림톡 템플릿 심사
출시 5주 전  비공개 테스트 시작 (테스터 12명 이상, 14일)
출시 2주 전  스토어 등록 정보·스크린샷·데이터 보안 양식·처리방침 주소
출시 1주 전  프로덕션 심사 제출
출시일      심사 통과 확인 후 공개
```

> 💡 Claude에게: "내 서비스는 [안드로이드 앱 / 카카오 로그인 / 문자 인증 / 카드 결제]를 써. 출시 전에 통과해야 하는 외부 등록·심사를 표로 만들고, 각각 필요한 서류와 걸리는 기간, 출시일 기준 시작해야 할 날짜를 알려 줘. 최신 정책은 공식 문서 링크로 확인하라고 표시해 줘."

---

### 이 장 요약
1. 플랫폼마다 **등록·심사·검증**이 있고, 미리 모르면 출시가 몇 주 늦어진다. **출시 6~8주 전**에 관문 표를 확인.
2. 안드로이드 **개인 계정은 12명·14일 비공개 테스트**, 회원가입 앱은 **계정 삭제 기능**, 권한은 **필수·선택 구분 고지**.
3. 구글 로그인 **민감 정보는 앱 검증**, 카카오 이메일 등은 **비즈 앱·검수**, 대량 메일은 **인증·원클릭 해지·스팸률 0.3% 미만**, 문자는 **발신번호 사전 등록**.
