# 70. 사람 쓰기 — 알바·직원·프리랜서의 노무 기본

> 외주 계약과 공동 창업은 [53장](53-outsourcing-and-team.md), 인건비 세금 기본은 [44장](44-money-accounting-entity.md)에 있어요. 이 장은 **처음으로 사람을 쓸 때** 꼭 알아야 할 규칙이에요.

> ⚠️ 노동법은 사업장 규모(5인 미만/이상)와 고용 형태에 따라 적용이 달라지고, 금액과 요율은 매년 바뀌어요. 이 장의 2026년 숫자는 **블로그·안내 사이트 기준**이에요. 실제로 채용할 때는 고용노동부·4대보험 공단 안내를 확인하고, 애매하면 **노무사 상담**을 받으세요. ([참고 자료 모음](sources.md))

---

## 1. 어떤 형태로 쓸까

| 형태 | 특징 | 사장님 의무 |
|---|---|---|
| **직원(정규·계약직)** | 정해진 시간·장소에서 지시받아 일함 | 근로계약서, 최저임금, 4대보험, 주휴·연차, 퇴직금(1년 이상), 원천세 |
| **단시간 근로자(알바)** | 직원과 같은 근로자, 시간만 짧음 | 위와 같음 (주 15시간 미만이면 일부 예외) |
| **프리랜서(사업소득)** | 결과물로 계약, 일하는 방식은 본인이 정함 | **3.3% 원천징수** 신고 (44장) |
| **외주 업체** | 사업자끼리 계약 | 세금계산서, 계약서 (53장) |

> ⚠️ **"프리랜서 계약서를 썼다"고 프리랜서가 되는 게 아니에요.** 출퇴근 시간을 정하고, 업무를 매일 지시하고, 다른 일을 못 하게 하면 **실제로는 근로자**로 판단될 수 있어요(위장 프리랜서). 그러면 주휴·퇴직금·4대보험을 소급해서 줘야 할 수 있어요.

---

## 2. 근로계약서 — 일 시작 전에, 써서, 주기

- **일을 시작하기 전에** 쓰고, **한 부를 직원에게 줘야** 해요. 써 두고 안 주는 것도 위반이에요.
- 안내 자료들이 공통으로 꼽는 **꼭 들어갈 항목**:

| 항목 | 예 |
|---|---|
| 임금 (구성·계산·지급 방법·지급일) | 시급 10,320원, 매월 10일 계좌 입금 |
| 소정근로시간 | 월·수·금 10:00~15:00 (휴게 30분) |
| 주휴일 | 매주 일요일 |
| 연차 유급휴가 | 법에 따름 |
| 근무 장소·업무 내용 | 본점, 포장·출고 |
| 계약 기간 (기간제라면) | 2026.11.1 ~ 2027.4.30 |

- 안 쓰면 근로기준법상 **벌금**(일반 근로자), 기간제·단시간 근로자는 **과태료**가 각각 있을 수 있어요(금액은 자료마다 달라 확인 필요).
- 블로그 안내 기준, **5인 미만 사업장도 근로계약서 작성·교부 의무는 적용**돼요. (5인 미만에는 해고 제한·연장근로 가산수당 등 일부 조항이 적용되지 않아요.)
- 고용노동부 **표준근로계약서 양식**을 쓰면 빠뜨리지 않아요.
- 최저임금이 오르면 **계약서의 임금도 고쳐** 다시 쓰기.

## 3. 2026년 최저임금과 주휴수당

- **2026년 최저시급: 10,320원** (2026.1.1~12.31)
- **주휴수당**: 주 소정근로시간이 **15시간 이상**이고 그 주를 다 나오면, 하루치 임금을 더 줘요. 주 40시간이면 8시간분, 주 20시간이면 4시간분.

```python
MIN_WAGE_2026 = 10_320          # 2026년 최저시급 (원)

def monthly_wage(hourly, weekly_hours):
    if weekly_hours >= 15:                       # 주 15시간 이상이면 주휴수당
        paid_holiday = weekly_hours / 40 * 8     # 주 40시간이면 8시간, 20시간이면 4시간
    else:
        paid_holiday = 0
    hours_per_month = (weekly_hours + paid_holiday) * 365 / 7 / 12   # 한 달 평균 약 4.345주
    return round(hours_per_month), round(hourly * round(hours_per_month))

for h in [40, 20, 14]:
    hours, pay = monthly_wage(MIN_WAGE_2026, h)
    print(f"주 {h}시간: 월 {hours}시간 → 최저 월급 {pay:,}원")
```

실행 결과 (직접 돌려 확인했어요):
```
주 40시간: 월 209시간 → 최저 월급 2,156,880원
주 20시간: 월 104시간 → 최저 월급 1,073,280원
주 14시간: 월 61시간 → 최저 월급 629,520원
```
- 주 40시간 결과(209시간, 2,156,880원)는 안내 자료들의 2026년 최저 월급과 같아요.
- ⚠️ 주휴 계산은 **"주 15시간을 넘기지 않게" 쪼개는 꼼수**로 쓰면 안 돼요. 그리고 실제 근무가 15시간을 넘으면 주휴수당이 생겨요.
- 수습 기간 감액, 야간·휴일·연장 가산수당(5인 이상)은 따로 확인하세요.

## 4. 4대보험 — 사장님이 실제로 내는 돈

직원을 **1명이라도** 쓰면 4대보험(국민연금·건강보험·고용보험·산재보험)에 가입해야 해요(짧은 근무 등 일부 예외는 공단 확인). 월급에서 직원 몫을 떼고, **사장님 몫을 더해서** 내요.

2026년 요율 (조사 기준):
| 보험 | 전체 | 직원 | 사장님 |
|---|---|---|---|
| 국민연금 | 9.5% | 4.75% | 4.75% |
| 건강보험 | 7.19% | 절반 | 절반 |
| 장기요양 | 건강보험료의 13.14% | 절반 | 절반 |
| 고용보험 | — | 0.9% | 0.9% + 회사 규모별 추가분 |
| 산재보험 | 업종마다 다름 | 없음 | **전액** |

```python
# 2026년 요율 (조사 기준, 공단 고시로 꼭 다시 확인)
PENSION = 0.0475           # 국민연금 9.5%의 절반씩
HEALTH = 0.0719 / 2        # 건강보험 7.19%의 절반씩
CARE_OF_HEALTH = 0.1314    # 장기요양 = 건강보험료의 13.14%
JOB_WORKER = 0.009         # 고용보험 근로자 몫
JOB_EMPLOYER = 0.009 + 0.0025   # 사업주 몫 (150명 미만 회사 예시)
ACCIDENT = 0.01            # 산재보험: 업종마다 다름 (여기선 1%로 가정)

def burden(pay):
    health = pay * HEALTH
    common = pay * PENSION + health + health * CARE_OF_HEALTH
    worker = common + pay * JOB_WORKER
    employer = common + pay * (JOB_EMPLOYER + ACCIDENT)
    return round(worker), round(employer)

pay = 2_156_880            # 2026년 최저 월급 (주 40시간)
w, e = burden(pay)
print(f"월급 {pay:,}원")
print(f"직원 월급에서 빠지는 4대보험: 약 {w:,}원")
print(f"사장님이 따로 내는 4대보험: 약 {e:,}원")
print(f"사장님의 한 달 인건비: 약 {pay + e:,}원 (퇴직금 적립 별도)")
```

실행 결과 (직접 돌려 확인했어요):
```
월급 2,156,880원
직원 월급에서 빠지는 4대보험: 약 209,592원
사장님이 따로 내는 4대보험: 약 236,553원
사장님의 한 달 인건비: 약 2,393,433원 (퇴직금 적립 별도)
```
- **월급 외에 약 10% 이상이 더 든다**고 생각하세요. 1년 이상 일하면 **퇴직금**(대략 1년에 한 달치)도 쌓아 둬야 해요.
- 소득세(원천세)도 매달 떼서 신고해요. 세무사나 급여 프로그램을 쓰면 편해요.
- 소규모 사업장의 보험료 일부를 지원하는 정부 사업(예: 두루누리 등)이 있었어요. 올해 조건은 공단에서 확인하세요(45장 지원금).

## 6. 1인 사업자가 첫 사람을 쓸 때의 현실 팁

- 처음엔 **짧은 시간 알바나 프리랜서**로 시작해 일의 양을 확인하세요. 단, 실제 일하는 방식이 형태와 맞아야 해요(1절).
- 사람을 쓰면 **사장님의 일이 "일하기"에서 "가르치고 확인하기"로** 바뀌어요. 매뉴얼이 없으면 오히려 더 바빠져요.
- 인건비는 **고정비**예요. 3개월치 인건비를 버틸 현금이 있는지 확인하세요(44장 현금 흐름).
- 지인·가족을 쓸 때도 **똑같이 계약서와 4대보험**. 관계가 틀어졌을 때 가장 크게 문제가 돼요.

---

### 이 장 요약
1. 형태보다 **실제 일하는 방식**이 근로자인지 결정한다. 근로자면 **일 시작 전 근로계약서 작성·교부**(5인 미만도).
2. 2026년 최저시급 **10,320원**, 주 15시간 이상이면 **주휴수당**, 주 40시간 최저 월급 **2,156,880원**.
3. 4대보험 사장님 몫을 더하면 **월급의 약 10% 이상 추가** + 퇴직금. 채용 전에 **매뉴얼·현금·자동화 가능성**부터 확인.
