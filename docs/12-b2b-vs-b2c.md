# 12. B2B vs B2C — 운영이 어떻게 다른가

같은 "인터넷 사업"이어도 **기업 상대(B2B)** 와 **개인 상대(B2C)** 는 거의 다른 직업이라고 할 만큼 운영 방식이 달라요.

---

## 1. 한눈에 비교

| 항목 | B2C (개인 손님) | B2B (기업 손님) |
|---|---|---|
| 손님 수 | 많음 (수천~수백만) | 적음 (수십~수천) |
| 1건 금액 | 작음 (수천~수만 원) | 큼 (수십만~수억 원) |
| 사는 데 걸리는 시간 | 몇 초~며칠 | **몇 주~몇 달** |
| 누가 결정하나 | 본인 혼자 | 여러 명 (사용자, 팀장, 구매팀, 보안팀, 대표) |
| 결정 이유 | 감정, 디자인, 가격, 후기 | **업무 효율, 비용 절감, 안정성, 보안** |
| 결제 | 카드 즉시 결제 | **세금계산서, 계좌이체, 월말 정산, 연간 계약** |
| 마케팅 | SNS 광고, 인플루언서, 이벤트 | 콘텐츠(사례·백서), 세미나, **영업 사원**, 소개 |
| 고객 응대 | 많은 문의를 빠르게 (FAQ, 챗봇) | 담당자 배정, **전담 매니저** |
| 약속 | 이용약관 | **계약서, SLA, 보안 서약** |
| 잃으면 | 손님 1명 (작은 손실) | 큰 고객 1곳 (매출 큰 비중) |

---

## 2. B2C 운영의 핵심

1. **많이 데려오기**: 광고 효율(ROAS, CAC)이 생명.
2. **빨리 사게 만들기**: 결제 단계 줄이기, 간편결제(카카오페이·네이버페이·토스페이).
3. **다시 오게 만들기**: 적립금, 회원 등급, 알림, 정기 배송.
4. **CS 대량 처리**: FAQ, 답변 템플릿, 챗봇.
5. **트래픽 폭주 대비**: 이벤트·방송 노출 때 사이트가 멈추지 않게 미리 서버 여유 확보.
6. **리뷰 관리**: 후기 한 줄이 매출을 좌우.

## 3. B2B 운영의 핵심

1. **영업 단계(파이프라인) 관리**
   ```
   리드(관심) → 미팅 → 데모(시연) → 제안서·견적 → 무료 체험(PoC) → 계약 → 온보딩
   ```
   > **PoC** = Proof of Concept. "우리 회사에서도 정말 되는지" 짧게 시험해 보는 것.
2. **계약과 서류**: 견적서, 계약서, 세금계산서, 보안 점검 질문지 대응.
3. **SLA(서비스 약속)**: "월 가동률 99.9%", "1급 장애는 1시간 안에 대응" 같은 약속을 지켜야 함 → [9장](09-operations.md) 모니터링·장애 대응이 훨씬 엄격해짐.
4. **온보딩**: 계약 후 고객사가 실제로 잘 쓰게 만드는 단계. 여기서 실패하면 1년 뒤 재계약이 안 됩니다.
5. **고객 성공(Customer Success)**: 고객사가 성과를 내도록 계속 챙기는 팀/역할. 업셀(더 비싼 요금제), 재계약을 책임.
6. **업데이트 공지**: 고객사 업무가 내 서비스에 의존하므로, **변경을 미리 알리고**(릴리스 노트), 큰 변경은 일정 기간 이전 방식도 유지.
7. **권한·보안 기능**: 관리자/일반 사용자 권한, 로그인 기록, SSO(회사 계정으로 로그인) 같은 기능을 요구받음.

---

## 4. 업데이트·관리 방식의 차이

| 항목 | B2C | B2B |
|---|---|---|
| 배포 빈도 | 자주 (매일~매주) | 자주 하되 **큰 변경은 예고** |
| 실험 | A/B 테스트 적극적 | 고객사별로 다르게 켜는 **기능 플래그** 많이 사용 |
| 점검 시간 | 새벽 | **고객사 업무 시간 밖** (해외 고객이면 시차 고려) |
| 장애 보고 | 공지사항 | 고객사 담당자에게 **직접 보고 + 사후 보고서** |
| 데이터 백업 | 서비스 전체 기준 | 고객사별 **데이터 내보내기·삭제 요청** 대응도 필요 |

---

## 5. 섞인 형태들

- **B2B2C**(배달앱): 가게(B)를 위한 관리 도구 + 손님(C)을 위한 주문 앱을 **둘 다** 운영 → 두 종류의 CS, 두 종류의 마케팅.
- **프로슈머 SaaS**(노션·캔바): 개인이 무료로 쓰다가 → 회사 전체가 유료 도입. B2C처럼 퍼뜨리고 B2B처럼 판다. (**PLG**, Product-Led Growth: 제품이 스스로 영업하는 방식)

---

### 이 장 요약
1. B2C = **많이, 빠르게, 감정·후기**. B2B = **적게, 천천히, 신뢰·계약**.
2. B2B는 **SLA·온보딩·고객 성공**이 운영의 중심.
3. 업데이트도 B2B는 **미리 알리고, 고객별로 조절**한다.
