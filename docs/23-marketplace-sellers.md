# 23. 오픈마켓 셀러 · 위탁판매 · 구매대행

내 쇼핑몰을 만드는 대신 **이미 손님이 모여 있는 큰 장터**(오픈마켓)에 입점해서 파는 방식이에요.
한국에서 1인 온라인 판매를 시작하는 가장 흔한 방법입니다.

> ⚠️ 수수료·정책·세금 기준은 자주 바뀝니다. 2026년 10월 조사 기준이며, 각 마켓의 **판매자 센터 공지**와 국세청 안내를 꼭 확인하세요.

---

## 1. 자사몰 vs 오픈마켓

| 항목 | 자사몰 (13장) | 오픈마켓 (네이버 스마트스토어, 쿠팡, 11번가, G마켓 등) |
|---|---|---|
| 손님 모으기 | **내가** 광고해서 데려와야 함 | 마켓에 **이미 손님이 있음** |
| 수수료 | PG 수수료 정도 | 판매 수수료 + 결제 수수료 (카테고리마다 다름) |
| 디자인 자유 | 높음 | 낮음 (정해진 상품 페이지 틀) |
| 고객 정보 | 내 것 (재구매 마케팅 가능) | 마켓 것 (직접 연락 제한) |
| 가격 경쟁 | 덜함 | **치열** (같은 상품을 여러 판매자가 팖) |
| 정책 위험 | 낮음 | 마켓 정책·검색 순위 규칙이 바뀌면 매출 급변 |

> 💡 흔한 성장 경로: **오픈마켓에서 시작 → 잘 팔리는 상품·단골이 생기면 자사몰을 같이 운영**(손님을 내 것으로).

---

## 2. 판매 방식 4가지

| 방식 | 재고 | 어떻게 | 장점 | 단점·주의 |
|---|---|---|---|---|
| **사입 판매** | 있음 | 도매로 사서 내가 보관·발송 | 마진 관리, 빠른 배송 | 재고 위험, 창고·포장 |
| **위탁판매(배송대행)** | 없음 | 도매 사이트 상품을 내 마켓에 올리고, 주문 오면 도매처가 손님에게 직접 발송 | 시작 비용 거의 0 | 마진 낮음, 품절·배송 지연을 내가 책임, **같은 상품 판매자 수천 명** |
| **해외구매대행** | 없음 | 해외 쇼핑몰 상품을 손님 대신 사서 보내 줌 | 국내에 없는 상품 | 통관, 긴 배송, 반품 어려움, 제품 안전 문제 |
| **제조·브랜드(PB)** | 있음 | 공장에 맡겨 내 브랜드로 생산 | 경쟁 적음, 높은 마진 | 초기 비용, 재고 위험이 가장 큼 |

### 구매대행 세금 포인트
- 구매대행은 보통 **상품 가격 전체가 아니라 "대행 수수료"를 매출로** 보는 구조라고 안내돼요. 예) 손님이 1만 원 냄, 상품값+배송비 8,000원 → 내 매출은 수수료 2,000원.
- 대신 국세청은 쇼핑몰 전체 판매액을 기준으로 보고 있어서 **"정말 수수료만 남았다"는 증빙(해외 결제 내역, 배송 내역)** 을 보관해야 해요.
- 개인 해외직구에는 **면세 한도**(일반적으로 미화 150달러, 미국발 일부는 200달러)가 있지만, 기준이 바뀌는 논의가 있으니 관세청 안내를 확인하세요.
- 전기용품·어린이용품 등은 **KC 인증(안전 인증)** 문제가 생길 수 있는 대표 품목이에요. 2024년 정부가 KC 미인증 해외 직구 금지를 발표했다가 철회한 일이 있을 만큼 민감한 분야입니다.

## 3. 오픈마켓 운영의 핵심

### ① 상품 등록 = 검색 최적화
마켓 안에도 검색이 있어요. **마켓 안의 SEO**가 매출을 정합니다.
- **상품명**: 손님이 검색할 단어로. 예) "무설탕 수제 그래놀라 500g 아침대용"
- **대표 이미지**: 흰 배경, 상품이 크게 (마켓마다 규칙 있음)
- **카테고리·속성** 정확히 입력
- **리뷰 수와 평점**, 판매량, 배송 속도가 순위에 영향

### ② 가격 계산 — 수수료를 빼고 남는가?
```
판매가                          20,000원
− 마켓 수수료 (예: 10% 가정)      −2,000원
− 상품 원가                     −9,000원
− 택배비                        −3,000원
− 포장비                          −500원
− 광고비 (1개당 평균)             −2,000원
= 1개당 남는 돈                  3,500원
```
→ 수수료율은 **마켓·카테고리마다 다르니** 판매자 센터의 수수료표로 꼭 확인. (2장의 공헌이익 계산과 같은 원리)

### ③ 마켓 광고
- 마켓 내 검색 광고(키워드 광고). **ROAS**(광고비 1원당 매출)를 매일 확인 (3·11장).
- 처음엔 작게, 잘 팔리는 키워드에만 예산 늘리기.

### ④ 배송·CS 지표 관리
마켓은 판매자를 점수로 평가해요.
- **발송 기한 지키기** (늦으면 페널티)
- 문의 답변 시간
- 취소·반품 비율
→ 점수가 낮으면 노출이 줄거나 판매가 제한될 수 있어요.

### ⑤ 여러 마켓 동시 운영
- 스마트스토어 + 쿠팡 + 자사몰처럼 여러 곳에서 팔면 **재고가 꼬여요**(한쪽에서 팔렸는데 다른 쪽에서 또 팔림).
- 해결: **통합 관리 솔루션**(여러 마켓의 상품·주문·재고를 한 화면에서 관리하는 서비스) 사용.

## 4. 셀러가 자주 겪는 문제와 대응

| 문제 | 대응 |
|---|---|
| **상표권 침해 신고** (남의 브랜드 이름·로고 사용) | 정품 판매라도 상표 사용에 주의. 짝퉁은 절대 금지 |
| **상품 이미지 도용** | 내가 찍은 사진 사용. 도매처 이미지는 사용 허락 확인 |
| **허위·과장 광고** ("암 예방", "살 빠지는") | 식품·화장품은 효능 표현 규제가 강함 |
| **판매 금지 상품** | 의약품, 주류, 담배 등은 온라인 판매가 금지·제한 (29장) |
| **위탁판매 품절** | 주문 후 품절 → 취소 페널티. 재고 연동되는 도매처 선택 |
| **정산 지연** | 마켓마다 정산 주기가 다름 → 현금 흐름 계획 |

## 5. 크라우드펀딩 (와디즈 등)

- 상품을 **만들기 전에** 펀딩 페이지로 미리 주문(후원)을 받고, 모인 돈으로 생산해서 보내 주는 방식.
- 장점: 재고 위험 없이 **수요를 먼저 확인**, 초기 자금 확보.
- 주의: **약속한 날짜에 못 보내거나 품질이 다르면** 신뢰가 무너지고 분쟁이 생겨요. 생산 일정을 넉넉하게.

---

### 이 장 요약
1. 오픈마켓은 **손님이 이미 있는 대신 수수료·경쟁·정책 위험**이 있다.
2. 위탁판매·구매대행은 재고 없이 시작할 수 있지만 **마진이 낮고 책임은 판매자**에게 있다.
3. 핵심은 **마켓 안 검색 최적화 + 수수료 뺀 마진 계산 + 배송·CS 점수 관리**.
