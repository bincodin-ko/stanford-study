# 13. 실전 시뮬레이션 — 작은 쇼핑몰 0일차 → 1년차

앞에서 배운 걸 **한 사업에 다 적용**해 봅니다.

> **가상 사업**: "그래놀라랩" — 무설탕 수제 그래놀라를 파는 1인 온라인 쇼핑몰 (B2C, 자사몰, 실물 상품)

---

## 0단계. 준비 (출시 4~8주 전)

| 할 일 | 관련 장 | 결과물 |
|---|---|---|
| 손님 정의: "아침을 거르는 30대 직장인, 성분 꼼꼼히 봄" | 4장 | 페르소나 1장 |
| 1개 팔 때 남는 돈 계산 | 2장 | 판매가 12,900원 / 공헌이익 약 4,000원 |
| 사업자등록 (간이과세 검토) | 10장 | 사업자등록증 |
| 쇼핑몰 빌더 선택 (예: 아임웹/카페24 중 하나) | 4·5장 | 계정, 도메인 `granolalab.co.kr` (**내 명의, 자동 갱신 ON**) |
| PG 신청 + 구매안전서비스 | 10장 | 결제 연동 |
| 통신판매업 신고 (면제 여부 구청 확인) | 10장 | 신고번호 |
| 약관·개인정보처리방침 작성 | 10장 | 사이트 하단 게시 |
| 계정 목록 문서 만들기 + 모든 관리자 계정 2FA | 9·10장 | `운영문서/계정목록` |

## 1단계. 만들기 (출시 2~4주 전)

- MVP 기능만: 상품 3종, 장바구니, 결제, 주문 조회, FAQ.
- 화면: 모바일 먼저. 상세 페이지에 성분표·후기를 위쪽에.
- **테스트 스킨(복사본)** 에서 디자인 작업 → 확인 후 적용. *(6장: 운영을 직접 고치지 않는다)*
- 상품 사진 원본은 내 PC + 클라우드 드라이브 2곳에 보관. *(8장)*

## 2단계. 출시 전 점검 (출시 1주 전)

- [출시 전 체크리스트](14-checklists.md#1-출시-전-체크리스트) 전부 확인.
- 아이폰·안드로이드·PC에서 실제 카드로 결제 → 환불까지 해 보기.
- 모니터링 가입: 5분마다 사이트 확인, 안 되면 휴대폰 알림. *(9장)*
- GA4·네이버 서치어드바이저 등록. *(11장)*

## 3단계. 소프트 런칭 (1주차)

- 지인 30명에게만 공개 + 할인 쿠폰.
- 문의·불편 사항을 전부 메모 → "결제 버튼이 화면 아래에 가려져요" 같은 문제 발견.
- 고친 내용은 변경 이력에 기록: `2026-11-03 v1.0.1 모바일 결제 버튼 위치 수정`.

## 4단계. 정식 런칭 (2~4주차)

- 인스타그램 광고 하루 2만 원으로 시작, 링크에 **UTM** 붙이기.
- 매일 아침 10분 루틴: 주문 확인 → 문의 답변 → 어제 매출·광고비 보기. *(9장)*
- 1주 결과 예시:

| 지표 | 값 | 판단 |
|---|---|---|
| 방문자 | 2,000 | |
| 전환율 | 1.0% | 낮음 → 상세 페이지 개선 필요 |
| 주문 | 20건 | |
| 광고비 | 14만 원 | |
| CAC | 7,000원 | 공헌이익 4,000원보다 큼 → **첫 구매만으론 적자** |

→ **대응**: ① A/B 테스트로 상세 페이지 개선(후기 상단 배치), ② "2봉 세트" 상품으로 객단가 올리기, ③ 재구매 쿠폰 문자(수신 동의자만). *(11장)*

## 5단계. 첫 업데이트 (2개월차) — "정기 배송" 기능 추가

```
1. 기획: 정기 배송 원하는 문의 40건 → Should 기능으로 승격
2. 백업: 회원·주문 목록 엑셀 내보내기, 현재 디자인 스킨 복사
3. 테스트 스킨에서 정기 배송 상품 페이지 제작
4. 직접 정기 결제 테스트 (테스트 모드)
5. 화요일 오전 10시 적용 (주문 가장 적은 시간)
6. 적용 후 30분간 주문·결제 확인
7. 공지사항 + 기존 손님에게 안내 문자 (수신 동의자만)
```
*(7장의 표준 배포 절차 그대로)*

## 6단계. 첫 장애 (4개월차)

- 상황: 일요일 밤, 모니터링 알림은 없는데 **4시간째 주문 0건**.
- 확인해 보니 PG사 쪽 설정 변경으로 **카드 결제만 실패**.
- 대응: 공지 배너 "카드 결제 일시 장애, 간편결제 이용 부탁드립니다" → PG 고객센터 연락 → 복구.
- 포스트모템 → **재발 방지**: "2시간 동안 주문 0건이면 알림" 감시 추가. *(9장)*

## 7단계. 정기 관리 (매달 / 분기)

- 매달: 도메인·카드 만료일 확인, 월 손익 정리, 안 쓰는 관리자 계정 정리.
- 분기: **복구 훈련** — 내보낸 엑셀로 상품·회원 데이터가 제대로 살아나는지 확인. 비밀번호 교체. *(8장)*

## 8단계. 1년차 — 성장의 갈림길

| 선택지 | 고려할 점 |
|---|---|
| 오픈마켓 입점 (쿠팡·스마트스토어) | 판매 채널 확대 vs 수수료 |
| 카페·회사에 납품 (**B2B 추가**) | 세금계산서, 대량 견적, 정기 계약 *(12장)* |
| 직접 개발 사이트로 이전 | 자유도 ↑, 하지만 백업·배포·보안을 전부 내가 *(6~8장)* |
| 직원 채용 | 운영 매뉴얼·권한 관리 필요 *(9·10장)* |

---

## 정리: 1년 동안 실제로 반복한 것

```
기획 → 백업 → 테스트 환경에서 수정 → 확인 → 배포 → 감시 → 숫자 보기 → 다시 기획
```

이 고리를 **안전하게, 자주** 돌리는 것이 인터넷 사업 운영의 전부라고 해도 과언이 아닙니다.
