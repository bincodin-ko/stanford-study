# 04. 기초 ①: 변수 · 조건 · 반복 · 함수

모든 프로그래밍 언어에는 **4가지 뼈대**가 있어요. 이 4개만 알아도 간단한 프로그램은 다 만들 수 있습니다.

| 뼈대 | 하는 일 | 비유 |
|---|---|---|
| **변수** | 값을 저장 | 이름표 붙은 상자 |
| **조건문** | 상황에 따라 다르게 | 갈림길 |
| **반복문** | 같은 일 여러 번 | 빙글빙글 도는 컨베이어 |
| **함수** | 일을 묶어서 이름 붙이기 | 레시피 카드 |

예제는 **파이썬**이에요. `#` 뒤는 **주석**(사람을 위한 메모, 컴퓨터는 무시)이고, `# 출력:` 은 실행 결과를 적어 둔 거예요.

---

## 1. 출력 — 화면에 보여 주기

```python
print("안녕하세요")
print(3 + 4)
print("나이:", 20)
# 출력:
# 안녕하세요
# 7
# 나이: 20
```

---

## 2. 변수 — 이름표 붙은 상자

```python
name = "민수"      # name 상자에 "민수"를 넣는다
age = 20
height = 175.5

print(name, age, height)   # 출력: 민수 20 175.5

age = age + 1      # 상자의 값을 꺼내 1 더해서 다시 넣는다
print(age)         # 출력: 21
```

> ⚠️ 수학의 `=`(같다)와 달라요. 코딩의 `=`는 **"오른쪽 값을 왼쪽 상자에 넣어라"** 라는 뜻이에요. 같은지 비교할 때는 `==`를 씁니다.

### 변수 이름 짓기 규칙
- 영어·숫자·밑줄(`_`) 사용, **숫자로 시작 불가** (`1st` ✕, `first` ○)
- 띄어쓰기 불가 → `user_name` 처럼 밑줄로 (파이썬 관례)
- **뜻이 보이는 이름**: `a`, `x` 보다 `price`, `total_count` (11장에서 왜 중요한지 배워요)

---

## 3. 자료형 — 상자에 담기는 값의 종류

| 자료형 | 이름 | 예 | 설명 |
|---|---|---|---|
| `int` | 정수 | `10`, `-3` | 소수점 없는 수 |
| `float` | 실수 | `3.14`, `175.5` | 소수점 있는 수 |
| `str` | 문자열 | `"안녕"`, `'abc'` | 글자. 따옴표로 감쌈 |
| `bool` | 참/거짓 | `True`, `False` | 조건 판단 결과 |

```python
print(type(10))       # 출력: <class 'int'>
print(type("10"))     # 출력: <class 'str'>

print(10 + 5)         # 출력: 15      (숫자 더하기)
print("10" + "5")     # 출력: 105     (글자 이어 붙이기!)
print(int("10") + 5)  # 출력: 15      (글자를 숫자로 바꾼 뒤 더하기)
```

> 💡 `"10"`과 `10`은 컴퓨터에게 완전히 다른 값이에요. 초보자 오류의 상당수가 여기서 나옵니다.

---

## 4. 연산자 — 계산하기

```python
print(7 + 2)    # 9    더하기
print(7 - 2)    # 5    빼기
print(7 * 2)    # 14   곱하기
print(7 / 2)    # 3.5  나누기
print(7 // 2)   # 3    몫
print(7 % 2)    # 1    나머지  ← 짝수/홀수 판단에 자주 씀
print(7 ** 2)   # 49   거듭제곱
```

비교 연산자(결과는 `True` / `False`):

```python
print(5 > 3)    # True
print(5 == 3)   # False  같은가?
print(5 != 3)   # True   다른가?
print(5 >= 5)   # True
```

논리 연산자:

```python
age = 25
print(age >= 20 and age < 30)   # True   둘 다 참이면 참
print(age < 10 or age > 60)     # False  하나라도 참이면 참
print(not True)                 # False  반대로
```

## 5. 조건문 — 갈림길

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C 이하")
# 출력: B
```

- `if` → 조건이 참이면 아래 들여쓴 줄을 실행
- `elif` → 앞 조건이 거짓일 때 다음 조건 검사 (else if)
- `else` → 위가 전부 거짓일 때
- 파이썬은 **들여쓰기(보통 띄어쓰기 4칸)** 로 "여기까지가 if 안쪽"을 표시해요. 들여쓰기가 틀리면 오류!

### 짝수/홀수 판단
```python
n = 7
if n % 2 == 0:
    print("짝수")
else:
    print("홀수")
# 출력: 홀수
```

## 6. 반복문 — 같은 일 여러 번

### `for` — 정해진 횟수·목록만큼
```python
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 4):     # 1, 2, 3  (끝 숫자 4는 포함 안 됨!)
    print(i, "번째")
```

### `while` — 조건이 참인 동안 계속
```python
count = 3
while count > 0:
    print(count)
    count = count - 1
print("발사!")
# 출력: 3 2 1 발사! (한 줄씩)
```

> ⚠️ `while`에서 조건이 영원히 참이면 프로그램이 멈추지 않아요(**무한 루프**). 위 예에서 `count = count - 1`을 빼먹으면 영원히 3을 출력합니다. 멈추려면 터미널에서 `Ctrl + C`.

### `break`와 `continue`
```python
for i in range(1, 10):
    if i == 5:
        break        # 반복을 완전히 멈춤
    if i % 2 == 0:
        continue     # 이번 차례만 건너뜀
    print(i)
# 출력: 1 3 (한 줄씩)
```

### 반복 + 조건 = 구구단
```python
for dan in range(2, 4):
    for i in range(1, 10):
        print(dan, "x", i, "=", dan * i)
```

## 7. 함수 — 레시피 카드

자주 쓰는 일을 묶어서 이름을 붙이면, 이름만 불러서 다시 쓸 수 있어요.

```python
def greet(name):              # 함수 만들기(정의). name은 "재료(매개변수)"
    print("안녕하세요,", name, "님")

greet("민수")                  # 함수 부르기(호출)
greet("지영")
# 출력:
# 안녕하세요, 민수 님
# 안녕하세요, 지영 님
```

### 값을 돌려주는 함수 (`return`)
```python
def add(a, b):
    return a + b              # 결과를 돌려준다

result = add(3, 4)
print(result)                 # 출력: 7
print(add(10, 20) * 2)        # 출력: 60
```

### 함수를 쓰는 이유
1. **반복 제거**: 같은 코드를 여러 번 쓰지 않아도 됨
2. **이름으로 설명**: `calculate_tax(price)` 만 봐도 뭘 하는지 앎
3. **고치기 쉬움**: 세금 계산 방식이 바뀌면 함수 한 곳만 고치면 됨

## 8. 입력 받기

```python
name = input("이름을 입력하세요: ")
print("반가워요,", name)
```
- `input()` 으로 받은 값은 **항상 문자열**이에요. 숫자로 쓰려면 `int(input())` 처럼 바꿔야 해요.

## 9. 종합 예제: 숫자 맞히기 게임

```python
import random                      # 남이 만든 기능 묶음(모듈) 불러오기

answer = random.randint(1, 100)    # 1~100 중 무작위 숫자
tries = 0

while True:
    guess = int(input("1~100 숫자를 맞혀 보세요: "))
    tries = tries + 1
    if guess < answer:
        print("더 큰 수예요")
    elif guess > answer:
        print("더 작은 수예요")
    else:
        print("정답!", tries, "번 만에 맞혔어요")
        break
```

변수·조건·반복·함수(모듈)·입력이 전부 들어 있어요. 이걸 직접 쳐서 실행해 보면 **기초 1단계 완료**입니다.

### 이 장 요약
1. **변수**(`=`로 저장), **조건**(`if/elif/else`), **반복**(`for/while`), **함수**(`def/return`) = 모든 언어의 뼈대.
2. `"10"`(글자)과 `10`(숫자)은 다르다. `=`(넣기)와 `==`(비교)도 다르다.
3. 파이썬은 **들여쓰기**가 문법이다.
