# 02. 언어 지도 — 종류별로 정리

프로그래밍 언어는 수백 개가 있지만, 실제로 많이 쓰이는 건 20개 안팎이에요.
**"무엇을 만들고 싶은가"** 에 따라 언어가 정해지는 경우가 많습니다.

---

## 1. 지금 많이 쓰이는 언어 (조사 기준)

| 조사 | 결과 요약 |
|---|---|
| **TIOBE 지수** (검색량 기반, 2026년 10월) | 1위 **파이썬**, 2위 **C**, 3·4위를 **C++** 와 **자바**가 다툼. R, SQL, 줄리아(Julia) 등도 상위권 |
| **스택오버플로 개발자 설문** (2025년) | 많이 쓰는 순: **자바스크립트**(약 69%) → HTML/CSS → SQL → **파이썬**(약 55%) → 셸·타입스크립트. "가장 좋아하는 언어"는 몇 년째 **러스트** |

> 순위는 조사 방법마다 달라요. TIOBE는 "검색에 많이 나오는 정도", 스택오버플로는 "응답한 개발자가 쓰는 비율"이에요. **"1위 언어 = 내가 배울 언어"는 아닙니다.** 만들고 싶은 것을 먼저 정하세요(12장).

---

## 2. 용도별 언어 지도

```
웹 화면(브라우저)   → HTML/CSS + 자바스크립트 / 타입스크립트
웹 서버(백엔드)     → 자바, 파이썬, 자바스크립트(Node.js), Go, PHP, C#, 코틀린, 루비
모바일 앱          → 코틀린(안드로이드), 스위프트(아이폰), 다트(Flutter), 자바스크립트(React Native)
게임              → C++ (언리얼 엔진), C# (유니티)
데이터·AI         → 파이썬, R, SQL, 줄리아
운영체제·임베디드   → C, C++, 러스트, 어셈블리
윈도우 프로그램     → C#, C++
자동화·서버 관리    → 셸(Bash), 파이썬, PowerShell
데이터베이스       → SQL
```

---

## 3. 주요 언어 한 장씩

난이도: ★ 쉬움 ~ ★★★★★ 어려움 (초보자 기준의 대략적인 느낌)

### 🐍 파이썬 (Python) — ★
- **한 줄 설명**: 영어 문장처럼 읽히는, 가장 배우기 쉬운 언어 중 하나.
- **어디에**: 데이터 분석, **AI·머신러닝**, 업무 자동화, 웹 서버(Django, FastAPI), 교육.
- **장점**: 문법이 짧고 쉬움, 라이브러리(남이 만들어 둔 기능 모음)가 엄청 많음.
- **단점**: C 같은 언어보다 느림 (대신 무거운 계산은 C로 만든 라이브러리가 처리).
- **특징**: 들여쓰기(띄어쓰기)로 코드 묶음을 구분.
```python
print("Hello")
```

### ⚙️ C — ★★★★
- **한 줄 설명**: 1970년대에 만들어진, 거의 모든 언어의 "할아버지".
- **어디에**: 운영체제(리눅스·윈도우의 핵심), 임베디드(세탁기·자동차 칩), 다른 언어의 내부.
- **장점**: **매우 빠름**, 하드웨어를 직접 제어.
- **단점**: 메모리를 직접 관리해야 해서 실수하면 프로그램이 터지거나 보안 구멍이 생김 (10장).
```c
#include <stdio.h>
int main(void) { printf("Hello\n"); return 0; }
```

### ➕ C++ ("씨쁠쁠") — ★★★★★
- **한 줄 설명**: C에 **객체지향**(6장) 등 많은 기능을 더한 언어.
- **어디에**: **게임 엔진(언리얼)**, 고성능 프로그램(브라우저, 포토샵류), 금융 거래 시스템, 임베디드.
- **장점**: C만큼 빠르면서 큰 프로그램을 짜기 좋음.
- **단점**: 기능이 매우 많고 복잡 — 배우는 데 오래 걸림.
```cpp
#include <iostream>
int main() { std::cout << "Hello" << std::endl; }
```

### #️⃣ C# ("씨샵") — ★★★
- **한 줄 설명**: 마이크로소프트가 만든, 자바와 비슷한 언어. 이름만 C 계열이고 실제로는 자바와 더 닮았어요.
- **어디에**: **유니티 게임 개발**, 윈도우 프로그램, 기업용 웹 서버(.NET).
- **장점**: 문법이 깔끔, 도구(비주얼 스튜디오)가 좋음, 메모리 자동 관리.
```csharp
Console.WriteLine("Hello");
```

### ☕ 자바 (Java) — ★★★
- **한 줄 설명**: "한 번 작성하면 어디서나 실행"을 목표로 만든 언어.
- **어디에**: **대기업·은행·공공기관 서버**(한국에서 특히 많이 씀, 스프링 프레임워크), 안드로이드(예전), 빅데이터 도구.
- **장점**: 안정적, 대규모 프로젝트에 강함, 자료와 개발자가 많음.
- **단점**: 코드가 길어지는 편 (`public static void main`…).
```java
public class Main {
    public static void main(String[] args) { System.out.println("Hello"); }
}
```
> ⚠️ **자바와 자바스크립트는 완전히 다른 언어예요.** "햄과 햄스터" 정도로 관계없다는 농담이 있을 정도입니다.

### 🌐 자바스크립트 (JavaScript) — ★★
- **한 줄 설명**: **웹 브라우저에서 돌아가는 유일한 주류 언어.** 웹 화면을 움직이게 만드는 언어.
- **어디에**: 웹 화면(React, Vue 등), 서버(Node.js), 앱(React Native), 데스크톱 앱(Electron).
- **장점**: 브라우저만 있으면 바로 실행, 화면과 서버를 같은 언어로.
- **단점**: 예전 설계의 이상한 동작이 남아 있음 (예: `"5" - 2`는 3, `"5" + 2`는 `"52"`).
```javascript
console.log("Hello");
```

### 🔷 타입스크립트 (TypeScript) — ★★★
- **한 줄 설명**: 자바스크립트에 **"자료형 표시"** 를 더한 언어. 실행 전에 자바스크립트로 바뀌어요.
- **어디에**: 요즘 웹 개발 현업에서 자바스크립트 대신 많이 씀.
- **장점**: "숫자 자리에 글자를 넣었다" 같은 실수를 **실행 전에** 잡아 줌 → 큰 프로젝트에 필수처럼 쓰임.
```typescript
const name: string = "Hello";
console.log(name);
```

### 🐹 Go (고, Golang) — ★★★
- **한 줄 설명**: 구글이 만든, 단순하고 빠른 서버용 언어.
- **어디에**: 클라우드 서버, 인프라 도구(도커·쿠버네티스가 Go로 만들어짐), 네트워크 서비스.
- **장점**: 문법이 작고 단순, 빠름, **동시에 여러 일 하기**(10장)가 쉬움.
```go
package main
import "fmt"
func main() { fmt.Println("Hello") }
```

### 🦀 러스트 (Rust) — ★★★★★
- **한 줄 설명**: C/C++만큼 빠르면서 **메모리 실수를 컴파일러가 막아 주는** 언어.
- **어디에**: 시스템 프로그래밍, 브라우저·운영체제 일부, 고성능 서버, 블록체인.
- **장점**: 빠르고 안전. 개발자 설문에서 "가장 좋아하는 언어" 단골.
- **단점**: 규칙이 엄격해서 처음 배우기 어려움.
```rust
fn main() { println!("Hello"); }
```

### 🤖 코틀린 (Kotlin) — ★★★
- **한 줄 설명**: 자바를 더 짧고 안전하게 다듬은 언어. 자바와 함께 쓸 수 있음.
- **어디에**: **안드로이드 앱**(구글 공식 권장 언어), 서버.
```kotlin
fun main() { println("Hello") }
```

### 🍎 스위프트 (Swift) — ★★★
- **한 줄 설명**: 애플이 만든 언어.
- **어디에**: **아이폰·아이패드·맥 앱**.
```swift
print("Hello")
```

### 🐘 PHP — ★★
- **한 줄 설명**: 웹 서버용으로 오래 쓰인 언어.
- **어디에**: **워드프레스**(전 세계 사이트의 큰 비중), 한국의 그누보드 같은 게시판, 오래된 쇼핑몰.
```php
<?php echo "Hello";
```

### 💎 루비 (Ruby) — ★★
- **한 줄 설명**: "개발자가 행복한 언어"를 목표로 만든, 읽기 좋은 언어.
- **어디에**: 웹 서버(Ruby on Rails). 스타트업에서 빠르게 서비스를 만들 때 쓰였음.
```ruby
puts "Hello"
```

### 🎯 다트 (Dart) — ★★★
- **한 줄 설명**: 구글의 **Flutter**로 앱을 만들 때 쓰는 언어. 코드 하나로 안드로이드·아이폰 앱을 동시에.

### 📊 R — ★★★
- **한 줄 설명**: 통계 분석 전문 언어. 연구·통계 분야에서 많이 씀.

### 🗄️ SQL ("에스큐엘", "시퀄") — ★★
- **한 줄 설명**: **데이터베이스에 질문하는 언어.** 프로그램을 만드는 언어라기보다 "데이터를 꺼내고 넣는" 언어.
- **어디에**: 거의 모든 서비스. 개발자뿐 아니라 기획자·마케터도 배움.
```sql
SELECT name, price FROM products WHERE price < 10000;
```

### 🐚 셸 (Bash) — ★★
- **한 줄 설명**: 터미널(검은 화면)에서 컴퓨터에게 명령하는 언어. 파일 정리·서버 관리 자동화.
```bash
echo "Hello"
```

### 🔧 어셈블리 (Assembly) — ★★★★★
- **한 줄 설명**: 기계어 바로 위 단계. CPU 종류마다 다름. 보안 분석(리버싱), 아주 작은 칩 프로그래밍에 사용.

## 4. "언어"라고 부르지만 프로그래밍 언어는 아닌 것

| 이름 | 정체 | 비유 |
|---|---|---|
| **HTML** | 웹 페이지의 **뼈대·내용** (제목, 문단, 사진) | 집의 벽과 방 |
| **CSS** | 웹 페이지의 **모양** (색, 글꼴, 배치) | 페인트와 인테리어 |
| **JSON / YAML** | 데이터를 적는 **형식** | 정해진 양식의 서류 |
| **Markdown** | 글을 꾸미는 간단한 형식 (이 자료도 마크다운) | 메모장 꾸미기 규칙 |

> HTML·CSS는 "계산"이나 "조건 판단"을 하지 못해서 보통 프로그래밍 언어로 치지 않아요. 하지만 웹을 만들려면 **반드시 같이 배워야** 해요.

## 5. 언어를 나누는 기준 (조금 더 깊게)

| 기준 | 종류 | 설명 |
|---|---|---|
| **실행 방식** | 컴파일 / 인터프리터 / 가상 머신 | 1장 참고 |
| **자료형 검사 시점** | **정적 타입**(C, 자바, 타입스크립트, Go, 러스트) / **동적 타입**(파이썬, 자바스크립트, 루비) | 정적: 실행 전에 "숫자 자리에 글자" 같은 실수를 잡아 줌. 동적: 자유롭고 빠르게 쓰지만 실행해 봐야 알 때가 많음 |
| **메모리 관리** | **수동**(C, C++) / **자동·가비지 컬렉션**(자바, 파이썬, JS, Go, C#) / **소유권 규칙**(러스트) | 10장 참고 |
| **프로그래밍 방식(패러다임)** | 절차형(C) / 객체지향(자바, C#) / 함수형(하스켈, 일부 JS) / 여러 방식 혼합(파이썬, C++, 코틀린) | 6장 참고 |

## 6. 처음 배울 언어 고르기

| 목표 | 추천 첫 언어 | 이유 |
|---|---|---|
| 코딩이 뭔지 알고 싶다 / 자동화 / AI | **파이썬** | 가장 쉽고 쓰임새가 넓음 |
| 웹사이트를 만들고 싶다 | **HTML/CSS + 자바스크립트** | 브라우저에서 바로 결과가 보임 |
| 게임을 만들고 싶다 | **C#** (유니티) | 게임 엔진과 함께 배우기 좋음 |
| 아이폰 앱 / 안드로이드 앱 | **스위프트 / 코틀린** | 각 플랫폼 공식 언어 |
| 컴퓨터 원리를 깊이 / 전공 공부 | **C** → 이후 C++ | 메모리·포인터 등 원리를 배우게 됨 |
| 한국 대기업 서버 개발자 취업 | **자바** | 국내 수요가 많음 |

> 💡 **첫 언어 하나를 제대로 배우면 두 번째 언어는 훨씬 빨라요.** 변수·조건·반복·함수(4장)는 거의 모든 언어에 똑같이 있으니까요. 3장에서 직접 비교해 보세요.

---

### 이 장 요약
1. 언어는 **만들고 싶은 것**으로 고른다: 웹=JS, AI=파이썬, 게임=C#/C++, 앱=코틀린/스위프트, 시스템=C/러스트.
2. **C**는 빠르고 어렵고 원리를 배우기 좋고, **C++**는 C를 확장한 고성능 언어, **C#**은 자바와 닮은 게임·윈도우용 언어.
3. 처음이라면 **파이썬**이나 **자바스크립트**로 시작하는 경우가 가장 많다.
