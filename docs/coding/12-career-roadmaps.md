# 12. 진로별 로드맵

"무엇을 만들고 싶은가"에 따라 배울 순서가 달라요. 모든 길의 **공통 출발점**은 같습니다.

```
공통: 언어 하나(4~5장) → Git·터미널(8장) → 자료구조·알고리즘 기초(7장) → 작은 프로젝트 완성
```

## 10. 공부 기간 감각 (사람마다 크게 다름)

| 목표 | 꾸준히 공부할 때의 대략적인 느낌 |
|---|---|
| 간단한 프로그램 작성 (4~5장) | 몇 주 ~ 2개월 |
| 작은 웹 서비스 혼자 완성 (9장) | 수개월 |
| 신입 개발자 수준 | 보통 1년 안팎 이상의 꾸준한 공부 + 프로젝트 |
| 고수(시니어) | 현업 경험 수년 이상 |

> 💡 기간보다 중요한 건 **"완성한 프로젝트 수"** 예요. 강의를 10개 듣는 것보다 작은 서비스 3개를 끝까지 만들어 배포하는 게 실력이 더 많이 늘어요.

### 이 장 요약
1. 출발점은 같다: **언어 하나 → Git·터미널 → 자료구조 기초 → 작은 프로젝트**.
2. 웹 프론트(JS/TS·React), 백엔드(자바·파이썬·TS·Go + SQL), 앱(코틀린·스위프트·Flutter), 게임(C#·C++), 데이터·AI(파이썬·SQL), 임베디드(C).
3. 실력은 **완성한 프로젝트 수**로 쌓인다.
