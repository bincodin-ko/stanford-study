## 공부할 때 기억할 3가지

1. **읽기만 하지 말고 직접 쳐 보기.** 코딩은 자전거 타기처럼 손으로 배웁니다. 예제를 복사하지 말고 직접 타이핑해 보세요.
2. **오류는 정상입니다.** 고수도 하루에 수십 번 오류를 봐요. 오류 메시지를 읽는 습관이 실력입니다.
3. **작은 걸 끝까지 만들기.** 거창한 앱보다 "계산기 하나 완성"이 훨씬 많이 배우게 해 줍니다.

> 인터넷 사업 운영 자료(백업, 배포, Git, 서버 구조 등)는 [상위 폴더의 사업 자료](../../README.md)와 연결돼 있어요. 특히 [사업 6장 Git](../06-environments-and-git.md), [사업 5장 사이트 구조](../05-how-websites-work.md)를 함께 보면 좋아요.
