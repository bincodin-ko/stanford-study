# 55. 처음부터 끝까지 실습 프로젝트

지금까지 배운 걸 **실제로 하나 만들어 출시하고 운영**해 보는 실습이에요.
13장의 쇼핑몰 시뮬레이션이 "읽는 실습"이었다면, 이건 **직접 하는 실습**이에요.

> 각 단계 옆의 (○장)은 다시 볼 곳이에요. 처음이면 4주, 천천히 하면 8주를 잡으세요.

---

## 실습 주제 고르기 (추천 3가지)

| 주제 | 난이도 | 배우는 것 |
|---|---|---|
| **A. 계산기·도구 사이트** (예: 연봉 실수령액, 그래놀라 칼로리, 로또 당첨금 세금 계산기) | ★ | 정적 사이트, SEO, 광고 수익, 출시 체크리스트 |
| **B. 작은 디지털 상품 판매** (예: 노션 템플릿, 전자책) | ★★ | 결제 연동, 상세 페이지, 마케팅, 정산 |
| **C. 오목 1:1 대전 웹게임** | ★★★ | 웹소켓, 서버 판정, 매칭, 어뷰징 |

> 💡 처음이면 **A**를 추천해요. 결제·개인정보가 없어서 위험이 적고, 출시·운영 전 과정을 빠르게 한 바퀴 돌 수 있어요. A를 끝내면 B, 그다음 C.

아래는 **A. 계산기 사이트** 기준이고, B·C는 차이점만 표시했어요.

---

## 0주차 — 검증 (42장)

- [ ] 문제 한 문장: "○○한 사람은 ○○을 계산하기 번거롭다"
- [ ] 검색량 확인 (네이버 키워드 도구·구글 트렌드)
- [ ] 경쟁 계산기 5개 써 보고 불편한 점 정리
- [ ] 주변 3~5명에게 "지난번에 이 계산 어떻게 했어요?" 물어보기
- [ ] 이름 정하기 + 도메인·상표 검색 (34·47장)

## 1주차 — 설계 (4·48장)

- [ ] 화면 1~2개 와이어프레임 (입력 → 결과)
- [ ] 첫 화면 제목: "누가·무엇을·얼마나 쉽게" (48장)
- [ ] 결과 화면에 **공유 버튼** (33장 워들처럼)
- [ ] 기술 선택: HTML/CSS/JS 정적 사이트 ([코딩 9장](coding/09-web-development.md)), 정적 호스팅 (36장)
- [ ] 프로젝트 폴더 + Git 저장소 + CLAUDE.md (6·49장)

## 2주차 — 만들기 (49장)

- [ ] AI와 단계별로: 입력 화면 → 계산 로직 → 결과 화면 → 공유 버튼 (단계마다 커밋)
- [ ] 계산 로직 **자동 테스트** (경계값: 0, 음수, 아주 큰 수) (50장)
- [ ] 모바일 화면 확인
- [ ] 설명 글 1~2개 (계산 방법, 자주 묻는 질문) — 검색 유입용 (17장)

> **B(디지털 상품)라면**: 상세 페이지 + 결제 연동(테스트 키, 39장) + 다운로드 링크 + 환불 정책
> **C(오목)라면**: 웹소켓 서버 + 서버 판정(20·40장) + AI 대전 먼저 → 1:1 대전

## 3주차 — 출시 준비 (36~38·50장)

- [ ] 38장 **요청문**을 Claude에게 보내 30가지 점검
- [ ] 50장 **막 눌러 보기** + 기기별 시나리오
- [ ] 도메인 연결, HTTPS, OG 썸네일(카카오 디버거 확인) (34·38장)
- [ ] GA4 + 서치 콘솔 + 네이버 서치어드바이저 등록
- [ ] 개인정보처리방침 (GA4 쓰면 필요, 10·38장), 문의 이메일 (30장)
- [ ] 보안 기본 (37장): 계정 2단계 인증, 비밀 키 없음 확인

> **B라면 추가**: 사업자등록·통신판매업 신고 (10장), PG 심사, 라이브 키로 소액 결제→취소
> **C라면 추가**: 부하 테스트(내 서버에만), 신고 기능, 어뷰징 대비 (41장)

## 4주차 — 출시와 첫 손님 (32·33장)

- [ ] 지인 10명 소프트 런칭 → 피드백
- [ ] 관련 커뮤니티·스레드에 **도움 되는 글**로 소개 (홍보 규칙 지키기)
- [ ] 인스타 릴스 또는 쇼츠 1~3개 ("이거 계산 3초 만에")
- [ ] 첫 주 숫자: 방문자, 계산 횟수(GA4 이벤트), 공유 수

## 5~8주차 — 운영과 개선 (9·11·51장)

- [ ] 매주 금요일 30분 점검 (33·54장)
- [ ] 서치 콘솔에서 들어온 검색어 → 관련 설명 글 추가
- [ ] 가장 많이 나온 의견 1개 고치기 → 배포 (7장 절차) → 회귀 테스트 (50장)
- [ ] 백업·업타임 알림 확인 (8·9장)
- [ ] (트래픽이 생기면) 광고 신청 (18장)

---

## 마무리 회고 (꼭 써 보기)

```
1. 처음 가설은 맞았나? (누가 왔고, 무엇을 썼나)
2. 가장 오래 걸린 단계는? 왜?
3. 다시 한다면 다르게 할 것 3가지
4. 숫자: 방문자 / 사용 횟수 / 공유 / (수익)
5. 다음 프로젝트: B? C? 이걸 키우기?
```

> 💡 결과가 작아도 괜찮아요. **기획 → 개발 → 출시 → 운영을 한 바퀴 끝까지 돈 경험**이 이 자료 전체에서 가장 큰 공부예요. 그다음 프로젝트는 훨씬 빨라져요.

---

### 이 장 요약
1. 처음엔 **계산기·도구 사이트(A)** 로 위험 없이 한 바퀴, 그다음 **디지털 상품(B)** → **오목 게임(C)**.
2. **0주 검증 → 1주 설계 → 2주 만들기 → 3주 출시 준비 → 4주 출시 → 5~8주 운영**, 각 단계에서 앞 장을 다시 본다.
3. 끝나면 **회고**를 쓰고 다음 프로젝트로.
