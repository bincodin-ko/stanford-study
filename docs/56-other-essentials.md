# 56. 그 밖에 놓치기 쉬운 것들

1인 창업·운영 자료들을 살펴보며, 앞 장들에서 따로 다루지 않았지만 **실제로 운영하면 꼭 마주치는 주제**를 모았어요.

> ⚠️ 법·계약 관련 내용은 요약이에요. 실제 상황에서는 전문가와 확인하세요. ([참고 자료 모음](sources.md))

## 1. 이용약관 직접 만들기

| 넣을 내용 | 예 |
|---|---|
| 서비스 내용·이용 조건 | 무엇을 제공하나, 회원 자격 |
| 회원의 의무·금지 행위 | 어뷰징·도배·불법 행위 (16·41장) |
| 결제·환불·해지 | 청약철회(10장), 구독 해지 (43장) |
| 게시물 권리 | 회원 게시물의 저작권과 이용 범위 (16·47장) |
| 서비스 변경·중단 | 미리 공지하는 방법 |
| 책임 제한 | 서비스 장애·데이터 손실 시 범위 |
| 분쟁 해결 | 관할, 소비자분쟁조정 |
| 약관 변경 | 손님에게 불리하면 미리 공지 (10장) |

- 공정거래위원회가 업종별 **표준약관**을 공개하고 있어요 → 참고해서 내 서비스에 맞게.
- 손님에게 일방적으로 불리한 조항(예: "어떤 경우에도 환불 불가")은 **약관법상 무효**가 될 수 있어요.

## 2. 평판·위기 대응

### 악성 리뷰·불만이 올라왔을 때
```
1. 바로 감정적으로 답하지 않기 (하루 생각)
2. 사실 확인: 실제 주문인가? 무엇이 문제였나?
3. 공개 답변: 사과(잘못이 있다면) + 해결 방법 + 1:1 연락 안내
4. 비공개로 해결
5. 원인을 고쳐 같은 일이 반복되지 않게 (9장 포스트모템)
```
- 사실과 다른 악의적 글은 플랫폼 신고, 명예훼손이면 법적 대응 검토 (16장 임시조치).
- **리뷰 삭제를 조건으로 보상**하거나 가짜 리뷰로 덮는 건 역효과·법 위반 위험 (10·41장).

### 큰 장애·사고 때 손님 공지
- **빨리, 정직하게, 무엇을 하고 있는지**: "현재 결제 오류가 있어 복구 중이에요. ○시까지 다시 안내드릴게요."
- 해결 후: 원인과 재발 방지 + 피해 보상 기준 (9장)

## 3. 사업 보험

| 보험 | 필요한 경우 |
|---|---|
| **배상책임보험** | 제품으로 손님이 다치거나 손해를 봤을 때 (식품·화장품·유아용품 등) |
| **사이버보험** | 개인정보 유출·해킹 피해 대응 비용 |
| **보증보험** | PG 계약 시 요구되기도 (39장) |
| **화재·재고 보험** | 창고·재고가 있을 때 |

- 업종에 따라 **의무 가입**인 보험도 있어요 (예: 개인정보를 일정 규모 이상 다루는 사업자의 손해배상책임 보장 관련 의무). 해당 여부 확인.

## 6. 사업을 접거나 팔 때 — 출구 전략

### 사업을 접을 때 (폐업)
| 할 일 | 내용 |
|---|---|
| 손님 공지 | 서비스 종료일, 남은 구독·적립금 환불, 데이터 내보내기 기간 |
| 주문·정산 마무리 | 진행 중 주문, PG 정산, 판매자 정산 (39장) |
| 개인정보 파기 | 법에 따라 보관할 것만 남기고 파기 (10장) |
| 폐업 신고 | 사업자 폐업 신고 + 통신판매업 폐업 신고 |
| 세금 | 폐업 후에도 부가세·종합소득세 신고 (44장) |
| 계정·도메인 | 해지 순서 (도메인은 마지막에, 사칭 방지) |

### 사업을 팔 때 (매각)
- 사는 사람이 보는 것: **매출·이익 증빙, 트래픽 출처, 손님 수, 운영 문서, 코드·도메인·계정 소유권, 법적 문제 유무** (22장)
- 깔끔한 장부(44장)와 문서(4절)가 곧 **가격**이에요.

---

### 이 장 요약
1. **약관은 표준약관을 참고**해 내 서비스에 맞게, 손님에게 일방적으로 불리한 조항은 무효가 될 수 있다.
2. 악성 리뷰·장애는 **빨리·정직하게·해결 중심**으로, 업종에 맞는 **보험**을 확인한다.
3. **운영 문서**가 있어야 쉬고·뽑고·팔 수 있다. 접을 땐 **손님 공지 → 정산 → 개인정보 파기 → 폐업 신고 → 세금**.
