# 63. 콘텐츠·검색 노출 심화 — 키워드 조사부터 AI 검색까지

> 검색 노출 기초는 [11장](11-growth-and-data.md), 출시 전 기술 설정(제목·설명·사이트맵·구조화된 데이터)은 [38장](38-launch-checklist-for-claude.md), 정보 사이트와 검색 스팸은 [17장](17-info-sites.md)에 있어요.

> ⚠️ 검색 엔진의 기준은 공개되지 않은 부분이 많고 자주 바뀌어요. 이 장의 "잘 걸리는 글" 요령은 **공식 기준이 아니라 업계 경험**인 부분이 많아요. 공식 문서로 확인한 것은 따로 표시했어요. ([참고 자료 모음](sources.md))

---

## 1. 왜 콘텐츠·검색인가 — 광고와 비교

| | 광고 (61장) | 콘텐츠·검색 |
|---|---|---|
| 효과가 나오는 시점 | 켜자마자 | **몇 주~몇 달 뒤** |
| 돈을 끄면 | 손님이 바로 끊김 | 글은 **계속 남아** 손님을 데려옴 |
| 비용 | 손님마다 돈 | 쓰는 시간 |
| 1인 사업자에게 | 테스트·빠른 확인용 | **오래 쌓이는 자산** |

추천: **광고로 빨리 확인하고, 콘텐츠로 천천히 쌓기.** 둘 다 같은 질문("손님이 무엇을 궁금해하나")에서 시작해요.

## 2. 키워드 조사 — 손님이 실제로 치는 말 찾기

### 조사 도구 (무료)
| 도구 | 보는 것 |
|---|---|
| **네이버 검색광고 키워드 도구** | 네이버 월간 검색 수(PC·모바일), 연관 키워드. 광고 계정이 있으면 무료로 써요 |
| **네이버 데이터랩** | 검색어의 **추세**(계절, 늘고 있나) |
| **구글 트렌드** | 구글 검색어 추세, 지역별 관심 |
| **구글 서치 콘솔** | **내 사이트가 이미** 어떤 검색어로 노출·클릭되는지 (38장에서 등록) |
| **검색창 자동완성·관련 질문** | 사람들이 실제로 붙여 치는 말 |
| **커뮤니티·내 문의함** | 손님의 진짜 말투 (30장 자주 온 문의) |

### 키워드 고르는 기준
```
큰 키워드:  "그래놀라"              검색 많음, 경쟁 매우 큼, 사려는지 불분명
중간:       "무설탕 그래놀라"        검색 보통, 경쟁 보통
긴 키워드:  "당뇨 아침 그래놀라 추천"  검색 적음, 경쟁 적음, 원하는 게 분명 ← 여기서 시작
```
- 이렇게 길고 구체적인 검색어를 **롱테일 키워드**라고 해요. 하나하나는 적어도 **모으면 크고, 구매 의도가 분명**해요.
- **검색 의도**를 함께 봐요.

| 의도 | 예 | 맞는 글 |
|---|---|---|
| 알고 싶다 | "그래놀라 칼로리" | 설명 글 |
| 비교하고 싶다 | "그래놀라 vs 오트밀" | 비교 글 |
| 사고 싶다 | "무설탕 그래놀라 추천" | 추천·상품 페이지 |
| 찾아가고 싶다 | "그래놀라랩" | 홈페이지 |

### 키워드 표 만들기 (엑셀 한 장)
| 키워드 | 월 검색 수 | 의도 | 지금 1페이지에 누가 있나 | 내가 쓸 글 | 우선순위 |
|---|---|---|---|---|---|
| 당뇨 아침 그래놀라 | (도구에서 확인) | 사고 싶다 | 블로그 3, 쇼핑 | 혈당 걱정 아침 메뉴 가이드 | 1 |

> 💡 **지금 1페이지를 직접 검색해 보세요.** 대기업·공공기관만 있으면 피하고, 개인 블로그·오래된 글이 보이면 기회예요.

## 3. 검색에 잘 걸리는 글의 구조

### 구글 공식 문서가 말하는 방향
- 구글은 **"사람을 위해 쓴 도움 되는 콘텐츠"**를 강조해요. 검색 순위만 노린 글, 대량 자동 생성 글은 스팸 정책에 걸릴 수 있어요(17장).
- **AI 검색 결과(AI 개요·AI 모드)에 나오는 데도 특별한 설정은 필요 없고**, 일반 검색과 같은 기본(검색에 색인되고 스니펫으로 보일 수 있는 상태)을 지키면 된다고 공식 문서에 적혀 있어요.

### 업계에서 많이 쓰는 글 틀 (경험 기반)
```
제목(h1): 검색어 + 손님이 얻는 것     "당뇨 걱정 아침 메뉴, 그래놀라 고르는 5가지 기준"
첫 2~3줄: 질문에 대한 답부터 요약     (결론 먼저 — AI 요약에 인용되기도 쉬워요)
목차
소제목(h2·h3): 손님이 이어서 궁금해할 질문 순서대로
  - 직접 해 본 경험·사진·숫자          (남의 글 요약이 아닌 "내 경험")
  - 표·목록                             (비교·순서는 표로)
자주 묻는 질문 3~5개                   (38장 FAQ 구조화 데이터와 함께)
다음 행동: 관련 글·상품 링크           (내부 링크, 38장)
작성자 소개·작성일·수정일
```

### 경험이 들어간 글이 강한 이유
- 검색 결과가 비슷한 요약 글로 넘쳐 나고, AI가 요약까지 해 주는 시대에는 **"직접 해 본 사람만 쓸 수 있는 내용"**이 남아요.
- 예: "그래놀라 7종 혈당 측정 2주 기록", "우리 가게 손님 100명에게 물어본 결과".
- 구글 품질 기준에서 자주 언급되는 **경험·전문성·권위·신뢰(E-E-A-T)**도 같은 방향이에요.

## 4. AI 검색 시대에 달라진 것

| 변화 | 의미 | 대응 |
|---|---|---|
| 검색 결과 위에 **AI 요약**(구글 AI 개요, 네이버 AI 브리핑) | 요약만 보고 **클릭 없이 떠나는** 검색이 늘어요 | 요약으로 끝나지 않는 **경험·도구·상품**을 제공 |
| AI가 **출처 링크**를 달아 줌 | 인용되면 신뢰·방문이 생겨요 | 결론 먼저, 표·숫자, 분명한 소제목 |
| 네이버 AI 브리핑 확대 | 자료마다 적용 비율이 다르게 보도됨(20~40%) | 블로그 외에 **스마트플레이스·쇼핑·클립** 등 네이버 안 서비스도 관리(32장) |
| 챗GPT·클로드 등에서 직접 질문 | 검색창 밖에서도 추천이 일어남 | 여러 곳에 **같은 정보**(이름·가격·특징)를 일관되게, 리뷰·언론 보도 쌓기(62장) |

> 💡 AI 검색에 맞춘다며 **같은 글을 대량으로 찍어 내는 것**은 오히려 위험해요(17장 대량 저품질 콘텐츠). 결국 **좋은 글 한 편**이 답이에요.

## 5. 콘텐츠 운영 — 1인 사업자 루틴

### 콘텐츠 묶음(허브 앤 스포크)
```
            [허브: 아침 식사 완벽 가이드]
           /          |            \
[그래놀라 고르는 법] [혈당 걱정 메뉴] [5분 아침 레시피 10개]
           \          |            /
               [상품 페이지 링크]
```
- 큰 주제 글 1개(허브)와 세부 글 여러 개(스포크)를 **서로 링크**해요. 검색 엔진과 손님 모두 주제를 이해하기 쉬워요.

### 주간 루틴
| 요일 | 할 일 |
|---|---|
| 월 | 서치 콘솔·GA4 확인: 어떤 글이 노출·클릭되나 |
| 화~목 | 새 글 1편 또는 **옛 글 고치기 1편** |
| 금 | 글 하나를 **잘게 나눠** SNS 게시물·릴스·뉴스레터로 재활용(32·64장) |

- **옛 글 고치기**가 새 글보다 효과적인 경우가 많아요: 서치 콘솔에서 **노출은 많은데 클릭이 적은 글** → 제목·설명 고치기, **순위 11~20위 글** → 내용 보강.

### AI와 함께 쓰기
- AI로 **목차·초안·맞춤법**은 빠르게, 그러나 **경험·사진·숫자·최종 확인은 내가.**
- 요청 예: "이 키워드 표를 보고 글 10편의 제목과 목차를 제안해 줘. 각 글에 내가 직접 넣어야 할 경험·사진 자리를 [ ]로 표시해 줘."
- AI가 쓴 사실(숫자·법·효능)은 **반드시 확인**하세요. 틀린 효능 주장은 법 위반이 될 수 있어요(29장).

## 6. 하지 말 것

| 하지 말 것 | 왜 |
|---|---|
| 키워드 억지로 반복(도배) | 읽기 불편하고 스팸 취급 가능 |
| 남의 글·이미지 복사 | 저작권 침해, 검색 제외 (17·47장) |
| 링크 사고팔기 | 구글 스팸 정책 위반 |
| AI로 수백 편 자동 발행 | 대량 저품질 콘텐츠 정책 (17장) |
| 네이버 블로그 글 대량 복사·발행 | 저품질 판정 위험이 있다고 업계에서 자주 경고 |

---

### 이 장 요약
1. **긴 키워드(롱테일) + 검색 의도**로 시작하고, 지금 1페이지를 직접 검색해 기회를 찾는다.
2. 글은 **결론 먼저, 소제목은 질문 순서, 직접 해 본 경험·숫자·표**로. AI 검색에 특별한 설정은 필요 없다는 게 구글 공식 입장.
3. **허브와 세부 글을 링크로 묶고**, 매주 서치 콘솔을 보며 **옛 글을 고친다.**
