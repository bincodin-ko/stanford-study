# 36. 서버·호스팅 고르는 법

5장에서 호스팅 종류(빌더, 웹호스팅, 클라우드, 서버리스)를 간단히 봤어요.
이 장은 **"내 사업이면 실제로 어디에 올릴까?"** 를 고르는 방법이에요.

> ⚠️ 무료 요금제·가격·조건은 자주 바뀌어요. 2026년 10월 조사 기준이고, 숫자 상당수는 공식 가격표가 아니라 비교 기사에서 확인한 것이에요. 고르기 전에 각 회사의 **공식 가격표와 이용약관**을 꼭 확인하세요. ([참고 자료 모음](sources.md))

---

## 1. 먼저 내 사이트가 어떤 종류인지

| 사이트 종류 | 예 | 필요한 것 |
|---|---|---|
| **① 정적 사이트** | 회사 소개, 포트폴리오, 랜딩 페이지, 계산기(브라우저에서만 계산) | 파일(HTML·CSS·JS)만 올리면 끝. 서버 프로그램·DB 없음 |
| **② 콘텐츠 사이트** | 블로그, 정보 사이트 | 글 관리(CMS) + DB |
| **③ 쇼핑몰** | 자사몰 | 상품·주문·결제·회원 → 빌더가 가장 편함 |
| **④ 웹 서비스·앱 서버** | 회원제 서비스, SaaS, AI 서비스, 커뮤니티 | 서버 프로그램 + DB + 파일 저장소 |
| **⑤ 실시간 서비스** | 오목 대전, 채팅 | 계속 연결된 서버(웹소켓), 지연 시간 중요 |

## 2. 호스팅 종류 다시 보기 (실전 기준)

| 종류 | 대표 예 | 내가 할 일 | 잘 맞는 사이트 |
|---|---|---|---|
| **사이트·쇼핑몰 빌더** | 카페24, 아임웹, 식스샵, 쇼피파이, 윅스 | 거의 없음 (업체가 서버·보안·백업 대부분 처리) | ③, 간단한 ① |
| **정적 호스팅** | GitHub Pages, Cloudflare Pages, Netlify, Vercel | 파일 올리기(대개 Git push만 하면 자동 배포) | ① |
| **설치형 웹호스팅** | 국내 웹호스팅 업체, 워드프레스 전용 호스팅 | 워드프레스·플러그인 업데이트 | ② |
| **애플리케이션 플랫폼(PaaS)** | Vercel, Render, Railway, Fly.io, Firebase, Supabase 등 | 코드만 올림, 서버 관리는 플랫폼이 | ④ 초기 |
| **VPS·가상 서버** | AWS Lightsail, 각종 VPS 업체 | **운영체제부터 보안 업데이트·백업 전부 직접** | ④⑤, 서버 공부 |
| **대형 클라우드** | AWS, 구글 클라우드, 마이크로소프트 애저, 네이버 클라우드, KT 클라우드 | 설계부터 비용 관리까지 | ④⑤ 성장 후, 큰 서비스 |

> 💡 **"직접 관리할수록 싸고 자유롭지만, 내 시간과 책임이 늘어난다."** 초보자는 **위쪽(빌더·PaaS)에서 시작**해서, 필요해질 때 아래쪽으로 내려가는 게 일반적이에요.

## 3. 고르는 기준 10가지

| # | 기준 | 확인할 질문 |
|---|---|---|
| 1 | **사이트 종류** | 정적? DB 필요? 실시간? (1절) |
| 2 | **내 실력·시간** | 서버 보안 업데이트를 매주 할 수 있나? 못 하면 관리형으로 |
| 3 | **비용 구조** | 월 고정? 사용량 과금? **트래픽 폭주 시 요금 폭탄** 가능성? 예산 알림 설정 가능? |
| 4 | **상업 사용 가능 여부** | 무료 요금제가 **상업용 금지**인 경우가 있음 (5절) |
| 5 | **서버 위치(리전)** | 손님이 한국이면 **서울 리전·국내 서버**가 빠름 |
| 6 | **개인정보** | 해외 서버에 회원 정보를 두면 **국외 이전 고지**가 필요할 수 있음 (6절) |
| 7 | **백업** | 자동 백업이 있나? 보관 기간은? 내가 따로 내려받을 수 있나? (8장) |
| 8 | **확장성** | 손님이 10배 늘면 어떻게? 버튼으로 늘릴 수 있나? |
| 9 | **지원** | 한국어 고객 지원? 장애 공지 페이지? |
| 10 | **떠나기 쉬운가(락인)** | 나중에 다른 곳으로 옮길 때 데이터를 쉽게 가져갈 수 있나? |

## 4. 상황별 추천 조합

| 상황 | 추천 출발점 | 이유 |
|---|---|---|
| 처음 쇼핑몰 (13장) | **국내 쇼핑몰 빌더** | 결제(PG)·배송·사업자 표시·보안을 대부분 해결 |
| 해외에도 판매 | 쇼피파이 등 글로벌 빌더 | 해외 결제·통화 |
| 회사 소개·랜딩 페이지 | 빌더 또는 **정적 호스팅** | 무료·저렴, 빠름 |
| 블로그·정보 사이트 (17장) | 블로그 서비스, 워드프레스 호스팅, 정적 사이트 생성기 + 정적 호스팅 | 글 관리 편의 vs 속도·비용 |
| 계산기·도구 사이트 | **정적 호스팅** | 계산을 브라우저에서 하면 서버 비용 거의 0 |
| 회원제 웹 서비스·AI 서비스 MVP (28장) | **PaaS + 관리형 DB** | 서버 관리 없이 빨리 출시 |
| 실시간 게임(오목) (20장) | 웹소켓을 지원하는 PaaS 또는 VPS, **서울 근처 리전** | 지연 시간 |
| 손님이 크게 늘어난 서비스 | 대형 클라우드 (전문가와 함께) | 확장·안정성 |

## 5. 무료 요금제의 함정

| 함정 | 설명 |
|---|---|
| **상업 사용 금지** | 예: Vercel의 무료(Hobby) 요금제는 **개인·비상업용**으로만 쓸 수 있고, 수익이 나는 사이트는 유료(Pro, 보도 기준 사용자당 월 20달러)가 필요하다는 안내가 여러 비교 글에 있어요. 다른 회사들은 무료에서도 상업 사용을 허용한다고 소개되지만, **약관 원문 확인 필수** |
| **잠자는 서버** | 일부 무료 서버는 한동안 접속이 없으면 꺼졌다가, 첫 손님이 올 때 수십 초 걸려 켜짐 |
| **한도 초과 시 멈춤** | 무료 한도를 넘으면 **사이트가 일시 정지**되거나 속도가 제한됨 |
| **사용량 과금 폭탄** | 반대로 유료 사용량 과금은 갑자기 사람이 몰리거나 공격을 받으면 **요금이 폭증** → **예산 알림·지출 한도** 꼭 설정 |
| **무료 정책 변경** | 무료 요금제가 줄거나 없어진 사례가 여러 번 있었음 → 옮길 수 있게 준비 |

## 6. 서버 위치와 개인정보

- 손님이 대부분 한국이면 **서울 리전**(한국 데이터센터)을 고르는 게 속도에 유리해요. 서울↔미국 왕복은 물리적으로 수십~100ms 이상 걸려요 ([코딩 10장](coding/10-advanced.md)).
- 2023년 개정 개인정보보호법(제28조의8)에 따라, **개인정보를 해외로 보내거나(제공), 해외 업체에 맡기거나(위탁), 해외에 보관**하면 "국외 이전" 규칙이 적용될 수 있어요.
  - 해외 클라우드(해외 리전)에 회원 정보를 맡기면서 **이전 국가·방법을 처리방침에 공개하지 않은 것**이 인증 심사에서 결함 사례로 소개돼요.
  - 처리방침에 적을 항목 예: 이전되는 개인정보 항목, 이전 국가·시기·방법, 이전받는 회사 이름과 연락처, 보유 기간.
  - 서울 리전을 써도 해외 본사가 접근할 수 있는 구조면 어떻게 보는지 등은 **사례마다 판단이 다를 수 있어서** 전문가·개인정보보호위원회 안내로 확인하세요.

## 7. 비용 감 잡기 (예시 시나리오)

> 아래는 **구조를 이해하기 위한 예시**예요. 실제 금액은 업체·환율·사용량에 따라 크게 달라요.

| 단계 | 구성 예 | 비용 감각 |
|---|---|---|
| 랜딩 페이지 | 정적 호스팅 무료 + 도메인 | 도메인값 정도 (34장) |
| 쇼핑몰 시작 | 쇼핑몰 빌더 기본 요금 + PG 수수료 | 월 이용료 + 매출의 몇 % |
| 회원제 서비스 MVP | PaaS 유료 1개 + 관리형 DB 소형 + 메일 발송 | 월 몇만 원 수준부터 |
| 성장기 | 서버 여러 대 + DB + CDN + 모니터링 | 사용량에 비례해 증가 → **매월 비용 점검** |

### 비용 아끼는 습관
- 이미지 용량 줄이기 (트래픽 비용 ↓, 속도 ↑)
- CDN·캐시 사용 (10장)
- 안 쓰는 서버·테스트 환경 끄기
- **예산 알림** 설정 (예: 월 5만 원 넘으면 메일)

## 8. 출시 전 호스팅 점검표

- [ ] 상업 사용 가능한 요금제인가 (약관 확인)
- [ ] HTTPS 자동 적용·자동 갱신
- [ ] 서버 위치(리전) 확인, 해외면 처리방침에 국외 이전 내용
- [ ] 자동 백업 켜짐 + 직접 내려받기 테스트 (8장)
- [ ] 스테이징(연습용) 환경 따로 (6장)
- [ ] 예산 알림·지출 한도 설정
- [ ] 관리 계정 2단계 인증, 팀원 권한 최소화 (37장)
- [ ] 장애 공지 페이지(status page) 구독 (9장)
- [ ] 다른 곳으로 옮길 때 데이터 내보내기 방법 확인

---

### 이 장 요약
1. 먼저 **사이트 종류**(정적·콘텐츠·쇼핑몰·웹 서비스·실시간)를 정하고, 초보자는 **빌더·PaaS 같은 관리형**에서 시작한다.
2. 기준: 실력·시간, 비용 구조(요금 폭탄), **상업 사용 가능 여부**, 서버 위치, 개인정보 국외 이전, 백업, 확장, 지원, 이사 쉬움.
3. 무료 요금제는 **상업 금지·잠자는 서버·한도 초과 정지**를 확인하고, 유료는 **예산 알림**을 건다.
