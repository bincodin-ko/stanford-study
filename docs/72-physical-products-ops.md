# 72. 실물 상품 운영 — 상품 사진·재고·택배·포장·교환/반품

> 오픈마켓 판매는 [23장](23-marketplace-sellers.md), 물류 용어·주문 상태 흐름은 [35장](35-domain-knowledge.md), 청약철회(환불) 법 규칙은 [10장](10-security-and-law.md)에 있어요. 이 장은 **매일 손으로 하는 일**을 정리했어요.

> ⚠️ 택배 단가·계약 조건은 지역·물량·업체마다 크게 달라요. 이 장의 내용은 **일반적인 실무 요령**이고, 숫자는 직접 견적을 받아 확인하세요. ([참고 자료 모음](sources.md))

---

## 1. 상품 사진 — 상세 페이지의 절반

| 사진 | 목적 |
|---|---|
| **대표 사진** (흰 배경 또는 깔끔한 단색) | 검색·목록에서 눈에 띄기. 오픈마켓은 대표 사진 규정이 있으니 확인 (23장) |
| **사용 장면** | "내가 쓰면 이렇구나" |
| **크기 비교** | 손·동전·자와 함께 → "생각보다 작아요" 반품 줄이기 |
| **디테일·재질** | 확대 사진 |
| **성분표·라벨** | 식품·화장품은 법정 표시 내용 (29장) |
| **포장 상태** | 선물용 손님에게 중요 |

촬영 요령 (스마트폰으로 충분해요):
- **자연광**(창가, 직사광선 피하기) 또는 저렴한 조명 2개
- 배경은 흰 종이·폼보드, 그림자를 줄이려면 반대편에 흰 판(반사판)
- 같은 각도·같은 배경으로 **상품마다 통일** → 브랜드 일관성(62장)
- 실제와 **색이 다르게 보이지 않게** 보정은 최소 (색 차이는 반품 1순위 사유 중 하나)
- 웹에 올리기 전 크기 줄이기 (68장 속도)
- 남의 사진·폰트를 쓰려면 라이선스 확인 (47장). AI로 만든 사용 장면은 **실제 상품과 다르게 보이지 않게** — 과장 광고가 될 수 있어요.

## 2. 재고 관리

### 기본 규칙
- **팔 수 있는 수량 = 실제 재고 − 결제 대기·출고 대기 수량**
- 여러 곳(자사몰·스마트스토어·쿠팡)에서 팔면 재고가 **따로 줄어서 품절된 걸 또 파는** 사고가 나요 → 재고 **연동 도구**(통합 관리 솔루션)를 쓰거나, 채널별로 수량을 나눠 두기.
- **품절·지연**은 바로 상품 페이지에 반영하고, 이미 주문한 손님에게 먼저 연락 (10장: 공급 못 하면 빨리 환불).

### 얼마나 쌓아 둘까
```
다시 주문할 때 = (하루 평균 판매량 × 들어오는 데 걸리는 날) + 안전 재고
```
- 예: 하루 10개 팔리고, 공장에서 7일 걸리고, 안전 재고 30개 → **100개 남았을 때 주문**
- 처음엔 적게 사고 자주 주문하세요. **팔리지 않는 재고 = 묶인 현금**(44장 현금 흐름).
- 유통기한이 있는 상품은 **먼저 들어온 것부터 먼저 내보내기**(선입선출).

### 매달 재고 실사
- 장부(시스템) 수량과 실제 수량을 세어 비교 → 차이가 나면 원인(파손·분실·출고 실수) 기록.
- 연말 재고는 **세금 계산에도** 쓰여요(44·71장).

## 3. 택배 계약과 출고

### 택배를 보내는 방법
| 방법 | 맞는 경우 |
|---|---|
| 편의점·우체국 창구 개인 택배 | 하루 몇 개 이하, 테스트 단계 |
| **택배사 대리점과 계약** (방문 수거) | 하루 수십 개 이상, 단가 협상 가능 |
| 택배 대행·통합 서비스 | 여러 택배사 비교, 송장 일괄 출력 |
| **풀필먼트(물류 대행)** | 보관·포장·출고까지 맡기기 (35장). 물량이 늘고 내가 포장할 시간이 없을 때 |

- 계약할 때 물어볼 것: **크기·무게별 단가**, 하루 최소 물량, 수거 시간, **반품 단가**, 파손·분실 보상 기준, 제주·도서산간 추가 요금, 송장 출력 방식(쇼핑몰과 연동되나).
- 물량이 늘면 **3~6개월마다 단가 재협상**.

### 매일 출고 루틴
```
1. 주문 확인 (결제 완료만) → 2. 송장 일괄 출력 → 3. 피킹(상품 꺼내기)
→ 4. 검수(상품·수량·옵션 맞나) → 5. 포장 → 6. 송장 부착
→ 7. 송장 번호 쇼핑몰에 등록 (손님에게 배송 알림, 64장 알림톡) → 8. 수거
```
- **마감 시간**을 정해 상세 페이지에 표시: "오후 2시 결제까지 당일 출고"
- 4번 검수에서 실수가 가장 많이 잡혀요. 옵션(색·사이즈) 오배송이 반품 원인 상위권.

## 4. 포장

| 원칙 | 내용 |
|---|---|
| **상품 보호** | 흔들리지 않게 완충재, 액체는 비닐 밀봉, 깨지는 건 "취급 주의" |
| **크기 맞춤** | 상자가 크면 택배비가 오르고 과대포장 규제 대상이 될 수 있어요 |
| **비용** | 상자·완충재·테이프를 1개당 원가에 넣기 (61장 손익분기) |
| **브랜드 경험** | 감사 카드, 사용법 카드, **카카오 채널·리뷰 QR**(64장) |
| **환경** | 종이 완충재, 테이프 줄이기 — 손님 반응이 좋은 경우가 많아요 |

- 포장재 과대포장·재질 관련 규제가 있어요. 제품 종류별 기준은 환경부 안내 확인.

## 5. 교환·반품 — 손님 경험과 돈이 갈리는 곳

### 법 기본 (10장 복습)
- 온라인 구매는 원칙적으로 **받은 날부터 7일 안에 청약철회(반품·환불)** 가능, 상품이 설명과 다르면 더 길게.
- **단순 변심 반품 택배비는 손님**, 상품 하자·오배송은 **판매자** 부담이 원칙.
- 예외(사용해서 가치가 크게 줄어든 경우 등)는 **미리 상세 페이지에 분명히** 알려야 적용돼요.

### 처리 순서
```
1. 접수: 사유·사진 받기 (문의 템플릿, 30장)
2. 판단: 하자·오배송 / 단순 변심 → 택배비 부담 결정
3. 회수: 반품 택배 접수 (계약 택배사 반품 단가로)
4. 검수: 도착 상품 상태 확인 (사진 기록)
5. 환불: 결제 취소 (PG 부분 취소, 39장) — 법정 기한 안에
6. 재고: 다시 팔 수 있으면 재고로, 아니면 불량 재고로 분리 (2절)
7. 기록: 반품 사유 집계 → 상세 페이지·포장·검수 개선
```

### 반품률 줄이기
| 반품 사유 | 줄이는 법 |
|---|---|
| 생각과 크기·색이 다름 | 크기 비교 사진, 실제 색 사진, 상세 치수표 |
| 오배송 | 출고 검수, 옵션별 보관 위치 분리 |
| 파손 | 포장 개선, 택배사 변경 |
| 늦게 와서 | 출고 마감 시간 지키기, 지연 시 먼저 연락 |

> 💡 반품 사유를 매달 표로 보면 **상세 페이지 고칠 곳**이 보여요. 반품은 비용이 아니라 **공짜 고객 조사**이기도 해요.

---

### 이 장 요약
1. 상품 사진은 **대표·사용 장면·크기 비교·디테일**, 실제 색과 같게.
2. 재고는 **판매 가능 수량 = 실제 − 대기 중**, 다시 주문할 시점을 계산하고 **매달 실사**. 여러 채널은 재고 연동.
3. 택배는 **단가·반품 단가·보상 기준**을 비교해 계약, 출고는 **검수**가 핵심. 반품은 **법정 기한 안에 처리하고 사유를 집계**해 개선한다.
