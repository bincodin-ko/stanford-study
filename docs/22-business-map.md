# 22. 인터넷 사업 분류 지도 — 6가지 기준으로 나누기

1장에서는 **"누구에게 파는가"(B2B·B2C…)** 한 가지 기준만 봤어요.
실제로는 같은 사업도 **여러 기준**으로 동시에 분류할 수 있고, 기준마다 운영 방식이 달라집니다.

---

## 1. 6가지 분류 기준

| # | 기준 | 나뉘는 종류 | 이 기준이 정하는 것 |
|---|---|---|---|
| ① | **누구에게 파나** | B2C, B2B, C2C, B2B2C, D2C, B2G | 영업 방식, 결제 방식 (1·12장) |
| ② | **무엇을 파나** | 실물, 디지털 상품, 사람의 서비스, 소프트웨어, 정보·콘텐츠, 관심(광고) | 재고·배송·서버 부담 |
| ③ | **어떻게 버나** | 판매, 구독, 수수료, 광고, 후원, 사용량 과금 (2장) | 매일 볼 숫자 |
| ④ | **누가 콘텐츠·상품을 만드나** | 운영자 / 회원 / 판매자 / AI | 비용 구조, 관리할 대상 |
| ⑤ | **어디서 파나 (채널을 누가 갖나)** | 내 사이트 / 남의 플랫폼(오픈마켓, 유튜브, 앱스토어) | 수수료, 정책 변화 위험 |
| ⑥ | **규제 강도** | 신고만 / 등록·허가 필요 / 아예 금지 | 시작 가능 여부 (29장) |

### 예: "오목 사이트"를 6가지로 분류하면
| 기준 | 분류 |
|---|---|
| ① 누구에게 | B2C |
| ② 무엇을 | 소프트웨어(게임) + 관심(광고) |
| ③ 어떻게 | 광고 + 광고 제거 구독 + 꾸미기 아이템 |
| ④ 누가 만드나 | 운영자(게임) + 회원(대국 기록·커뮤니티) |
| ⑤ 어디서 | 내 사이트 (앱으로 내면 앱스토어 = 남의 플랫폼) |
| ⑥ 규제 | 게임 등급분류, 환전 금지 (20장) |

> 💡 새 사업 아이디어가 생기면 이 표를 먼저 채워 보세요. 채우기 어려운 칸이 곧 **아직 생각 안 해 본 위험**입니다.

### F. 규제가 아주 강한 분야 (29장)

### G. 사업 자체를 사고팔기
| 사업 | 설명 |
|---|---|
| **사이트 매매** | 방문자·수익이 있는 사이트를 키워서 팔거나, 사서 키우기. 보통 "월 순이익 × 몇 년치"로 값을 매기는 경우가 많아요 |
| **도메인 투자** | 좋은 주소를 미리 사 두고 팔기. 남의 **상표**와 비슷한 도메인을 선점해 팔면 분쟁·법적 문제 (사이버스쿼팅) |

> 사이트를 팔 때 사는 사람이 확인하는 것 = 이 자료에서 배운 것 전부예요: 트래픽 출처(18장), 수익 증빙, 코드·DB·도메인 소유권(5·6장), 운영 문서(9장), 법적 문제(10장). **잘 정리된 운영이 곧 사이트의 가격**이 됩니다.

## 3. 분류별 "가장 큰 위험" 한 줄 요약

| 분류 | 가장 큰 위험 |
|---|---|
| 물건 팔기 | 재고·배송·반품, 낮은 마진 |
| 콘텐츠·관심 팔기 | 플랫폼(검색·유튜브) 알고리즘 변화 |
| 지식·서비스 팔기 | 내 시간이 곧 상품 → 규모를 키우기 어려움 |
| 소프트웨어 팔기 | 개발·유지보수 비용, 장애 |
| 연결해 주기 | 양쪽 손님을 동시에 모으기, 거래 분쟁 책임 |
| 규제 분야 | 허가 없이 시작하면 형사처벌 |

---

### 이 장 요약
1. 사업은 **누구에게 · 무엇을 · 어떻게 · 누가 만드나 · 어디서 · 규제** 6가지로 동시에 분류된다.
2. 새 아이디어는 **6칸 표를 채워 보며** 위험을 찾는다.
3. 큰 분류는 **물건 / 콘텐츠 / 지식·서비스 / 소프트웨어 / 중개 / 규제 분야 / 사업 매매**.
