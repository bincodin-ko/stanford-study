# 19. 로또·운세·"번호 추천" 사이트 — 합법과 불법의 경계

로또 관련 사이트는 검색이 아주 많은 인기 주제예요. 그런데 **잘못 설계하면 바로 사기·불법**이 되는 대표 분야이기도 합니다.
이 장은 "어디까지가 정상적인 정보 사이트이고, 어디부터가 위험한가"를 배우는 장이에요.

> ⚠️ 2026년 10월 조사 기준입니다. 법 해석이 필요한 부분은 변호사·관계 기관에 확인하세요.

---

## 1. 먼저 알아야 할 사실: 로또 번호는 예측할 수 없다

- 로또 6/45는 매 회차 **공을 무작위로 추첨**합니다. 지난 번호가 다음 번호에 영향을 주지 않아요.
- 어떤 6개 번호 조합이든 1등 확률은 **8,145,060분의 1**로 똑같습니다. (45개 중 6개를 고르는 경우의 수)
- 그래서 "AI 분석으로 당첨 확률 UP", "1등 배출 N회" 같은 주장은 **과학적 근거가 없어요.** 이런 광고를 하는 유료 사이트들이 사기로 처벌받은 사례가 여럿 보도됐습니다(예: 번호 예측 사이트를 수십 개 운영하며 수백억 원을 챙긴 업체, "공 무게 조작으로 당첨 번호를 안다"며 돈을 받은 일당 실형).
- 금융감독원은 **"피해금을 돌려주겠다"며 또 돈을 뜯는 2차 사기**도 주의하라고 경고했어요.

---

## 2. 신호등으로 보는 로또 관련 사이트

| 신호 | 사이트 형태 | 판단 |
|---|---|---|
| 🟢 **괜찮음** | 역대 당첨 번호·통계 정리, 번호별 출현 횟수 그래프 | 공개 데이터를 정리한 **정보 사이트** |
| 🟢 | **무료 랜덤 번호 생성기** ("재미로 뽑아 보세요") | 단순 도구. "재미용, 당첨과 무관" 표시 |
| 🟢 | 당첨금 세금 계산기, 판매점 지도 | 유용한 도구 |
| 🟡 **주의** | "통계 기반 추천 번호" (무료) | 당첨 가능성이 높다고 **오해하게 만들면** 문제. 효과를 과장하지 않기 |
| 🟡 | 무료 번호를 미끼로 **전화번호 수집** | 개인정보를 모아 유료 영업 전화에 쓰는 패턴이 피해 사례에 자주 등장. 수집 목적 명확히, 마케팅 동의 분리 |
| 🔴 **위험/불법** | **유료** 회원제 "당첨 번호 예측", "당첨 보장·환불 보장" | 근거 없는 효과를 내세워 돈을 받으면 **사기, 허위·과장 광고** 문제 |
| 🔴 | 복권을 **대신 사 주는(구매 대행)** 서비스 | 복권은 정해진 판매처·공식 사이트에서만 팔 수 있어서 **허가 없이 팔거나 대행하면 불법** |
| 🔴 | 로또 번호로 돈을 거는 **사설 베팅** | **불법 도박** |

> 💡 판단 기준을 한 줄로: **"돈을 받고 당첨 가능성을 높여 준다고 말하는가?"** → 그렇다면 하지 마세요.

---

## 3. 🟢 정상적인 로또 정보 사이트를 만든다면

### 기능 예
- 회차별 당첨 번호·당첨금 조회
- 번호별 출현 빈도, 홀짝·합계 분포 그래프 (재미있는 통계)
- 랜덤 번호 생성기 (조건 설정: "1~10에서 2개 포함" 등)
- 당첨금 실수령액 계산기 (세금 공제)
- "내 번호 당첨 확인" (지난 회차에 넣어 보기)

### 운영 포인트
| 항목 | 내용 |
|---|---|
| 데이터 | 당첨 번호는 **공식 발표**를 기준으로. 매주 토요일 추첨 후 빠르게 업데이트 → 트래픽이 몰리는 시간 |
| 문구 | 모든 생성기·통계 화면에 **"과거 통계는 미래 당첨과 무관합니다. 재미로만 이용하세요."** |
| 수익 | 디스플레이 광고 (18장). 단, 도박성 주제로 분류되면 광고가 제한될 수 있음 → 광고 정책 확인 |
| 트래픽 패턴 | **토요일 저녁~일요일**에 폭증. 이 시간 서버가 멈추지 않게 (CDN, 캐시) |
| 사회적 책임 | 과도한 구매를 부추기지 않기. 도박 문제 상담 안내(한국도박문제예방치유원 1336) 링크를 두는 것도 좋은 습관 |

## 4. 비슷한 "운·예측" 분야 — 같은 원리

| 분야 | 🟢 정상 | 🔴 위험 |
|---|---|---|
| **운세·타로** | "재미로 보는" 오늘의 운세 + 광고 | 불안을 자극해 고액 부적·굿 판매 |
| **주식·코인 정보** | 공개 데이터 정리, 차트 도구 | 돈 받고 "종목 찍어 주기" → 자격 없는 투자자문·리딩방 사기 위험 |
| **스포츠 정보** | 경기 일정·기록·통계 | **불법 스포츠 도박 사이트** 홍보 배너 (큰돈을 준다고 연락이 와도 거절) |
| **게임 확률 정보** | 아이템 확률 정리 (20장) | 게임 계정·아이템 현금 거래 중개 → 게임 약관 위반, 일부는 불법 |

> ⚠️ 트래픽이 많은 정보 사이트를 운영하면 **불법 도박·성인 사이트에서 "배너 달아 주면 월 수백만 원"** 같은 제안이 자주 옵니다. 받는 순간 **도박 광고 방조**로 처벌받을 수 있고, 정상 광고(애드센스 등)도 끊깁니다.

---

### 이 장 요약
1. 로또 번호는 **예측 불가**. 모든 조합의 1등 확률은 같다.
2. **통계·랜덤 생성기·계산기 = 정보 사이트**로 OK. **유료 예측·구매 대행·베팅 = 위험/불법**.
3. "돈 받고 당첨(수익) 가능성을 높여 준다"고 말하는 순간 선을 넘는다.
