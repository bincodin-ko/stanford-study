# 71. 1인 사업자 세금·보험·신고 실무 — 경비 처리부터 각종 신고까지

> 세금 달력·장부·법인 전환은 [44장](44-money-accounting-entity.md), 사업자등록·통신판매업은 [10장](10-security-and-law.md), 직원 4대보험은 [70장](70-hiring-and-labor.md)에 있어요. 이 장은 **실제로 돈을 쓰고 신고할 때 자주 막히는 것들**이에요.

> ⚠️ 세금·보험 금액과 기준은 자주 바뀌고, 이 장은 **세무 블로그·기사 기준으로 조사**했어요. 신고 전에는 국세청 홈택스·공단 안내를 확인하고, 매출이 생기면 **세무사 상담**을 권해요. ([참고 자료 모음](sources.md))

---

## 1. 경비 처리 — "사업에 쓴 돈"을 인정받으려면

사업에 쓴 돈(경비)은 이익에서 빠져 **세금이 줄어요.** 대신 **증명**할 수 있어야 해요.

### 적격증빙 4가지
| 증빙 | 받는 법 |
|---|---|
| **세금계산서** (면세 품목은 계산서) | 사업자에게 살 때 내 사업자번호로 |
| **신용카드 매출전표** | 사업용 카드로 결제 (홈택스에 사업용 카드 등록하면 자동 수집) |
| **현금영수증 (지출증빙용)** | 현금·계좌이체 때 내 사업자번호로 발급 요청 |
| (간이영수증) | 소액일 때만 — 아래 규칙 참고 |

### 기억할 숫자 (조사 기준)
| 규칙 | 내용 |
|---|---|
| **건당 3만 원 초과** | 적격증빙 없이 계좌이체 내역 등만 있으면 비용은 인정될 수 있지만 **금액의 2% 가산세**(증빙불비 가산세) |
| **3만 원 이하** | 간이영수증도 가능 |
| **거래처 접대(기업업무추진비)** | 일반 경비보다 엄격. 건당 기준 초과 시 적격증빙 없으면 **비용 자체가 인정 안 될 수 있음** |
| **부가세 매입세액 공제** | 적격증빙이 있어야 사면서 낸 부가세를 돌려받을 수 있음 |
| **보관 기간** | 신고 기한 끝난 뒤 **5년** |

### 1인 개발·온라인 사업자가 흔히 쓰는 경비 예
| 경비 | 메모 |
|---|---|
| 호스팅·도메인·클라우드·AI API·디자인 도구 구독 | **해외 결제**는 카드 전표 + 결제 메일 보관 |
| 노트북·모니터 등 장비 | 금액이 크면 몇 년에 나눠 비용 처리(감가상각) |
| 광고비 | 플랫폼 세금계산서·영수증 발급 메뉴 확인 |
| 외주비 | 세금계산서 또는 3.3% 원천징수 신고 (44장) |
| 공유 오피스·사무실 임차료 | 계약서 + 세금계산서 |
| 업무용 통신비, 교육·도서 | 업무 관련성 |
| 택배·포장재 (72장) | |

- **사적인 지출을 섞지 마세요.** 사업용 통장·카드를 따로 쓰는 게 가장 쉬운 방법이에요(44장).
- 집에서 일하는 경우의 집세·관리비, 차량 비용은 인정 기준이 까다로워요. 세무사에게 물어보세요.

## 2. 간이과세 vs 일반과세

| | 간이과세자 | 일반과세자 |
|---|---|---|
| 대상 | 연 매출이 일정 기준 미만인 작은 개인사업자 (업종 제외 있음) | 그 외 |
| 부가세 부담 | 업종별로 낮게 계산돼 **적음** | 매출세액 − 매입세액 |
| 세금계산서 발급 | 매출 규모에 따라 못 하는 경우가 있음 → **B2B 거래처가 싫어할 수** 있음 | 가능 |
| 신고 | 1년에 1번 (원칙) | 1년에 2번 (원칙) |

- 기준 금액·제외 업종은 자주 바뀌어요. 사업자등록할 때 홈택스 안내를 확인하세요.
- **B2B 위주(12장)**거나 **초기에 장비·재고를 크게 사서 부가세를 돌려받아야** 한다면 일반과세가 나을 수 있어요.

## 3. 사장님 본인의 보험·노후 — 놓치기 쉬운 것

### 건강보험·국민연금
- 회사에 다니지 않는 1인 사업자는 보통 **지역가입자**로 건강보험·국민연금을 내요. **사업 소득이 신고되면 보험료가 바뀌어요**(다음 해에 반영되는 경우가 많아 "갑자기 올랐다"고 느껴요). 미리 예산에 넣으세요.
- **직원을 1명이라도 쓰면** 사업장 가입자가 되고, 대표도 사업장 가입자로 바뀌어요(70장).
- 회사를 다니면서 부업으로 사업하면 **소득이 일정 금액을 넘을 때** 추가 보험료가 붙을 수 있어요. 회사 규정의 **겸업 금지**도 확인하세요(57장).

### 노란우산공제 (소기업·소상공인 공제)
- 중소기업중앙회가 운영하는 **사장님 퇴직금** 같은 제도예요. 폐업·노령 때 받을 수 있고, 일반적으로 압류가 제한된다고 안내돼요.
- **소득공제**: 여러 자료에서 2026년 기준 **사업소득 4,000만 원 이하는 연 최대 600만 원**까지 공제된다고 해요. 소득 구간별 한도와 2026년 바뀐 **납입 한도**는 자료마다 달라 공식 사이트 확인이 필요해요.
- 중도 해지하면 불리할 수 있어요. 낼 수 있는 만큼만.

### 그 밖에
- **1인 자영업자 고용보험·산재보험**: 원하면 가입할 수 있는 제도가 있어요(폐업 시 실업급여 등). 조건은 공단 확인.
- 사업 보험(배상책임·사이버보험)은 56장.

## 4. 업종·서비스별 신고 목록 — 내가 해당하나?

| 신고 | 언제 필요 | 관련 장 |
|---|---|---|
| **사업자등록** | 계속 반복해서 돈을 벌면 | 10장 |
| **통신판매업 신고** | 온라인으로 물건·서비스 판매 (면제 기준 확인) | 10장 |
| **부가통신사업 신고** | 인터넷으로 통신을 매개하는 서비스(커뮤니티·플랫폼 등). 과기정통부 관계자 설명 기준 **자본금 1억 원 이하 소규모 사업자는 신고한 것으로 간주**돼요. 법인을 크게 키우면 다시 확인 | 16·27장 |
| **위치정보 관련 신고·허가** | 손님 위치를 수집·이용하는 서비스 | 27·29장 |
| **직업정보제공사업 신고 / 유료직업소개 등록** | 구인구직 서비스 | 27장 |
| **게임물 등급분류** | 게임 서비스 | 20장 |
| **식품·화장품·건강기능식품 등 영업 신고** | 해당 상품 판매 | 23·29장 |
| **전자금융 관련 등록** | 선불 충전금·포인트를 크게 운영 | 29·39장 |
| **개인정보 유출 신고** | 유출 시 72시간 안 (2026년 9월 개정 내용은 10장) | 10·37장 |

> 💡 새 기능을 넣을 때마다 이 표를 다시 보세요. **"위치 기능 하나 추가"가 신고 대상**이 되는 경우가 있어요.

## 5. 이벤트·경품을 줄 때의 세금

- 손님이 받는 경품은 보통 **기타소득**이에요. 안내 자료 기준, **건당 경품 가액이 5만 원을 넘으면** 주최자가 **22%(지방소득세 포함)를 원천징수**하고 신고하는 게 원칙이에요.
- 그래서 고가 경품 이벤트는 당첨자에게 **"제세공과금 22%를 내셔야 받을 수 있어요"** 또는 **주최자가 대신 부담**을 미리 공지해요.
- **5만 원 이하 경품**은 이 원천징수 대상이 아닌 경우가 많아요 → 작은 사업자는 **5만 원 이하 경품을 여러 개** 주는 게 관리가 쉬워요.
- 당첨자 개인정보(이름·연락처·주민번호)는 **세금 신고에 필요한 만큼만** 받고, 끝나면 파기 (10장).
- 이벤트 운영 규칙(당첨 기준·발표일 공지)은 32장, 73장.

## 6. 1인 사업자 세금·보험 연간 달력 (요약)

| 시기 | 할 일 |
|---|---|
| **매달** | 직원 있으면 원천세 신고·납부(10일), 4대보험, 증빙 정리 (44장 월간 루틴) |
| **1월** | 부가세 확정 신고(일반과세 2기·간이과세 1년치), 지급명세서 준비 |
| **5월** | 종합소득세 신고 (전년도 소득) |
| **7월** | 부가세 확정 신고(일반과세 1기) |
| 수시 | 경품 원천징수, 프리랜서 3.3% 신고, 신규 기능 신고 확인 |

> 💡 매출이 생기기 시작하면 **세무 기장(장부 대행)을 맡기는 비용**과 내가 쓰는 시간을 비교해 보세요. 실수로 내는 가산세보다 싼 경우가 많아요.

---

### 이 장 요약
1. 경비는 **적격증빙**으로: 건당 3만 원 넘으면 **세금계산서·카드·현금영수증**, 없으면 2% 가산세. 5년 보관, 사업용 카드·통장 분리.
2. 사장님 본인의 **건강보험·국민연금은 소득 신고 후 오른다** — 예산에 넣고, **노란우산공제** 소득공제(4,000만 원 이하 최대 600만 원)를 확인.
3. 새 기능마다 **신고 대상인지**(부가통신·위치정보·등급분류 등) 확인하고, **5만 원 넘는 경품은 22% 원천징수**.
