# 45. 지원금·투자·창업 지원사업

1인 창업은 **내 돈 → 매출 → (필요하면) 지원금·대출·투자** 순서로 생각하는 게 보통이에요.
이 장은 정부 지원사업과 투자를 **받는 법과 조심할 점**이에요.

> ⚠️ 지원사업은 **매년 공고가 바뀌어요.** 아래 금액·조건은 2026년 기사·블로그 기준이고, 공식 공고문 원문은 직접 보지 못했어요. 신청 전 **K-Startup(창업지원포털)의 해당 연도 공고문**을 꼭 확인하세요. ([참고 자료 모음](sources.md))

---

## 1. 돈을 구하는 방법 비교

| 방법 | 갚아야 하나 | 지분을 주나 | 특징 |
|---|---|---|---|
| **내 돈(부트스트래핑)** | — | 아니오 | 가장 자유로움. 작게 시작 (3장) |
| **매출** | — | 아니오 | 사전 판매·크라우드펀딩(23·42장)도 포함 |
| **정부 지원사업(지원금)** | 대부분 아니오 | 아니오 | 사업계획서 심사, 쓰는 곳 제한, 정산 서류 |
| **정책 대출** | **예** | 아니오 | 일반 대출보다 조건이 좋은 경우 많음 |
| **엔젤·액셀러레이터 투자** | 아니오 | **예** | 초기 회사에 소액 투자 + 교육·연결 |
| **벤처캐피털(VC) 투자** | 아니오 | **예** | 큰 성장을 기대할 때. 빠른 성장 압박 |

> 💡 **투자는 공짜 돈이 아니에요.** 회사의 일부를 파는 거예요. "작고 꾸준히 버는 사업"이 목표라면 투자보다 매출·지원사업이 더 맞을 수 있어요.

---

## 2. 대표적인 정부 창업 지원사업 (2026년 기사 기준)

| 사업 | 대상 | 지원 내용 (보도·블로그 기준) |
|---|---|---|
| **예비창업패키지** | 공고일 기준 **사업자등록·법인 설립을 하지 않은** 예비 창업자 | 사업화 자금 평균 약 4천만 원 수준이라는 안내 |
| **초기창업패키지** | 창업 1~3년 차 | 최대 1억 원(평균 7천만 원 내외)이라는 안내, 지역별 자부담 비율이 다를 수 있음 |
| **창업도약패키지 등** | 3~7년 차 | 성장 단계 지원 |
| 지자체·대학·공공기관 사업 | 지역·분야별 | 공간(입주), 시제품 제작, 교육, 판로 |

- 2026년엔 창업 지원이 단계별(예비·초기·도약 등)로 더 세분화됐다는 보도가 있어요.
- **신청 시기 주의**: 예비창업패키지는 대부분 **연초(2~3월)** 에 모집해요. 그리고 **사업자등록을 먼저 해 버리면 "예비 창업자" 자격을 잃을 수 있으니**, 지원을 노린다면 등록 시점을 공고와 맞춰 보세요.
- 매년 초 중소벤처기업부가 **창업지원사업 통합공고**를 내요 → 그해 사업 목록을 한 번에 볼 수 있어요.

### 지원금 받을 때 알아 둘 것
| 항목 | 내용 |
|---|---|
| **쓰는 곳이 정해짐** | 외주 개발, 시제품, 마케팅 등 승인된 항목만. 내 월급·개인 용도 ✕ |
| **증빙·정산** | 영수증·계약서·결과물 제출. 틀리면 환수될 수 있음 (44장 증빙 습관이 중요) |
| **자부담** | 일부는 내 돈(현금·현물)을 함께 넣어야 하는 경우 |
| **의무** | 중간·최종 평가, 교육 참여, 일정 기간 사업 유지 |
| **세금** | 지원금도 회계 처리 필요 → 세무사 확인 |

### 선정되는 사업계획서
→ [46장](46-business-plan-and-pitch.md)에서 자세히. 핵심은 **문제가 진짜인가(42장 검증 결과) + 내가 할 수 있나 + 돈을 어떻게 쓰고 무엇을 만들어 낼 건가**를 숫자와 증거로.

## 3. 정책 대출·보증 (간단히)

- 소상공인·중소기업 대상 정책 자금, 신용보증기관의 보증 대출 등이 있어요.
- **대출은 갚아야 해요.** 매출 계획이 확실할 때, 재고·장비처럼 돈을 버는 데 쓰일 때만.

## 4. 투자 받기 기초

### 투자의 흐름
```
엔젤·액셀러레이터 (시드) → 시리즈 A → 시리즈 B … 
  각 단계마다 회사 지분 일부를 팔고 돈을 받음
```

| 용어 | 쉬운 뜻 |
|---|---|
| **밸류에이션(기업가치)** | 회사가 지금 얼마짜리인지 정하는 값 |
| **지분 희석** | 투자를 받을 때마다 내 지분 비율이 줄어드는 것 |
| **액셀러레이터** | 초기 회사를 뽑아 소액 투자 + 교육·멘토링 (예: 국내외 창업 프로그램) |
| **IR** | 투자자에게 회사를 소개하는 활동·자료 (46장) |
| **텀시트** | 투자 조건 요약서 |
| **우선주·상환·청산 우선권** | 투자자에게 주는 특별 조건들 → **반드시 전문가와 검토** |

### 조심할 점
- **보통 법인이어야** 투자를 받을 수 있어요 (44장).
- "투자해 줄 테니 먼저 컨설팅비를 내라"는 제안은 **사기 의심**.
- 공동 창업자가 있다면 투자 전에 **지분·역할·떠날 때 규칙(베스팅)** 을 문서로 (53장).
- 투자 계약서는 **변호사 검토** 필수.

---

## 5. 1인 창업자를 위한 현실적인 순서

```
1. 내 돈으로 아주 작게 검증 (42장) — 랜딩 페이지·사전 판매
2. 첫 매출 만들기
3. 그해 지원사업 공고 확인 (연초) → 검증 결과를 넣은 사업계획서
4. 지원금으로 MVP 고도화·마케팅
5. 성장이 빠르고 더 큰 돈이 필요하면 → 법인 전환 → 투자 검토
```

---

### 이 장 요약
1. 돈 구하는 순서: **내 돈 → 매출 → 지원금·정책 대출 → 투자**. 투자는 지분을 파는 것.
2. 정부 지원사업은 **매년 공고가 바뀌니 K-Startup 원문 확인**, 예비창업패키지는 **사업자등록 전**이어야 하는 점 주의, 지원금은 **증빙·정산** 필수.
3. 투자는 보통 **법인**이 받고, 계약 조건은 **전문가 검토**, 선입금 요구는 사기 의심.
