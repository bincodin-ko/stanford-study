# 17. 정보·콘텐츠 사이트

**정보 사이트** = 사람들이 궁금한 걸 찾아오는 사이트. 손님은 "물건"이 아니라 **답**을 원합니다.

---

## 1. 정보 사이트의 종류

| 종류 | 예 | 특징 |
|---|---|---|
| **블로그/칼럼** | 여행 후기, 육아 정보, IT 리뷰 | 글 하나하나가 검색으로 사람을 데려옴 |
| **데이터·통계 사이트** | 로또 당첨 통계, 날씨, 주식 정보, 게임 전적 | 공개 데이터를 보기 좋게 정리 |
| **도구(툴) 사이트** | 글자 수 세기, 대출 이자 계산기, 연봉 실수령액 계산기, 이미지 변환 | 개발 한 번이면 계속 사람이 옴 |
| **모음·디렉토리** | "서울 무료 전시회 모음", "정부 지원금 총정리" | 흩어진 정보를 한곳에 |
| **비교·리뷰** | 요금제 비교, 제품 비교 | 제휴 수익(18장)과 잘 맞음 |
| **뉴스레터** | 매주 메일로 정리해서 보냄 | 검색 의존도가 낮음, 구독자가 자산 |
| **위키·Q&A** | 나무위키, 지식인 형태 | 커뮤니티(16장)와 섞인 형태 |

> 💡 **도구 사이트**는 초보 개발자에게 특히 좋은 연습 아이템이에요. 기능이 하나라 만들기 쉽고, "계산기" 같은 검색어는 매일 꾸준히 검색됩니다.

---

## 2. 정보 사이트가 사람을 모으는 원리

```
누군가 검색함 ("연봉 4000 실수령액")
  → 검색 결과에 내 페이지가 뜸 (SEO, 11장)
  → 클릭해서 들어옴 (트래픽)
  → 답을 얻음 + 광고를 봄 / 제휴 링크를 누름 (수익, 18장)
  → 북마크하거나 다시 옴 (재방문)
```

### 좋은 정보 페이지의 조건
1. **검색한 질문에 바로 답한다** — 맨 위에 결론. 서론이 길면 손님은 나갑니다.
2. **직접 해 본 경험·자료가 있다** — 사진, 실제 수치, 비교표.
3. **최신이다** — "2026년 기준" 표시, 정기 업데이트.
4. **출처가 있다** — 특히 돈·건강·법 정보.
5. **빠르고 모바일에서 보기 좋다.**

> 구글은 품질을 볼 때 **경험(Experience)·전문성(Expertise)·권위(Authoritativeness)·신뢰(Trust)** 를 중요하게 봅니다(흔히 E-E-A-T라고 줄여 불러요). 특히 돈·건강처럼 삶에 큰 영향을 주는 주제에서 더 엄격해요.

---

## 3. 지금 정보 사이트가 겪는 큰 변화: AI 검색

- 검색 결과 맨 위에 **AI 요약 답변**이 뜨면서, 사람들이 링크를 덜 누르게 됐어요.
- 여러 조사(2025년)에서 AI 요약이 있을 때 **클릭률이 크게 떨어졌다**는 결과가 나왔습니다. 예: 미국 Pew 리서치 조사에서는 AI 요약이 없을 때 결과 링크 클릭이 15%, 있을 때 8%. (구글은 이런 조사 방법에 반박하고 있어서, 정확한 크기는 조사마다 다릅니다.)

그래서 요즘 정보 사이트 전략
| 약해진 것 | 강해진 것 |
|---|---|
| "OO란?" 같은 단순 정의 글 | **직접 해 본 후기, 독자적 데이터, 계산기 같은 도구** |
| 검색에만 의존 | **뉴스레터·커뮤니티·SNS로 직접 구독자 확보** |
| 글을 대량으로 찍어내기 | 적게, 깊게, 자주 업데이트 |

---

## 4. 하지 말아야 할 것 — 검색 스팸

구글은 2024년부터 아래 행동을 **스팸 정책**으로 명시하고, 걸리면 순위를 크게 내리거나 검색에서 아예 빼 버립니다.

| 스팸 유형 | 쉬운 설명 |
|---|---|
| **대량 저품질 콘텐츠(Scaled content abuse)** | 순위만 노리고 비슷한 글을 수백~수천 개 찍어내기. **사람이 쓰든 AI가 쓰든 똑같이** 적용 |
| **사이트 평판 악용** | 유명 사이트 한구석을 빌려 관련 없는 광고성 글을 올리기 |
| **만료 도메인 악용** | 예전에 유명했던 도메인을 사서 엉뚱한 저품질 글로 채우기 |
| 키워드 도배, 숨긴 텍스트, 링크 사고팔기 | 고전적인 수법 |

> 💡 "AI로 글 1,000개 자동 생성해서 애드센스" 같은 방법은 **위의 첫 번째 정책에 정면으로 걸리는** 대표 사례입니다.

## 5. 정보 사이트 운영 루틴

| 주기 | 할 일 |
|---|---|
| 매일/매주 | 새 글 1~3개, 댓글·문의 답변 |
| 매주 | 서치 콘솔에서 어떤 검색어로 들어왔는지 확인 → 그 주제 글 보강 |
| 매월 | **오래된 글 업데이트**(가격·법·연도), 깨진 링크 정리, 수익 페이지 점검 |
| 분기 | 방문이 0인 글 정리(합치거나 삭제), 백업 확인 |

### 콘텐츠 계획표 예 (엑셀 한 장이면 충분)
| 제목 | 목표 검색어 | 상태 | 발행일 | 마지막 업데이트 |
|---|---|---|---|---|
| 2026 연봉 실수령액 표 | 연봉 실수령액 | 발행 | 2026-01-05 | 2026-07-01 |
| 전세 vs 월세 계산기 | 전월세 전환 계산 | 작성 중 | — | — |

## 6. 저작권 — 정보 사이트가 자주 걸리는 곳

- 남의 글·사진·표를 **통째로 복사**하면 저작권 침해. 짧게 인용하고 **출처 표시**, 핵심은 내 말로.
- 무료 이미지라도 **라이선스 조건**(상업 사용 가능? 출처 표시 필요?) 확인.
- 공공 데이터는 **공공데이터포털(data.go.kr)** 처럼 이용 조건이 공개된 곳에서 받기.
- 다른 사이트 데이터를 자동으로 긁어 오는 것(크롤링)은 **이용약관·법적 분쟁 위험**이 있으니 공식 API를 우선.

---

### 이 장 요약
1. 정보 사이트는 **검색 → 답 → 광고/제휴** 구조.
2. AI 검색 시대에는 **직접 경험, 독자 데이터, 도구, 구독자**가 강하다.
3. **대량 찍어내기는 스팸**. 적게, 깊게, 꾸준히 업데이트.
