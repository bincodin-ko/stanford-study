# 62. 브랜딩·출시 홍보·언론 보도·인플루언서

> 채널별 운영은 [32장](32-marketing-channels.md), 실제 사례는 [33장](33-marketing-by-field-and-cases.md)·[57장](57-vibe-coding-money-cases.md), 광고를 **받는** 쪽은 [31장](31-ad-and-partnership-inquiries.md)에 있어요. 이 장은 **알리는 쪽**의 심화예요.

> ⚠️ 협찬·광고 표시 규칙은 법이 정한 것이고, **2025년 12월에 바뀌었어요**(4절). 실제로 진행할 때는 공정거래위원회 안내서 원문을 확인하세요. ([참고 자료 모음](sources.md))

## 1. 포지셔닝 — "누구에게, 무엇보다 나은가"

**포지셔닝** = 손님 머릿속에서 내 상품이 차지할 **자리**를 정하는 일이에요. 광고 문구·디자인·가격이 모두 여기서 나와요.

포지셔닝 전문가 에이프릴 던포드(April Dunford)가 책 『Obviously Awesome』에서 제시한 순서를 쉽게 줄이면 이래요.

| 순서 | 질문 | 그래놀라랩 예 |
|---|---|---|
| ① **대안** | 내 상품이 없으면 손님은 **지금 무엇을** 쓰나? | 편의점 빵, 대기업 시리얼, 굶기 |
| ② **나만의 특징** | 대안에 없는 내 특징은? | 무설탕, 성분 7가지만, 소량 생산 |
| ③ **그래서 얻는 가치** | 그 특징 덕분에 손님이 얻는 것은? | 아침 혈당 걱정 없이 5분 식사 |
| ④ **가장 반길 손님** | 그 가치를 **가장 크게** 느끼는 사람은? | 성분표를 보는 30대 직장인 |
| ⑤ **분류(카테고리)** | 손님이 "아, 그런 거구나" 하고 이해할 분류는? | "시리얼"보다 "무설탕 아침 식사" |

> 💡 첫 단계가 **경쟁사가 아니라 "대안"**이라는 점이 중요해요. 손님의 진짜 경쟁자는 "엑셀", "그냥 참기", "친구에게 물어보기"인 경우가 많아요.

### 포지셔닝 한 문장 (빈칸 채우기)
```
[④ 손님]을 위한, [⑤ 분류]입니다.
[① 대안]과 달리, [② 특징] 덕분에 [③ 가치]를 얻을 수 있어요.
```
> 예) **성분표를 꼼꼼히 보는 직장인**을 위한 **무설탕 아침 식사**예요. **편의점 빵**과 달리 **성분 7가지만** 써서 **아침 혈당 걱정 없이 5분 만에** 먹을 수 있어요.

이 문장은 **내부용**이에요. 손님에게는 이걸 바탕으로 짧은 **문구**(48장 카피)를 써요.

## 2. 브랜딩 — 작은 사업자가 할 수 있는 만큼만

**브랜드** = 손님이 내 이름을 들었을 때 **떠올리는 느낌과 약속**이에요. 로고가 브랜드의 전부는 아니에요.

| 해야 할 것 | 내용 |
|---|---|
| **이름** | 부르기·검색하기 쉽게, **상표 검색 먼저**(47장), 도메인·SNS 아이디 확인(34장) |
| **말투** | "친근한 반말 / 정중한 존댓말" 등 하나로. 상세 페이지·답변·SNS 모두 같은 말투 |
| **색·글꼴** | 색 2~3개, 글꼴 1~2개를 정해 **모든 곳에서 똑같이** (48장 디자인 시스템) |
| **약속 하나** | "성분을 숨기지 않는다", "하루 안에 답한다"처럼 **지킬 수 있는** 약속 |
| **창업자 이야기** | 왜 시작했나. 1인 사업자의 가장 큰 무기예요 |

> 💡 브랜드는 **일관성**에서 생겨요. 멋진 로고보다 **같은 말투·같은 색·같은 약속을 1년 지키는 것**이 더 강해요. 브랜드가 생기면 **가격 경쟁에서 벗어나기** 쉬워져요(43장).

## 3. 출시 홍보 — 첫날에 사람을 모으는 법

### 출시 전 4~6주: 기다리는 사람 만들기
```
□ 소개 페이지 + 이메일 받기 (42장 랜딩 페이지)
□ 만드는 과정을 SNS·블로그에 공개 (57장 빌드 인 퍼블릭)
□ 관련 커뮤니티에서 먼저 도움 되는 활동 (홍보만 하러 가면 차단돼요)
□ 첫 손님 후보 10~30명에게 직접 연락 → 출시 알림 약속
□ 출시일, 할인·선착순 혜택 정하기
```

### 출시를 알릴 곳
| 곳 | 어떤 사람들 | 팁 |
|---|---|---|
| **프로덕트 헌트** (해외) | 새 서비스를 찾는 개발자·창업자 | 아래 참고 |
| **해커 뉴스 "Show HN"** (해외) | 개발자 | 기술적인 이야기, 과장 없는 소개 |
| **인디 해커스** (해외) | 1인 창업자 | 출시 회고 글(숫자 공개)이 반응 좋음 |
| **디스콰이엇** 등 국내 메이커 커뮤니티 | 국내 IT 창업자·개발자 | 만든 과정과 배운 점 |
| **분야 커뮤니티** (카페·디스코드·레딧) | 내 진짜 손님 | **규칙 확인** 후, 도움 되는 글 속에 자연스럽게 |
| **기존 이메일 명단·SNS** | 이미 관심 있는 사람 | 가장 반응이 좋아요 |

### 프로덕트 헌트 출시 요령 (2026년 가이드 글들 기준)
- 미국 태평양 시간 **자정 직후**에 하루가 시작돼요(한국 시간 오후 4~5시). 그때 올려야 24시간을 다 써요.
- **화·수요일**을 많이 추천해요. 4~6주 전부터 준비.
- **첫 댓글**(누구를 위해, 왜 만들었나)을 미리 써 두고, 출시 당일 **댓글에 몇 분 안에 답해요.**
- **추천(업보트)을 조직적으로 사고팔거나 부탁해 몰아주면 불이익**을 받는다고 해요. 투표보다 **대화**에 집중.
- 기대치: 첫날 방문은 일부일 뿐이고, **후기·링크·첫 손님 대화**가 남는 가치예요.

> ⚠️ 해외 사이트는 **영어 페이지·해외 결제**가 준비돼야 의미가 있어요(52장).

## 4. 언론 보도 — 보도자료 쓰고 보내기

작은 사업도 **"뉴스가 되는 이야기"**가 있으면 기사가 나올 수 있어요. 기사는 **신뢰**(상세 페이지에 "○○ 보도")와 **검색 노출**에 도움이 돼요.

### 뉴스가 되는 소재
- 숫자 성과: "출시 3개월 만에 회원 1만 명"
- 새로운 시도: "AI로 혼자 만든 동네 예약 서비스"
- 사회 문제 해결, 지역 이야기
- 투자 유치, 지원사업 선정(45장), 수상
- 계절·이슈와 연결: "수능 앞두고…"

### 보도자료 구조
```
제목: 핵심 성과 하나 + 짧은 설명
  예) "무설탕 그래놀라 '그래놀라랩', 출시 6개월 만에 재구매율 38%"
부제: 한 줄 보충
첫 문단: 누가·언제·무엇을·왜 (이것만 읽어도 기사가 되게)
본문: 배경, 숫자, 손님 반응
대표 인용: "○○ 대표는 '…'라고 말했다."
회사 소개: 2~3줄
연락처: 담당자 이름·전화·이메일
첨부: 고화질 사진 2~3장 (사용 허락된 것)
```
- **한 자료에 주제 하나.** 여러 소식을 섞으면 기사화되기 어렵다고 해요.
- 문장은 짧게, 숫자는 **사실만**. 과장하면 신뢰를 잃어요.

### 보내는 법
| 방법 | 내용 |
|---|---|
| **직접 보내기** | 최근 1~2개월 안에 **비슷한 분야 기사를 쓴 기자**를 찾아 목록을 만들고 이메일로. 여러 명에게 보낼 땐 **숨은 참조(BCC)** |
| **배포 서비스** | 뉴스와이어 같은 유료 배포 서비스에 등록 |
| **보내는 시간** | 오전 8~9시 전후를 많이 권해요(편집 회의 전). 마감 시간대 전화는 피하기 |
| **본문에 바로** | 첨부 파일만 보내면 잘 안 열어 본대요. **메일 본문에 내용을 바로** 넣기 |

- 보낸 뒤 포털에서 기사 확인 → 내 사이트 "언론 보도"에 링크.
- **돈을 받고 기사처럼 써 주는 광고(기사형 광고)**는 광고임을 표시해야 하는 경우가 많아요. 일반 기사인 척하면 문제가 될 수 있어요.

## 5. 인플루언서·체험단 — 맡기는 쪽의 실전

### 진행 순서
```
1. 목표 정하기: 판매? 후기 모으기? 이름 알리기?
2. 찾기: 팔로워 수보다 "내 손님과 같은 사람들이 보는가", 댓글이 진짜인가
3. 제안: 무엇을 주고(제품·원고료·판매 수수료) 무엇을 바라는지
4. 계약: 아래 표
5. 진행: 광고 표시 확인, 과장 표현 확인
6. 성과 보기: 전용 할인 코드·UTM 링크로 판매 수 확인
```

### 찾을 때 확인할 것
| 확인 | 왜 |
|---|---|
| 팔로워 대비 댓글·좋아요 비율 | 가짜 팔로워 구별 |
| 댓글 내용 | "멋져요👍"만 반복되면 의심 |
| 최근 협찬 비율 | 광고만 올리는 계정은 효과가 약해요 |
| 내 손님층과 맞는가 | 2만 명의 **딱 맞는** 사람 > 50만 명의 엉뚱한 사람 (흔히 "마이크로 인플루언서") |

### 계약서에 넣을 것
| 항목 | 예 |
|---|---|
| 내용·횟수·일정 | 릴스 1개, 11월 10일까지 |
| 대가 | 제품 제공 / 원고료 ○원 / 판매당 ○% |
| **광고 표시 방법·위치·문구** | **제목이나 첫 부분**에 "광고", "협찬" (실무에서 가장 많이 빠뜨리는 항목이라고 해요) |
| 금지 표현 | 효능 과장, "최고·1위" 같은 근거 없는 표현 |
| 수정 요청 범위 | 사실 오류만 / 사전 검토 1회 |
| 게시 유지 기간 | 최소 ○개월 |
| 2차 활용 | 그 영상을 **내 광고에 써도 되는지**, 기간 |
| 책임 | 표시 의무 위반 시 책임 분담 |

### 광고 표시 규칙 (2025년 12월 개정 지침 기준, 보도·법률 해설 정리)
- 대가(제품·돈·할인·수수료 등)를 받은 후기·추천은 **경제적 이해관계를 밝혀야** 해요(뒷광고 금지).
- 표시 위치가 **"제목 또는 첫 부분"**으로 바뀌었어요. (예전엔 첫 부분 또는 끝 부분도 허용)
- "체험단", "Thanks to"처럼 **애매한 표현은 안 돼요.** "광고", "협찬", "○○로부터 제품과 원고료를 받음"처럼 분명하게.
- 플랫폼별 예: 유튜브는 제목·영상 시작 부분, 인스타그램은 사진(영상) 안에도.
- **광고주도 책임**을 질 수 있어요. 인플루언서가 표시를 빼먹거나 과장했는데 방치하면 함께 제재될 수 있어요.
- 2026년 4월, **AI 가상 인물이 추천하는 광고는 가상 인물임을 표시**하게 하는 개정안이 행정예고됐어요. 확정 여부는 확인하지 못했어요.

> ⚠️ 18장(제휴 링크)과 32장(협찬)의 "글 맨 위나 링크 가까이" 설명은 개정 전 기준이에요. 지금은 **제목이나 첫 부분**으로 맞추세요.

---

### 이 장 요약
1. 포지셔닝은 **대안 → 나만의 특징 → 가치 → 가장 반길 손님 → 분류** 순서로. 브랜드는 **같은 말투·색·약속을 오래 지키기**.
2. 출시는 **4~6주 전부터 기다리는 사람**을 만들고, 내 손님이 있는 커뮤니티·출시 플랫폼에 **대화하듯** 알린다. 보도자료는 **주제 하나, 첫 문단에 핵심**.
3. 인플루언서는 **팔로워 수보다 손님층 일치**, 계약서에 **광고 표시 위치·문구**를 꼭 쓰고, 표시는 **제목이나 첫 부분**에 분명하게.
