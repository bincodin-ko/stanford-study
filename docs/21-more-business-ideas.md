# 21. 다양한 인터넷 사업 아이템 비교

지금까지 본 것들을 포함해, 혼자 또는 작은 팀이 시작할 수 있는 인터넷 사업들을 한 표로 비교합니다.

> 더 많은 분류(오픈마켓 셀러, 크리에이터, 앱, 강의·외주, 중개 플랫폼, AI 서비스, 규제 업종)는 [22장 분류 지도](22-business-map.md)에서 이어집니다.

> 별점은 일반적인 경향을 나타낸 **대략적인 비교**예요. 같은 아이템이라도 주제·실력에 따라 크게 달라집니다.

| 아이템 | 수익 모델 | 시작 난이도 | 개발 필요 | 돈 벌기까지 | 운영 부담 | 법·정책 위험 |
|---|---|---|---|---|---|---|
| **정보 블로그** (17장) | 광고·제휴 | ★ | 거의 없음 | 느림 (수개월~) | 중간 (꾸준한 글) | 낮음 |
| **도구(계산기) 사이트** (17장) | 광고 | ★★ | 조금 | 중간 | 낮음 | 낮음 |
| **커뮤니티** (16장) | 광고·멤버십 | ★★ | 조금 (솔루션) | 느림 | **높음 (사람 관리)** | 중간 (게시물 책임) |
| **뉴스레터** | 구독료·스폰서 | ★ | 없음 | 중간 | 중간 | 낮음 |
| **디지털 상품** (템플릿, 전자책, 강의) | 판매 | ★ | 없음 | 빠름~중간 | 낮음 | 낮음 (저작권 주의) |
| **쇼핑몰** (13장) | 판매 | ★★ | 없음 (빌더) | 빠름 | 높음 (재고·배송·CS) | 중간 |

## 2. 나에게 맞는 아이템 고르기

```
Q1. 코딩을 할 수 있나?
 ├─ 아니오 → 정보 블로그 / 뉴스레터 / 디지털 상품 / 빌더 쇼핑몰
 └─ 예 →
    Q2. 운영(사람 상대)에 쓸 시간이 많나?
     ├─ 적다 → 도구(계산기) 사이트 / 캐주얼 게임 / 통계 정보 사이트
     └─ 많다 → 커뮤니티 / 대전 게임 / SaaS
```

### 처음 시작하는 사람에게 추천하는 조합
1. **내가 좋아하는 좁은 주제** 하나 정하기 (예: 오목)
2. 그 주제의 **정보 사이트 또는 도구**로 시작 (오목 규칙·기보 정리, 오목 AI 연습판)
3. 사람이 모이면 **커뮤니티** 기능 추가 (질문 게시판, 대회)
4. 더 모이면 **게임·유료 상품**으로 확장

→ 한 주제 안에서 **정보 → 커뮤니티 → 게임/상품**으로 키워 가면 앞 단계의 트래픽이 다음 단계의 첫 손님이 됩니다.

## 3. 어떤 아이템이든 공통으로 지켜야 할 것

| 원칙 | 관련 장 |
|---|---|
| 운영 사이트를 직접 고치지 않는다 (스테이징 → 배포) | 6·7장 |
| 코드·DB·파일을 각각 백업하고 복구 훈련 | 8장 |
| 모니터링 + 장애 대응 절차 | 9장 |
| 개인정보 최소 수집, 처리방침 게시 | 10장 |
| 숫자(지표)로 판단 | 11장 |
| **돈과 운(도박·예측)이 엮이는 구조는 특히 조심** | 19·20장 |

---

## 4. 하면 안 되는 "쉬워 보이는 돈벌이"

| 유혹 | 왜 안 되나 |
|---|---|
| AI로 글 수천 개 자동 생성 + 광고 | 검색 스팸 정책 위반 → 검색에서 사라짐 (17장) |
| 트래픽 구매, 클릭 유도 | 광고 계정 정지, 수익 몰수 (18장) |
| 불법 도박·성인 사이트 배너 | 형사 처벌 위험 (19장) |
| 유료 로또 번호 예측 | 사기·허위광고 (19장) |
| 이기면 돈 주는 게임, 게임머니 환전 | 도박·게임법 위반 (20장) |
| 영화·만화·스포츠 중계 불법 링크 모음 | 저작권 침해, 사이트 차단 |
| 남의 콘텐츠 통째 복사 | 저작권 침해 (17장) |

---

### 이 장 요약
1. 시작이 쉬운 건 **블로그·뉴스레터·디지털 상품**, 어려운 건 **SaaS·플랫폼**.
2. **좁은 주제 하나로 정보 → 커뮤니티 → 게임/상품** 순서로 키우는 전략이 좋다.
3. "쉬워 보이는 돈벌이"의 대부분은 **정책 위반이거나 불법**이다.
