# 27. 매칭·예약·중개 플랫폼

"사람과 사람", "손님과 가게"를 **연결해 주고** 수수료나 이용료를 받는 사업들이에요.
1장에서 본 **양면 시장**(양쪽 손님을 동시에 모아야 함)이 가장 직접적으로 나타나는 분야입니다.

> ⚠️ 이 분야는 업종마다 **별도 신고·등록·허가**가 필요한 경우가 많아요. 2026년 10월 조사 기준이며, 사업 모델이 정해지면 관계 기관이나 전문가에게 꼭 확인하세요.

---

## 1. 종류

| 분야 | 연결하는 대상 | 예 | 수익 |
|---|---|---|---|
| **구인구직·인력 매칭** | 회사 ↔ 구직자, 고객 ↔ 전문가 | 채용 사이트, 알바 앱, 청소·이사 고수 매칭 | 공고 게재료, 소개 수수료 |
| **예약·O2O** | 손님 ↔ 가게 | 미용실·식당·숙소·병원 예약 | 예약 수수료, 가게 월 이용료, 광고 |
| **중고거래(C2C)** | 개인 ↔ 개인 | 중고 장터 | 광고, 안전결제 수수료, 끌어올리기 |
| **만남·데이팅** | 사람 ↔ 사람 | 소개팅 앱 | 유료 구독, 아이템 |
| **전문가 상담** | 손님 ↔ 전문가 | 법률·세무·심리 상담 연결 | 수수료 (단, 전문직 광고 규제 주의) |

> **O2O** = Online to Offline. 온라인에서 예약·결제하고 오프라인(실제 가게)에서 서비스를 받는 것.

---

## 2. 중개 플랫폼의 공통 숙제

### ① 닭이 먼저냐 달걀이 먼저냐
- **한쪽부터 확보**: 예약 앱이면 먼저 **한 동네의 가게 30곳**을 직접 발로 뛰어 등록 → 손님이 "쓸 만하다" 느낄 만큼 채우기.
- **지역·분야를 좁게**: "전국 모든 예약" 대신 "○○동 네일숍 예약".
- 운영자가 초반엔 **직접 공급자 역할**을 하기도 함 (16장 커뮤니티의 씨앗 콘텐츠와 같은 원리).

### ② 신뢰 — 모르는 사람끼리 거래하게 만들기
| 장치 | 설명 |
|---|---|
| **본인 확인** | 휴대폰 인증, 사업자 확인 |
| **리뷰·평점** | 거래 후 서로 평가 |
| **안전결제(에스크로)** | 돈을 플랫폼이 잠시 맡았다가 거래 완료 후 전달 (10장) |
| **신고·차단** | 사기·비매너 사용자 제재 (16장) |
| **분쟁 처리 절차** | 환불·취소 기준을 미리 공개 |

### ③ 플랫폼 밖 직거래 (탈중개)
- 한번 연결되면 수수료를 피하려고 **플랫폼 밖에서 직접 거래**하는 문제.
- 대응: 플랫폼 안에서 거래해야 얻는 혜택(안전결제, 보증, 일정 관리, 리뷰 쌓기)을 크게 만들기.

### ④ 중개자의 법적 책임
- 온라인 장터를 운영하며 거래를 연결하는 사업자는 전자상거래법상 **통신판매중개자**로서, **"우리는 중개자이고 판매 당사자가 아니다"** 를 알리고, 판매자 정보를 확인·제공하는 등의 의무가 있어요.
- 분쟁이 생기면 **불만 접수와 해결 절차**를 운영해야 해요.

## 3. 분야별로 따로 확인할 법

| 분야 | 확인할 것 (요약) |
|---|---|
| **구인구직** | 구인·구직 **정보만 게시**하는 사업은 **직업정보제공사업 신고**, 직접 고용계약을 **알선하고 소개료를 받으면 유료직업소개사업 등록**이 필요한 구조라고 안내돼요(직업안정법). 등록 없이 유료 소개를 하면 형사처벌될 수 있어요. 구인 광고를 올리는 회사의 **사업자 확인 의무**도 강화됐다는 설명이 있어요 (가짜 구인 광고 사기 방지) |
| **결혼 목적 만남** | 결혼을 목적으로 소개하고 돈을 받는 사업은 **결혼중개업법** 적용 대상(신고·등록)일 수 있어요. 일반 소개팅 앱과 경계가 애매하면 확인 필요 |
| **데이팅 앱 일반** | **청소년 이용 차단**(나이 확인), 위치 정보를 쓰면 **위치정보법** 신고, 성매매·사기 방지 모니터링 |
| **숙박·여행 예약** | 숙박업은 **영업 신고된 숙소**만 연결해야 안전해요(미신고 숙소 중개 문제). 여행 상품을 직접 기획·판매하면 **여행업 등록** 대상일 수 있음 |
| **병원·의료 예약** | 의료 광고 규제, 환자 유인 금지 등 **의료법** 이슈 (29장) |
| **법률·세무 상담 연결** | 변호사·세무사 등 전문직은 **수수료를 받고 사건을 소개하는 것이 금지**된 경우가 있어 사업 구조 설계가 중요 |
| **중고거래** | 판매 금지 품목(의약품·주류·담배 등, 29장) 거래 차단, 사기 대응 |
| **위치 기반 서비스** | 사용자 위치를 쓰는 서비스는 위치정보법상 신고 대상일 수 있음 |

---

## 4. 중개 플랫폼 지표

| 지표 | 뜻 |
|---|---|
| **GMV** | 플랫폼에서 오간 총 거래액 (3장) |
| **Take rate** | 거래액 중 플랫폼 몫 (3장) |
| **매칭 성공률** | 요청 중 실제 연결된 비율 |
| **유동성** | 손님이 원할 때 공급자가 있는 정도 ("예약하려는데 가능한 가게가 있나") |
| **양쪽 재방문율** | 손님도 가게도 다시 오나 |
| 분쟁·신고 비율 | 신뢰 상태 |

---

### 이 장 요약
1. 중개 플랫폼은 **한쪽 먼저, 좁은 지역·분야부터** 채운다.
2. **신뢰 장치(본인 확인·리뷰·안전결제·분쟁 처리)** 가 곧 상품이다.
3. 구인구직·결혼중개·숙박·의료 등은 **업종별 신고·등록**을 먼저 확인한다.
