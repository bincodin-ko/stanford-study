# 64. 이메일·카카오톡 자동 마케팅 — 손님 행동에 맞춰 알아서 보내기

> 광고 메일·문자 법 규칙은 [30장](30-inquiries-and-email.md), 단골·재구매 분석은 [51장](51-retention-and-analytics.md)에 있어요. 이 장은 **자동으로 보내는 흐름을 설계**하는 법이에요.

**자동 메시지(자동화 마케팅)** = 손님이 **어떤 행동을 하면**(가입, 장바구니에 담고 떠남, 구매 후 30일) 미리 만들어 둔 메시지가 **알아서** 나가게 하는 것이에요.

1인 사업자에게 특히 좋은 이유: **한 번 만들어 두면 자는 동안에도** 손님을 챙겨요(54장 자동화).

> ⚠️ 카카오 메시지 상품은 **2025년 말에 바뀌었어요**(3절). 금액·규격은 대행사(딜러사) 블로그 기준이라, 실제 발송 전에 카카오 비즈니스 공식 안내를 확인하세요. ([참고 자료 모음](sources.md))

---

## 1. 먼저 구분 — 정보성 메시지 vs 광고성 메시지

| | 정보성 | 광고성 |
|---|---|---|
| 내용 | 주문 확인, 결제 완료, 배송 출발, 비밀번호 변경, 예약 안내 | 할인, 신상품, 이벤트, "다시 구경하세요" |
| 동의 | 거래에 필요하면 별도 광고 동의 없이 가능 | **마케팅 수신 동의를 받은 사람에게만** |
| 표시 | — | **(광고) 표시, 수신거부 방법**, 야간(흔히 오후 9시~오전 8시) 별도 동의 (30장) |
| 카카오 상품 | **알림톡** | **브랜드 메시지** |

> ⚠️ **정보성 메시지에 쿠폰·광고를 끼워 넣으면 광고 메시지**가 돼요(30장). "장바구니에 담은 상품이 기다려요"처럼 **구매를 권하는 메시지는 광고성**으로 보는 게 안전해요.

## 2. 꼭 만들어 둘 자동 흐름 6가지

| # | 흐름 | 시작 조건 | 보내는 것 (예) | 성격 |
|---|---|---|---|---|
| 1 | **환영** | 회원가입·뉴스레터 구독 | ① 바로: 환영 + 브랜드 이야기 ② 2일 뒤: 인기 상품·사용법 ③ 5일 뒤: 첫 구매 혜택 | ①②는 내용에 따라, ③은 광고성 |
| 2 | **장바구니 이탈** | 담고 1~24시간 동안 구매 안 함 | ① 1시간 뒤: "담아 두신 상품" ② 1일 뒤: 후기·배송 정보 ③ (선택) 3일 뒤: 작은 혜택 | **광고성** |
| 3 | **구매 후 안내** | 결제 완료 | 주문 확인 → 배송 출발 → 도착 후 사용법 | **정보성** |
| 4 | **후기 요청** | 배송 완료 3~7일 뒤 | 후기 부탁 (보상은 공정하게, **좋은 후기에만 보상 금지**) | 내용에 따라 |
| 5 | **재구매 알림** | 소모품 다 쓸 때쯤 (예: 30일 분량이면 25일 뒤) | "곧 떨어질 때예요" + 다시 주문 링크 | **광고성** |
| 6 | **다시 돌아오기** | 60~90일 동안 방문·구매 없음 | 새 소식, 그동안 바뀐 점, 복귀 혜택 | **광고성** |

### 흐름 그림 (장바구니 이탈 예)
```
장바구니 담음
   │ 1시간 동안 결제 없음
   ▼
[메시지 1] 담아 두신 상품이 있어요 ──── 결제함 → 흐름 종료 ✅
   │ 1일 동안 결제 없음
   ▼
[메시지 2] 이런 후기가 있어요 + 배송 안내 ── 결제함 → 종료 ✅
   │ 3일 동안 결제 없음
   ▼
[메시지 3] (선택) 첫 구매 무료 배송 ──────── 결제함 → 종료 ✅
   │
   ▼
흐름 끝 (더 보내지 않기)
```

**꼭 지킬 규칙**
- 손님이 **목표 행동을 하면 바로 흐름에서 빼기** (이미 샀는데 "아직 안 사셨네요"는 최악)
- **보내는 횟수 제한**: 여러 흐름이 겹쳐 하루에 메시지 3개가 가지 않게
- **할인을 습관으로 만들지 않기**: 매번 장바구니 할인을 주면 손님이 일부러 담고 기다려요
- 광고성 메시지는 **동의한 사람에게만**, 동의 여부를 **DB에 칸으로** 저장(59장)

## 3. 카카오톡 메시지 — 2026년 기준

| 상품 | 용도 | 받는 사람 | 보내는 법 |
|---|---|---|---|
| **알림톡** | 주문·결제·배송·예약 같은 **정보성** | 거래한 손님 (카카오 채널 친구가 아니어도) | **미리 심사받은 템플릿**만. 광고 문구가 있으면 심사에서 반려 |
| **브랜드 메시지** | 할인·이벤트 같은 **광고성** | 카카오톡 채널 친구 + **마케팅 수신 동의**한 손님 | 카카오 **공식 딜러사**(발송 대행 업체)를 통해 |
| ~~친구톡~~ | (예전 광고성 상품) | — | **2025년 12월 31일 종료**, 브랜드 메시지로 바뀜 |

- 알림톡·브랜드 메시지는 **발송 대행 업체**(딜러사)에 가입해서 보내요. 쇼핑몰 빌더 중에는 연동 기능이 있는 곳이 많아요.
- 알림톡이 실패하면 **문자로 대신 보내기**(대체 발송) 설정을 해 두면 중요한 안내가 빠지지 않아요.
- 카카오톡 채널 친구가 많을수록 유리하니, **채널 추가 버튼**을 주문 완료 페이지·포장 안 카드에 넣어요.

## 4. 이메일 — 도구와 기본 설정

| 준비 | 내용 |
|---|---|
| **보내는 도구** | 쇼핑몰 빌더의 메일 기능, 또는 이메일 마케팅 서비스(스티비, 메일침프, 클라비요 등) |
| **도메인 인증** | **SPF·DKIM·DMARC** 설정 (30장). 안 하면 스팸함으로 |
| **보내는 주소** | `news@내도메인`처럼 도메인 주소, 회신 받을 수 있는 주소 |
| **수신거부 링크** | 모든 광고 메일 아래에, **한 번에** 거부되게 |
| **목록 관리** | 반송되는 주소, 오래 안 여는 주소는 정리 (보낼수록 도착률이 떨어져요) |

### 좋은 자동 메일 쓰는 법
- **제목**: 무엇에 관한 메일인지 바로 (48장 카피). 낚시성 제목은 신뢰를 잃어요.
- **한 메일, 한 목적, 버튼 하나.**
- 이름 넣기(개인화)는 좋지만, **데이터가 비었을 때** "안녕하세요, {이름}님"이 그대로 나가지 않게 기본값 설정.
- 휴대폰에서 먼저 확인.

## 5. 숫자로 확인하기

| 숫자 | 뜻 | 볼 점 |
|---|---|---|
| **도착률** | 실제로 받은 비율 | 낮으면 30장 도메인 인증·목록 정리 |
| **열람률** | 연 비율 | 애플 메일의 개인정보 보호 기능 때문에 **정확하지 않을 수 있어요**. 참고만 |
| **클릭률** | 링크를 누른 비율 | 내용·버튼이 맞나 |
| **전환** | 메시지 덕분에 구매·재방문 | **진짜 기준**. 링크에 UTM(38장) |
| **수신거부율** | 그만 받겠다는 비율 | 갑자기 오르면 너무 자주·관련 없는 내용 |

### 효과를 정직하게 재는 법
- 자동 흐름은 **"어차피 살 사람"**에게도 가요. 그래서 메시지 덕분인지 헷갈려요.
- 방법: 대상자의 **10%는 일부러 안 보내고**(비교 그룹) 두 그룹의 구매율을 비교 (11장 A/B 테스트).

## 6. 처음 만드는 순서 (추천)

```
1주차: 정보성 — 주문·배송 알림톡 (손님 경험의 기본)
2주차: 환영 흐름 — 가입 즉시 메일 1통부터
3주차: 장바구니 이탈 — 메시지 1~2통
1~2달 뒤: 후기 요청, 재구매 알림 (재구매 주기를 51장 데이터로 확인한 뒤)
그다음: 다시 돌아오기
```

> 💡 Claude에게: "우리 쇼핑몰의 가입·장바구니·구매 이벤트를 기준으로 자동 메시지 흐름 6개를 표로 설계해 줘. 각 메시지가 정보성인지 광고성인지 표시하고, 광고성은 수신 동의한 사람만 받게, 구매하면 흐름에서 빠지게, 하루 최대 1통이 되게 조건을 넣어 줘."

---

### 이 장 요약
1. **정보성(알림톡)**과 **광고성(브랜드 메시지·광고 메일)**을 구분하고, 광고성은 **동의한 사람에게만, (광고) 표시·수신거부·야간 동의**.
2. 기본 흐름 6개: **환영, 장바구니 이탈, 구매 후 안내, 후기 요청, 재구매 알림, 다시 돌아오기**. 목표 행동을 하면 **바로 빼고**, 하루 보내는 수를 제한.
3. 진짜 기준은 열람률이 아니라 **전환**, 일부는 안 보내는 **비교 그룹**으로 효과를 확인.
