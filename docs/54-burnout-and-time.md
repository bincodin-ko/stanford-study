# 54. 번아웃·시간 관리·주간 운영 루틴

1인 사업자는 **기획자·개발자·마케터·CS·회계**를 혼자 해요. 할 일은 끝이 없고, 쉬는 날은 없고, 결과는 늦게 와요.
지치지 않는 것도 **사업의 핵심 능력**이에요.

> 반복 업무 자동화 도구는 [69장](69-automation-and-data-collection.md), 공부·정보 수집 루틴은 [74장](74-learning-routine.md)에 있어요.

> ⚠️ 이 장의 내용은 일반적인 생활·업무 관리 조언이에요. 우울감·불면·불안이 2주 이상 계속되면 **전문가 상담**을 받으세요(정신건강 상담 전화 등). ([참고 자료 모음](sources.md))

---

## 1. 번아웃 신호

| 신호 | 예 |
|---|---|
| 몸 | 계속 피곤, 잠을 자도 안 풀림, 자주 아픔 |
| 마음 | 사업 생각만 하면 짜증·무기력, "다 소용없다" |
| 일 | 미루기 늘어남, 간단한 결정도 어려움, 실수 증가 |
| 관계 | 사람 만나기 싫음, 예민해짐 |

> 💡 번아웃은 "의지가 약해서"가 아니라 **오래 과부하가 쌓인 결과**예요. 신호가 보이면 **속도를 줄이는 것이 사업을 지키는 일**이에요.

## 2. 1인 사업자에게 흔한 함정과 처방

| 함정 | 처방 |
|---|---|
| **모든 걸 완벽하게** | 80%면 출시 (4장 MVP). 고칠 수 있는 건 나중에 |
| **모든 채널을 다** | 채널 1~2개만 (32장) |
| **24시간 대기** | 문의 응대 시간을 정하고 공개 (30장), 알림 끄는 시간 |
| **숫자에 매일 휘둘림** | 매출은 **주 1회** 보기 (매일 보면 불안만 커짐) |
| **혼자 고민** | 같은 처지의 창업자 모임, 멘토, 지원사업 네트워크 (45장) |
| **쉬면 죄책감** | 쉬는 시간도 일정에 넣기 |
| **급한 일만 하다 하루 끝** | 아래 우선순위 방법 |

## 3. 우선순위 정하기

### 급함 × 중요함 (아이젠하워 매트릭스)
| | **급함** | **안 급함** |
|---|---|---|
| **중요** | 바로 하기 (장애, 결제 오류) | **일정에 넣어 꼭 하기** ← 사업이 크는 곳 (검증·개선·마케팅) |
| **안 중요** | 맡기거나 자동화 (반복 문의 → FAQ) | 버리기 |

### 오늘의 3가지
- 매일 아침 **"오늘 꼭 끝낼 일 3개"** 만 정하기. 나머지는 보너스.
- 가장 머리 쓰는 일(기획·개발)은 **집중이 잘 되는 시간**에, 메일·정산은 오후에 몰아서.

### 시간 덩어리 만들기
- 개발·글쓰기는 **2시간 덩어리**로 알림 끄고 (중간에 끊기면 다시 집중하는 데 오래 걸려요)
- 문의 답변은 **하루 2번** 정해진 시간에 몰아서

## 4. 자동화로 시간 벌기

| 반복 일 | 자동화 |
|---|---|
| 같은 문의 답변 | FAQ, 답변 템플릿, 자동 회신 (30장) |
| 주문 알림·송장 입력 | 빌더·통합 관리 솔루션 (23장) |
| 매출 정리 | 장부 자동 연동 (44장), 대사 자동화 (39장) |
| 백업 확인·사이트 감시 | 자동 백업·업타임 알림 (8·9장) |
| SNS 게시 | 예약 게시 |
| 반복 코드 작업 | AI 코딩 도구 (49장) |

## 5. 주간 운영 루틴 (예시)

```
월요일 (계획)  - 지난주 숫자 30분 (51장 대시보드)
              - 이번 주 목표 3개, 실험 1개 (33장 90일 계획)
화~목 (만들기) - 오전: 집중 작업 (개발·콘텐츠·개선)
              - 오후: 문의 답변 2회, 주문 처리, 마케팅
금요일 (점검)  - 30분 점검 (33장): 도달·클릭·구매·광고비
              - 백업·보안 업데이트 확인 (14장)
              - 다음 주에 넘길 일 정리
주말          - 쉬기 (긴급 장애만 대응하도록 알림 설정)
매월 첫 주     - 돈 정리 (44장), 매월 점검 (14장)
분기          - 복구 훈련, 가격·전략 점검, 반나절은 "큰 그림" 생각
```

## 6. 지속 가능한 1인 사업의 원칙

1. **수입이 안정될 때까지 생활비 계획을 따로** — 생활비 걱정이 가장 큰 스트레스
2. **혼자 일하되 혼자 고민하지 않기** — 동료 창업자 모임, 온라인 커뮤니티
3. **잘 자고, 움직이고, 먹기** — 너무 당연하지만 가장 먼저 무너지는 것
4. **"하지 않을 일 목록"** 만들기 — 거절도 전략
5. **작은 성공 기록하기** — 첫 매출, 첫 후기, 첫 재구매. 힘들 때 다시 보기

---

### 이 장 요약
1. 번아웃은 과부하의 결과 — 신호가 보이면 **속도를 줄이는 게 사업을 지키는 일**.
2. **급함×중요함**으로 나누고, 매일 **3가지만**, 집중 작업은 **2시간 덩어리**로.
3. 반복 일은 **자동화**, **주간 루틴**과 쉬는 시간을 일정에 넣는다.
