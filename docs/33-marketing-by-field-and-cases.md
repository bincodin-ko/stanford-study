# 33. 분야별 마케팅 시작법과 실제 사례

32장이 "채널 사용법"이라면, 이 장은 **"내 사업이면 무엇부터 할까?"** 와 **"실제로 성공한 곳들은 처음에 뭘 했나?"** 예요.

> 📌 사례는 기사·인터뷰·업계 분석에서 조사했어요. 숫자는 출처마다 조금씩 달라서 **"대략 이 정도"** 로 보고, 날짜·수치가 중요하면 [참고 자료 모음](sources.md)의 원문을 확인하세요.

---

## 1부. 실제 사례 10가지 — 처음에 무엇을 했나

### 사례 1. 배달의민족 — 길거리 전단지를 주워 데이터를 만들다 🇰🇷
- **무엇을**: 2010년 창업 초기, 창업자와 초기 멤버들이 **길거리 전단지를 줍고 아파트 쓰레기통의 메뉴판을 모아** 앱에 가게 정보를 직접 입력했다고 여러 매체가 전해요.
- **왜 통했나**: 사용자는 "가게가 많아야" 앱을 써요. 사장님들이 가입하기 전에 **운영자가 직접 손으로** 첫 데이터를 채웠어요.
- **배울 점**: 초기엔 **"규모가 커지면 못 할 일"을 직접 하는 게** 가장 빠른 마케팅일 때가 많아요. (중개 플랫폼 27장의 "한쪽 먼저 채우기")

### 사례 2. 당근 — 회사 안 장터에서 동네 장터로 🇰🇷
- **무엇을**: 2015년 카카오 출신 창업자들이 **판교 회사들의 사내 중고거래 게시판 '판교장터'** 로 시작. 다른 동네 주민들이 "우리 동네에서도 쓰고 싶다"고 요청하자, **회사 이메일 인증 → 동네(위치) 인증**으로 바꾸며 일반인에게 열었고, 판교 지역 거래량이 크게 늘었다고 보도됐어요.
- **배울 점**: **좁게 시작해서 진짜 쓰는 사람들을 만든 뒤** 넓혀요. 처음부터 "전국 중고거래"였다면 어느 동네에도 물건이 부족했을 거예요. 이후 **동네 가게 광고**가 수익원이 됐어요(32장 당근 광고).

### 사례 3. 무신사 — 신발 사진 커뮤니티가 쇼핑몰이 되다 🇰🇷
- **무엇을**: 창업자가 고등학생 때(2001년 무렵) 커뮤니티 서비스 프리챌에 연 **스니커즈 마니아 커뮤니티** "무진장 신발 사진이 많은 곳"이 출발점. 2003년 독립 사이트로 옮기고, 2009년 무신사 스토어를 열었어요.
- **배울 점**: **커뮤니티 → 콘텐츠(매거진) → 커머스** 순서. 물건을 팔기 전에 **그 물건을 좋아하는 사람들의 모임**부터 만들었어요. (16장 커뮤니티 → 21장 "한 주제로 키우기")

### 사례 4. 오늘의집 — "남의 집 구경" 콘텐츠에 구매 버튼을 달다 🇰🇷
- **무엇을**: 2014년 사용자들이 **자기 집 인테리어 사진(온라인 집들이)** 을 올리는 커뮤니티로 시작해, 2016년 무렵 **사진 속 제품을 누르면 바로 살 수 있는** 커머스를 붙였어요.
- **배울 점**: **사람들이 이미 즐겨 보는 콘텐츠**에 구매를 자연스럽게 연결. 인스타그램의 "제품 태그"와 같은 원리예요.

### 사례 5. 글로시에(Glossier) — 블로그와 인스타그램 팬부터 🇺🇸
- **무엇을**: 창업자가 2010년 뷰티 블로그 **Into The Gloss**를 운영하며 독자 커뮤니티를 만들었고, 제품을 만들 때 독자에게 **"꿈의 세안제는?"** 같은 질문을 던져 수백 개의 댓글로 의견을 모았어요. 인스타그램 계정은 **제품 출시 전에** 이미 팔로워가 많았다고 알려져요.
- **배울 점**: **제품보다 팬이 먼저.** 만들기 전부터 SNS에 과정을 공유하고 의견을 받으면, 출시일에 이미 기다리는 손님이 있어요. (다만 이후 회사가 어려움을 겪은 시기도 있어서, 커뮤니티가 모든 걸 해결하진 않아요.)

### 사례 6. 모닝 브루(Morning Brew) — 독자가 독자를 데려오는 뉴스레터 🇺🇸
- **무엇을**: 경제 뉴스레터. 매 메일에 **"친구에게 공유하기(Share the Brew)"** 칸을 넣고, 추천 인원에 따라 스티커·머그컵 같은 굿즈를 줬어요. 추천 프로그램이 초기엔 성장의 **대부분**, 이후에도 약 30%를 차지했다는 분석이 있어요.
- **배울 점**: **"공유하면 나도 좋은" 구조**를 콘텐츠 안에 매번 넣기. 담당자는 "구독자가 친구에게 공유하는 게 보이면 바로 추천 프로그램을 만들라"고 조언했어요.

### 사례 7. 드롭박스(Dropbox) — 친구 초대하면 둘 다 용량 🇺🇸
- **무엇을**: 친구를 초대하면 **초대한 사람과 받은 사람 모두에게 무료 저장 용량**을 줬어요. 2008~2010년 사이 약 15개월 동안 사용자가 약 10만 명에서 400만 명으로(약 3,900%) 늘었다는 사례로 유명해요.
- **배울 점**: 보상이 **제품 자체**(용량)라서 손님이 진짜 원하고, 회사 비용은 적었어요. 다만 이미 입소문이 있던 제품을 **더 키운 것**이지, 추천 프로그램이 없는 인기를 만들어 낸 건 아니에요.

### 사례 8. 워들(Wordle) — 정답을 숨긴 채 자랑하게 만든 게임 🎮
- **무엇을**: 하루 한 문제 단어 게임. 초기 사용자 한 명이 **결과를 초록·노랑 네모 이모지로 손으로 그려** 트위터에 올리자, 개발자가 이를 **공유 버튼으로 게임에 넣었어요.** 이후 폭발적으로 퍼졌고 뉴욕타임스가 인수했어요.
- **배울 점**: **스포일러 없이 자랑하고 비교할 수 있는 공유 형식**. 오목 게임이라면 "오늘의 퍼즐 7수 만에 해결 ⚫⚪" 같은 공유 카드를 생각해 볼 수 있어요 (20장).

### 사례 9. 어몽어스(Among Us) — 스트리머가 키운 게임 🎮
- **무엇을**: 2018년 출시 후 거의 안 알려졌다가 2020년 **한국·멕시코·브라질 스트리머** 방송에서 먼저 인기를 얻고, 이후 유명 영어권 스트리머들이 하면서 세계적으로 폭발했어요.
- **배울 점**: 여러 명이 함께 해야 하는 게임이라 **여러 방송에 동시에 나오는 구조**였어요. 게임·앱은 **"보는 것만으로 재미있는가"** 가 크리에이터 마케팅의 핵심이에요.

### 사례 10. 듀오링고(Duolingo) — 마스코트가 SNS에서 사람처럼 🦉
- **무엇을**: 초록 부엉이 마스코트 "듀오"를 틱톡에서 **장난스럽고 엉뚱한 캐릭터**로 운영. 마스코트 없이 올린 초기 영상보다 마스코트가 나온 뒤 조회수가 크게 늘었다고 알려지고, 틱톡 콘텐츠는 **광고비 없이(오가닉)** 운영했다고 보도됐어요. 부엉이를 보면 "아, 오늘 공부 안 했다"가 떠오르게 하는 효과도 노렸어요.
- **배울 점**: 앱·서비스는 **브랜드를 캐릭터처럼** 만들면 SNS에서 친근해져요. 다만 브랜드 성격과 맞아야 해요.

### 그 밖에 자주 인용되는 사례 2가지 (참고)
- **피터 레벨스(Pieter Levels)** — 1인 개발자. "12개월에 12개 서비스 만들기"를 공개 선언하고, **만드는 과정과 매출을 X(트위터)에 공개(빌드 인 퍼블릭)** 하며 팬을 모았어요. Nomad List는 도시 정보 **스프레드시트 한 장**에서 시작했어요. → 1인 SaaS·AI 서비스에 잘 맞는 방식.
- **에어비앤비 초기의 크레이그리스트 연동** — 이미 사람이 많은 사이트(크레이그리스트)에 숙소 글을 자동으로 올려 손님을 데려온 유명한 성장 사례. 하지만 **상대 사이트의 이용약관을 어긴 방식**이라는 비판도 함께 받아요. → "사람이 있는 곳으로 간다"는 아이디어는 배우되, **약관 위반·스팸 방식은 따라 하지 마세요.**

### 사례에서 뽑은 공통 원칙 6가지
| 원칙 | 사례 |
|---|---|
| **1. 좁게 시작하라** | 당근(판교), 무신사(스니커즈 마니아) |
| **2. 처음엔 손으로 직접 하라** | 배달의민족(전단지), 오늘의집·글로시에(커뮤니티 직접 운영) |
| **3. 팬·커뮤니티가 먼저, 제품은 그다음** | 무신사, 글로시에, 오늘의집 |
| **4. 공유가 제품 안에 있게** | 워들(이모지), 모닝 브루(공유 칸), 드롭박스(용량) |
| **5. 이미 사람이 모인 곳으로 가라** | 어몽어스(스트리머), 에어비앤비(크레이그리스트 — 방법은 주의) |
| **6. 브랜드에 성격을 줘라** | 듀오링고 |

## 2부. 분야별 마케팅 시작법

각 분야별로 **첫 채널, 첫 30일에 할 일, 핵심 지표, 비슷한 사례**를 정리했어요.

| 분야 | 첫 채널 | 첫 30일에 할 일 | 볼 숫자 | 참고 사례 |
|---|---|---|---|---|
| **자사몰** (13장) | 인스타그램 + 네이버 블로그·검색 | 프로필 정리, 릴스 주 3개, 체험단 5~10명, 반응 좋은 릴스에 소액 광고 | 전환율, ROAS, 재구매율 | 글로시에 |
| **오픈마켓 셀러** (23장) | 마켓 안 검색·마켓 광고 + 인스타 | 상품명·대표 이미지 최적화, 첫 리뷰 20개 모으기(구매평 이벤트는 규칙 안에서), 마켓 키워드 광고 소액 | 마켓 검색 순위, 리뷰 수, ROAS | — |
| **동네 가게·서비스** | 네이버 플레이스 + 당근 + 카카오 채널 | 플레이스 정보·사진 완성, 실제 손님 리뷰 요청, 당근 비즈프로필 쿠폰, 채널 추가 혜택 | 플레이스 유입, 리뷰 수, 재방문 | 당근 |
| **커뮤니티** (16장) | 이미 사람이 있는 오픈채팅·카페·디스코드 | 운영자가 매일 씨앗 글, 첫 100명 1:1로 챙기기, 좁은 주제 | 하루 새 글 수, 글 쓰는 회원 비율 | 무신사, 당근 |
| **정보·도구 사이트** (17장) | 검색(네이버·구글) + 스레드 | 검색어 조사 → 핵심 글·도구 10개, 서치 콘솔 등록, 스레드에 계산 결과·꿀팁 공유 | 검색 유입, 재방문 | 피터 레벨스(Nomad List) |
| **트래픽·광고 수익** (18장) | 검색 + SNS 재배포 | 같은 콘텐츠를 글·릴스·스레드로 나눠 올리기, 이메일 구독 받기 | PV, RPM, 구독자 수 | 모닝 브루 |
| **로또·운세 정보** (19장) | 검색 + 스레드 | 추첨일(토요일 저녁) 직후 빠른 업데이트, "재미용" 공유 카드 | 토요일 밤 유입, 재방문 | 워들(공유 카드) |
| **게임·오목** (20장) | 커뮤니티 + 스트리머·유튜버 + 쇼츠 | 플레이 영상·명장면 쇼츠, 오목 커뮤니티·디스코드에 소개, 작은 스트리머에게 연락, 결과 공유 카드 | 동시 접속, D1·D7 리텐션 | 어몽어스, 워들 |
| **크리에이터** (24장) | 유튜브 + 쇼츠/릴스 | 한 주제로 영상 10개, 썸네일·제목 A/B, 쇼츠로 긴 영상 홍보 | 클릭률, 시청 지속 시간, 구독 전환 | 듀오링고(캐릭터) |
| **모바일 앱** (25장) | 앱스토어 검색(ASO) + 숏폼 + 추천 프로그램 | 앱 이름·스크린샷 최적화, 기능 시연 숏폼, "친구 초대하면 둘 다 혜택" | 설치당 비용(CPI), D7 리텐션 | 드롭박스, 듀오링고 |
| **강의·디지털 상품** (26장) | 무료 콘텐츠(유튜브·블로그·스레드) + 이메일 | 무료 강의 한 편·템플릿 무료 버전 → 이메일 받기 → 사전 신청 | 구독 → 구매 전환율 | 글로시에(사전 의견 모으기) |
| **외주·에이전시** (26장) | 포트폴리오 + 재능 마켓 + 지인 소개 | 작업 사례 3개 정리, 재능 마켓 등록, 지난 고객에게 후기·소개 요청 | 문의 수, 계약 전환율 | — |
| **중개 플랫폼** (27장) | 공급자 직접 영업(오프라인) + 지역 커뮤니티 | 한 지역·한 업종 공급자 30곳 직접 등록, 손님 쪽은 지역 커뮤니티·당근 | 매칭 성공률, 양쪽 재방문 | 배달의민족, 당근, 에어비앤비 |
| **B2B·SaaS** (12장) | 링크드인·업계 커뮤니티 + 검색 + 콘텐츠 | 고객사 문제 해결 글·사례, 무료 체험, 데모 요청 폼, 빌드 인 퍼블릭 | 데모 신청 수, 체험 → 유료 전환 | 피터 레벨스 |
| **AI 서비스** (28장) | 데모 영상(X·스레드·유튜브) + 런칭 커뮤니티 | "전/후" 비교 데모 영상, 무료 사용량 제공, 사용자 결과물 공유 기능 | 가입 → 재사용률, 1인당 AI 비용 | 워들(공유), 피터 레벨스 |

## 3부. 90일 실행 계획 템플릿 (복사해서 쓰기)

```
[0주] 준비
- 손님 1명 정의 (누구, 어디에 있나, 무엇이 불편한가)
- 채널 1~2개 선택 (32장 표)
- 측정 준비: GA4, UTM, 인스타 프로페셔널 계정, 광고 픽셀

[1~4주] 씨앗 뿌리기 — "직접, 손으로"
- 콘텐츠: 도움 되는 것 위주로 주 3~5개
- 첫 손님 30명: 지인·커뮤니티·체험단에게 직접 연락
- 후기·질문을 전부 모으기 → FAQ·다음 콘텐츠 재료

[5~8주] 반응 찾기 — "무엇이 퍼지나"
- 인사이트·GA4로 상위 콘텐츠 3개 찾기 → 같은 주제 변형 5개 더
- 반응 좋은 콘텐츠에 소액 광고 테스트 (ROAS 확인)
- 공유·추천 장치 하나 넣기 (공유 카드, 친구 초대 혜택)

[9~12주] 키우기 — "되는 것만 더"
- 잘 되는 채널 하나에 시간·예산 집중, 안 되는 채널 정리
- 협업: 작은 크리에이터·비슷한 분야 브랜드와 협업 게시물 (광고 표시)
- 이메일·카카오 채널로 단골 만들기 (수신 동의 받고)

[매주 금요일 30분 점검]
- 이번 주 도달 / 링크 클릭 / 가입·구매 / 광고비 / 다음 주 실험 1개
```

## 4부. 사례를 따라 할 때 주의할 점

| 함정 | 설명 |
|---|---|
| **생존자 편향** | 성공 사례만 기사가 돼요. 같은 방법으로 실패한 곳은 훨씬 많아요. **방법보다 원리**(좁게, 직접, 공유)를 가져오세요 |
| **시대가 다름** | 2008년 드롭박스, 2010년 배민의 환경과 지금은 달라요. 지금은 숏폼·AI 검색·광고 단가가 다른 시대 |
| **규칙 위반 성장** | 에어비앤비 크레이그리스트 연동처럼 약관 위반 방식은 지금 하면 계정 정지·소송 위험 |
| **숫자는 대략** | 사례 속 숫자는 출처마다 달라요(예: 무신사 시작 연도 2001/2002). 발표 자료에 쓸 땐 원문 확인 |

---

### 이 장 요약
1. 성공 사례의 공통점: **좁게 시작, 처음엔 손으로, 팬이 먼저, 공유가 제품 안에, 사람 있는 곳으로, 브랜드에 성격**.
2. 분야마다 **첫 채널과 첫 30일 할 일**이 다르다 — 동네 가게는 플레이스·당근, 게임은 스트리머·커뮤니티, B2B는 콘텐츠·데모.
3. **90일 계획: 씨앗(직접) → 반응 찾기(실험) → 키우기(집중)**, 매주 숫자로 점검. 사례는 방법이 아니라 **원리**를 가져온다.
