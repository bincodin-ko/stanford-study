# 77. 정부·인증기관 등록과 인증 — 제품 인증, 권리 등록, 기업 인증, 보안 의무

> 사업자등록·통신판매업 등 기본 신고와 업종별 신고 목록은 [10장](10-security-and-law.md)·[71장](71-tax-insurance-filings.md), 상표·저작권 기본은 [47장](47-trademark-copyright-license.md), 지원금은 [45장](45-funding-and-support.md)에 있어요.

이 장은 **"해야 하는데 몰라서 놓치는 것"(의무)**과 **"하면 혜택이 있는데 몰라서 안 하는 것"(선택)**을 나눠 정리했어요.

> ⚠️ 법·제도의 기준 금액·요건은 자주 바뀌고, 이 장은 대부분 **블로그·기사·컨설팅 업체 자료**로 조사했어요. 실제로 진행할 때는 각 기관의 공식 안내를 확인하세요. ([참고 자료 모음](sources.md))

| 제품 | **KC 인증** (안전) | 전기용품·생활용품·어린이제품을 만들거나 수입·판매 | **의무** (품목별) |
| 제품 | **전파 적합성평가** (KC 전자파) | 전자 제품, 블루투스·와이파이 기기 | **의무** |
| 수입 | **개인통관고유부호 / 사업자 통관 등록** | 해외에서 물건을 들여오는 사업 | 상황별 (23장) |
| 권리 | **프로그램 저작권 등록** | 소프트웨어를 만든 사람 | 선택 (분쟁 대비) |

| 기업 | **소프트웨어사업자 신고** | 공공기관 등에 SW를 납품하려는 기업 | 공공 납품 시 필요 |
| 보안 | **ISMS / ISMS-P 인증** | 일정 규모 이상 정보통신서비스 | 기준 넘으면 **의무** |
| 책임자 | **개인정보 보호책임자 지정** | 개인정보를 다루는 모든 사업자 | **의무** (작은 사업자는 대표가 맡는 경우가 많음) |
| 책임자 | **청소년 보호책임자 지정** | 일정 규모 이상 정보통신서비스 | 기준 넘으면 의무 |

## 2. 제품 인증 — 실물 상품을 판다면 (72장과 함께)

### KC 인증
- KC는 **여러 부처 인증을 합쳐 부르는 이름**이에요. 한 제품이 **둘 이상**(예: 전기 안전 + 전자파)을 받아야 할 수도 있어요.
- 대표 대상: **전기용품**(충전기·조명·전열기), **생활용품**(일부 생활 제품), **어린이제품**(만 13세 이하용 — 장난감·문구·의류 등).
- 인증 방식은 품목 위험도에 따라 **안전인증 / 안전확인 / 공급자적합성확인** 등으로 달라요.
- **온라인 판매자 의무**: 상세 페이지에 **KC 인증 번호와 표시 사항**을 보여야 하고, 인증 대상인데 인증이 없는 제품은 팔면 안 돼요. 구매대행도 표시 의무가 있다는 안내가 있어요(위반 시 과태료).
- 품목별 대상과 표시 방법은 **제품안전정보센터**(국가기술표준원)의 가이드북·상담(1381)으로 확인할 수 있어요.
- 해외 직구 제품 KC 의무화는 2024년 발표 후 철회된 일이 있을 만큼 바뀌는 분야예요(23장). 최신 상태 확인 필수.

### 전파 적합성평가 (전자파)
- 블루투스 이어폰, 와이파이 기기, 무선 충전기처럼 **전파를 내거나 전자파 영향이 있는 제품**은 적합성평가(KC 전자파)가 필요해요. 접수는 **전파민원센터**.
- 인증된 배터리·모듈을 써도 **완제품의 전자파 인증은 따로** 필요한 경우가 많아요.

> 💡 인증 비용·기간(몇 주~몇 달)은 **원가와 출시 일정**에 들어가요(43·61장). 상품을 정하기 전에 인증 대상인지부터 확인하세요.

## 3. 권리 등록 — 내 것임을 증명해 두기

### 프로그램 저작권 등록 (한국저작권위원회)
- 저작권은 **만들면 자동으로** 생겨요(47장). 등록은 **의무가 아니에요.**
- 그래도 등록하면: 분쟁 때 **누가 언제 만들었는지 추정**을 받는 데 유리하고, 투자·매각(56장) 때 **자산 증명**이 돼요.
- 외주로 만든 경우 **권리가 누구에게 있는지**(53장 계약서)부터 정리해야 등록할 수 있어요.
- 비용·절차는 한국저작권위원회 등록 안내에서 확인하세요.

### 특허 (BM 특허 포함)
- 특허는 **새롭고 쉽게 생각할 수 없는 기술적 아이디어**를 일정 기간 독점하는 권리예요. 저작권(표현)과 달리 **아이디어·방법**을 보호해요.
- **BM(비즈니스 모델) 특허**: 영업 방법이 **컴퓨터·기술로 구체적으로 구현**된 경우에 받을 수 있어요. "구독으로 판다" 같은 아이디어만으로는 어려워요.
- 주의:
  - **출원 전에 공개하면** 특허를 못 받을 수 있어요(일부 예외 기간 제도가 있지만 위험). 빌드 인 퍼블릭(57장) 전에 고민하세요.
  - 비용(변리사 비용 포함)과 시간이 꽤 들어요. 1인 사업 초기엔 **상표(47장)가 먼저**인 경우가 많아요.
  - 반대로 **남의 특허 침해**도 확인 — 특허청 무료 검색 서비스(KIPRIS)에서 비슷한 특허를 찾아볼 수 있어요.

## 4. 기업 인증 — 하면 혜택이 있는 것들

### 벤처기업 확인
- 유형: **벤처투자 / 연구개발 / 혁신성장 / 예비벤처** (자료 기준 4가지). 요건은 유형마다 달라요.
- 받으면 세금 감면·정책 자금·인증 우대 등이 있다고 안내돼요(45장 지원사업 심사 가점 등).
- 컨설팅 업체가 "무조건 받아 준다"며 비싼 수수료를 받는 경우가 있어요. **벤처기업확인기관 공식 안내**로 직접 요건부터 확인하세요.

### 기업부설연구소 / 연구개발전담부서
- 연구 인력과 독립된 연구 공간을 갖추면 인정받을 수 있어요. 인정되면 **연구·인력개발비 세액공제** 등의 혜택을 받을 때 유리해요.
- **2026년 2월 1일부터** 관련 제도가 별도 법률 체계로 바뀌고 요건 일부가 완화됐다는 보도가 있어요(파티션 허용 등). 세부 요건은 과기정통부 안내를 확인하세요.
- 1인 사업자에겐 아직 이른 경우가 많아요. **개발자를 1~2명 이상 쓰기 시작할 때** 세무사와 함께 검토하세요(70장).

### 소프트웨어사업자 신고
- 소프트웨어진흥법에 따른 신고로, **한국소프트웨어산업협회**가 접수해요.
- **공공기관에 소프트웨어를 납품**하거나 조달청 계약에 올리려면 필요한 경우가 많아요(73장 B2G).
- 일반 손님에게 파는 앱·SaaS만 운영한다면 당장 필요하지 않을 수 있어요.

## 5. 보안 의무 — 커지면 생기는 것들

### ISMS / ISMS-P 인증
- **정보보호 관리체계 인증**이에요. 아래 같은 기준(자료 기준)을 넘으면 **의무**예요.
  - 정보통신서비스 부문 **전년도 매출 100억 원 이상**, 또는
  - 직전 3개월 **하루 평균 이용자 100만 명 이상**, 또는
  - 연 매출 1,500억 원 이상 등 (그 밖에 통신망·데이터센터 사업자)
- 의무인데 안 받으면 과태료가 있어요.
- 2026년 개인정보법 개정으로 **대규모 개인정보처리자에게 ISMS-P를 의무화**하는 시행령 개정안이 논의·예고됐다는 보도가 있어요(매우 큰 기업 기준). 확정 내용은 공식 확인 필요.
- 1인 사업자에겐 먼 이야기지만, **37장 보안 체크리스트**가 이 인증의 축소판이라고 생각하면 돼요. 나중에 B2B 대기업 고객이 보안 인증을 요구할 때 다시 보세요.

### 개인정보 보호책임자
- 개인정보를 다루면 **개인정보 보호책임자를 정해 처리방침에 적어야** 해요. 작은 사업자는 보통 **대표가 맡아요**(10장). 이름·연락처(직책·부서 가능)를 처리방침에 넣으세요.

### 청소년 보호책임자
- 일정 규모 이상(일평균 이용자 수·매출 기준)의 정보통신서비스는 **청소년 보호책임자를 지정**하고 공개해야 해요. 커뮤니티(16장)·게임(20장)처럼 청소년이 볼 수 있는 서비스는 규모가 커지면 확인하세요. 정확한 기준은 법령 확인 필요.

## 6. 언제 무엇을 확인할까

| 시점 | 확인 |
|---|---|
| 상품 고를 때 | KC·전파 인증 대상인가, 인증 비용·기간 |
| 공개 발표·빌드 인 퍼블릭 전 | 특허를 낼 만한 기술이 있나 |
| 출시 전 | 개인정보 보호책임자, 업종 신고 (71장) |
| 투자·지원사업 준비 | 벤처기업 확인, 저작권 등록 |
| 개발자 채용 | 기업부설연구소·연구개발전담부서 |
| 공공기관 영업 | 소프트웨어사업자 신고 |
| 매출 100억·이용자 100만 근처 | ISMS 의무 |

> 💡 Claude에게: "내 사업은 [블루투스 스피커를 수입해 스마트스토어에서 판매]야. 필요한 인증·신고·등록을 의무와 선택으로 나눠 표로 만들고, 각각 담당 기관과 확인할 공식 사이트를 알려 줘. 확실하지 않은 건 확실하지 않다고 적어 줘."

### 이 장 요약
1. 실물 상품은 **KC 인증·전파 적합성평가**가 의무인 품목이 많다 — 상품을 고르기 전에 확인하고, 상세 페이지에 **인증 번호 표시**.
2. 저작권 등록·특허·벤처기업 확인·기업부설연구소는 **선택이지만 혜택**이 있다. 특허는 **공개 전에** 고민.
3. 개인정보 보호책임자는 **처음부터 지정**, ISMS·청소년 보호책임자는 **규모가 커지면** 의무.
