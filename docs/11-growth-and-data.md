# 11. 마케팅과 데이터 — 손님을 데려오고 숫자로 판단하기

---

## 1. 손님이 오는 길 — 유입 채널

| 채널 | 설명 | 비용 | 효과가 나타나는 속도 |
|---|---|---|---|
| **검색(SEO)** | 네이버·구글에서 검색해서 들어옴 | 시간·노력 (광고비 없음) | 느림 (몇 달) |
| **검색 광고** | 검색 결과 위 광고 | 클릭당 비용 | 즉시 |
| **SNS 광고** | 인스타그램·페이스북·유튜브 광고 | 노출/클릭당 비용 | 즉시 |
| **SNS 운영(오가닉)** | 내 계정에 꾸준히 올리기 | 시간 | 느림 |
| **인플루언서/체험단** | 다른 사람이 소개 | 제품·비용 | 중간 (광고 표시 의무!) |
| **이메일·문자·카카오 알림** | 기존 손님에게 다시 연락 | 저렴 | 즉시 (마케팅 수신 동의 필요) |
| **입소문·추천** | "친구 초대하면 둘 다 적립금" | 혜택 비용 | 중간 |
| **오픈마켓 입점** | 쿠팡·스마트스토어 등에도 판매 | 수수료 | 빠름 |

> **오가닉(Organic)** = 돈 안 내고 자연스럽게 들어오는 유입.

## 2. 퍼널 — 어디서 손님이 빠져나가나

```
방문         10,000명   ████████████████████  100%
상품 보기     4,000명   ████████               40%
장바구니        800명   ██                      8%
결제 시작       400명   █                       4%
결제 완료       200명   ▌                       2%   ← 전환율 2%
```

- 가장 크게 줄어드는 단계가 **제일 먼저 고칠 곳**입니다.
- 예: 장바구니(800) → 결제 시작(400)이 반토막 → 배송비가 장바구니에서 갑자기 보이는 건 아닌지? 회원가입을 강요하는 건 아닌지?

## 3. 꼭 볼 숫자 5개 (쇼핑몰 기준)

```
매출 = 방문자 수 × 전환율 × 객단가
```

이 공식이 전부예요. 매출을 올리는 방법은 셋 중 하나를 올리는 것뿐입니다.

| 올릴 숫자 | 방법 예 |
|---|---|
| **방문자 수** | 광고, SEO, SNS |
| **전환율** | 상세 페이지 개선, 리뷰 노출, 결제 단계 줄이기, 무료배송 기준 |
| **객단가** | 묶음 상품, "3만 원 이상 무료배송", 함께 사면 좋은 상품 추천 |

여기에 두 개를 더 봅니다.
- **재구매율**: 한 번 산 손님이 다시 사는 비율. 광고비 없이 들어오는 매출.
- **CAC vs 1인당 이익**: 손님 1명 데려오는 비용이 그 손님이 남겨 주는 이익보다 작아야 함. ([2장](02-revenue-models.md)의 계산)

### 구독/SaaS라면
- **MRR** 성장, **이탈률(Churn)**, **LTV/CAC**(흔히 3배 이상이면 건강하다고 봄), **CAC 회수 기간**(광고비를 몇 달 만에 되찾나).

## 4. 데이터 모으기 — 도구

| 도구 | 하는 일 |
|---|---|
| **구글 애널리틱스(GA4)** | 방문자 수, 어디서 왔는지, 어떤 페이지를 봤는지 |
| **네이버 애널리틱스 / 서치어드바이저** | 네이버 검색 유입, 검색 노출 관리 |
| **구글 서치 콘솔** | 구글 검색 노출, 어떤 검색어로 들어왔는지 |
| **광고 관리자** (메타, 네이버, 구글) | 광고별 클릭·구매·ROAS |
| **빌더 기본 통계** | 매출, 주문, 인기 상품 |
| **히트맵 도구** | 손님이 화면 어디를 많이 누르는지 |

> **UTM 꼬리표**: 인스타 광고 링크 끝에 `?utm_source=instagram&utm_campaign=fall_sale` 을 붙이면, GA4에서 "가을 세일 인스타 광고로 온 손님"을 따로 셀 수 있어요.

## 5. A/B 테스트 — 감 대신 실험

1. **가설**: "상세 페이지 맨 위에 리뷰 별점을 보여 주면 전환율이 오를 것이다."
2. **A안(기존)** 과 **B안(별점 추가)** 을 손님에게 반반 보여 준다.
3. **충분한 수**(보통 각 수백~수천 명 이상)가 모일 때까지 기다린다.
4. 차이가 의미 있으면 B안을 채택.

주의
- **한 번에 하나만** 바꾸기 (뭐가 효과였는지 알 수 있게).
- 하루 이틀 보고 결론 내지 않기 (요일·날씨에 따라 출렁임).

---

## 6. SEO 기본 (검색에 잘 걸리게)

- 페이지마다 **제목(title)과 설명**을 손님이 검색할 말로 쓰기. 예: "수제 그래놀라 | 무설탕 아침 대용"
- 상품 사진에 **설명(alt 텍스트)** 넣기.
- **빠른 사이트**: 사진 용량 줄이기.
- **모바일에서 보기 편하게**.
- **꾸준한 콘텐츠**: 블로그·후기·FAQ 글.
- 네이버 서치어드바이저, 구글 서치 콘솔에 **사이트 등록**.

---

### 이 장 요약
1. **매출 = 방문자 × 전환율 × 객단가.** 셋 중 무엇을 올릴지 정한다.
2. 퍼널에서 **가장 많이 빠지는 단계**부터 고친다.
3. 감이 아니라 **A/B 테스트**로 결정한다.
