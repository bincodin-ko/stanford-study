# 05. 사이트가 돌아가는 구조

손님이 주소창에 `myshop.com`을 치면 무슨 일이 일어날까요?
**가게**에 비유하면 이해가 쉬워요.

| 인터넷 | 가게 비유 |
|---|---|
| **도메인** (`myshop.com`) | 가게 간판 이름 |
| **DNS** | 간판 이름으로 실제 주소를 찾아 주는 지도 앱 |
| **서버** | 가게 건물 |
| **호스팅/클라우드** | 건물을 월세로 빌리는 것 |
| **프론트엔드** | 진열대와 인테리어 (손님이 보는 곳) |
| **백엔드** | 계산대와 창고 직원 (보이지 않는 처리) |
| **데이터베이스(DB)** | 장부와 창고 |
| **SSL(HTTPS)** | 손님과 가게 사이 대화를 아무도 엿듣지 못하게 하는 암호 |
| **CDN** | 전국 곳곳에 둔 작은 분점 창고 (사진을 가까운 곳에서 빨리 보냄) |

---

## 1. 접속 순서

```
손님 휴대폰
  │ ① "myshop.com 어디야?"
  ▼
DNS ── ② "123.45.67.89 번지야"
  │
  ▼ ③ HTTPS로 암호화해서 요청
서버(웹 서버 + 백엔드 프로그램)
  │ ④ "상품 목록 줘"
  ▼
데이터베이스 ── ⑤ 상품 정보 전달
  │
  ▼ ⑥ 화면(HTML)을 만들어 손님에게 보냄
손님 화면에 쇼핑몰 표시
```

---

## 2. 사이트를 이루는 "3가지 덩어리"

백업·업데이트를 이해하려면 이 구분이 **가장 중요**합니다.

| 덩어리 | 무엇이 들어 있나 | 얼마나 자주 바뀌나 | 어떻게 지키나 |
|---|---|---|---|
| **① 코드** | 화면 디자인, 프로그램 | 내가 고칠 때만 | **Git(버전 관리)** — 6장 |
| **② 데이터(DB)** | 회원, 주문, 결제 기록 | **매초** (손님이 주문할 때마다) | **DB 백업** — 8장 |
| **③ 파일(미디어)** | 상품 사진, 업로드 파일 | 상품 올릴 때 | **스토리지 백업** — 8장 |

> 💡 초보자가 가장 많이 하는 착각: "사이트 폴더를 통째로 복사해 두면 백업 끝!"
> → 코드는 복사됐지만 **주문·회원 정보는 DB라는 다른 곳**에 있어서 빠져 있는 경우가 많아요.
> 그래서 세 덩어리를 **각각 다른 방법**으로 지킵니다.

---

## 3. 호스팅의 종류

| 종류 | 비유 | 장점 | 단점 | 이런 사람에게 |
|---|---|---|---|---|
| **빌더형(SaaS)** — 카페24, 아임웹, 쇼피파이 | 백화점 입점 | 서버·보안·업데이트를 업체가 관리 | 자유도 낮음, 수수료/월 이용료 | 처음 쇼핑몰 |
| **웹호스팅(공유)** | 원룸 월세 | 저렴, 워드프레스 설치 쉬움 | 다른 사이트와 자원을 나눠 써서 느려질 수 있음 | 블로그, 소규모 |
| **VPS / 클라우드 서버** — AWS, 구글 클라우드, 네이버 클라우드 | 건물 한 층을 통째로 빌림 | 자유롭고 확장 쉬움 | 관리(보안·백업)를 직접 해야 함 | 직접 개발한 서비스 |
| **서버리스/플랫폼(PaaS)** — Vercel, Render 등 | 관리인 딸린 사무실 | 서버 관리 거의 없음, 배포 쉬움 | 사용량이 많아지면 비용 증가 | 개발자가 만든 작은 서비스 |

---

## 4. 도메인·SSL 관리 팁 (사고가 자주 나는 곳)

- 도메인은 **1년마다 갱신**합니다. 갱신을 놓치면 **사이트가 그냥 사라집니다.** → **자동 갱신**을 켜고, 결제 카드 유효기간도 확인.
- 도메인은 **회사(내) 명의 계정**으로 등록. 외주 업체 명의로 등록하면 나중에 되찾기 어려워요.
- SSL 인증서도 만료일이 있습니다. 요즘 대부분의 호스팅은 자동 갱신(예: Let's Encrypt)을 해 주지만, **만료 알림 메일**은 꼭 받는 메일로 설정.
- **이메일**: `help@myshop.com` 같은 도메인 메일을 쓰면 신뢰도가 올라갑니다.

---

### 이 장 요약
1. 도메인(간판) → DNS(지도) → 서버(건물) → DB(장부).
2. 사이트 = **코드 + 데이터 + 파일** 세 덩어리. 지키는 방법이 각각 다르다.
3. 도메인·인증서 **갱신 놓치기**가 초보자 사고 1위.
