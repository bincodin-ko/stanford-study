# 16. 커뮤니티 사이트 운영

**커뮤니티** = 사람들이 모여 글·댓글로 이야기하는 사이트. 예: 디시인사이드, 더쿠, 클리앙, 네이버 카페, 레딧, 디스코드 서버.

> 커뮤니티 사업의 특징: **콘텐츠를 운영자가 아니라 회원이 만든다.**
> 그래서 콘텐츠 비용은 거의 0이지만, 대신 **"사람 관리"** 가 일의 대부분이 됩니다.

---

## 1. 커뮤니티가 크는 순서

```
① 주제 정하기  → ② 첫 회원 모으기(가장 어려움) → ③ 글이 저절로 올라오는 단계
  → ④ 규칙·관리 체계 만들기 → ⑤ 돈 벌기
```

### ② 첫 회원 모으기 — "빈 식당" 문제
글이 없으면 아무도 안 쓰고, 아무도 안 쓰면 글이 없습니다. (1장의 "양면 시장"과 같은 문제)

해결 방법
- **주제를 아주 좁게**: "게임" 대신 "오목 고수 모임", "캠핑" 대신 "차박 장비 후기". 좁을수록 첫 회원이 모이기 쉬워요.
- **운영자가 처음 몇 달은 직접 글을 많이 쓴다** (씨앗 콘텐츠).
- 이미 사람이 모인 곳(오픈채팅, 기존 카페, SNS)에서 데려오기.
- **처음 100명**을 1명씩 직접 챙기기: 댓글 달아 주기, 이름 불러 주기.

### 1-9-90 법칙
커뮤니티에서 흔히 말하는 경험칙이에요.
- **1%** 는 글을 열심히 쓰고,
- **9%** 는 가끔 댓글을 달고,
- **90%** 는 읽기만 한다.

→ 글 쓰는 1%를 아끼고 챙기는 게 운영의 핵심입니다. (등급, 배지, 칭찬, 운영진 기회)

---

## 2. 꼭 필요한 기능

| 기능 | 이유 |
|---|---|
| 게시판 + 댓글 + 추천 | 기본 |
| **신고 버튼** | 문제 글을 회원이 알려 줌 (법적으로도 중요, 아래 4절) |
| **차단·제재 도구** | 글 숨기기, 회원 정지 |
| 검색 | 쌓인 글이 자산이 되게 |
| 알림 | 내 글에 댓글이 달리면 다시 오게 |
| 등급/포인트 | 활동하는 회원 보상 |
| **도배·광고 방지** | 가입 직후 글쓰기 제한, 링크 제한, 자동 가입 막기(캡차) |

만드는 방법: 네이버 카페·디스코드(무료, 대신 내 것이 아님) / 게시판 솔루션(그누보드, XE 계열, 디스코스 Discourse 등) / 직접 개발.

> ⚠️ 남의 플랫폼(카페·디스코드)은 시작이 쉽지만, **회원 목록과 규칙이 플랫폼 소유**예요. 커지면 독립 사이트로 옮기는 경우가 많습니다.

---

## 3. 운영 = 규칙 + 관리자 + 기록

### 규칙(이용 규칙) 예
```
1. 욕설·인신공격 금지          → 1회 경고, 2회 7일 정지
2. 광고·홍보 글 금지          → 즉시 삭제, 영구 정지
3. 개인정보(실명·연락처) 공개 금지 → 즉시 삭제
4. 불법 촬영물·음란물 금지      → 즉시 삭제, 영구 정지, 필요 시 신고
```
- 규칙은 **짧고, 구체적이고, 처벌 수준까지** 적어 두면 분쟁이 줄어요.
- 제재할 때는 **"어떤 규칙 몇 번 위반"** 을 남기기(기록). 나중에 "왜 정지했냐" 항의에 대응 가능.

### 관리자(모더레이터) 운영
- 커지면 혼자 못 봅니다. **열심히 활동하는 회원**을 부운영자로.
- 관리자 권한은 **필요한 만큼만**(10장 최소 권한), 관리자 작업도 기록.

### 커뮤니티가 망가지는 흔한 이유
- 운영자가 사라짐(답이 없음) → 회원도 떠남
- 소수의 싸움꾼 방치 → 다수의 조용한 회원이 떠남
- 광고·스팸 도배
- 갑작스러운 규칙 변경, 운영자의 불투명한 결정

## 4. 커뮤니티 운영자가 알아야 할 법

> ⚠️ 2026년 10월 조사 기준. 법 원문은 국가법령정보센터에서 꼭 다시 확인하세요.

| 주제 | 핵심 |
|---|---|
| **명예훼손·권리침해 글 (정보통신망법 제44조의2)** | 피해자가 삭제를 요청하면 **지체 없이 삭제 또는 임시조치**(최대 30일 동안 안 보이게 가려 두기)를 하고, 요청한 사람과 글쓴이에게 알려야 해요. 이렇게 하면 운영자 책임이 줄어들 수 있습니다 |
| **불법촬영물 유통 방지 (전기통신사업법)** | 매출 10억 원 이상 또는 하루 평균 이용자 10만 명 이상 등 일정 규모가 되면 **신고 기능, 검색 제한, 필터링** 같은 기술적 조치 의무가 생깁니다. 작은 커뮤니티라도 발견하면 **즉시 삭제**가 원칙 |
| **청소년 유해 정보** | 성인 게시판을 두려면 **성인 인증**과 청소년 접근 차단 |
| **개인정보 (10장)** | 가입 정보는 최소한만. 휴면·탈퇴 회원 정보 관리 |
| **저작권** | 회원이 퍼 온 기사·만화·영상 → 권리자가 요청하면 삭제 |
| **광고 글** | 회원인 척 쓰는 업체 홍보(바이럴 알바)는 표시광고법 문제가 될 수 있음 → 규칙으로 금지 |

## 5. 커뮤니티로 돈 버는 법

| 방법 | 설명 | 주의 |
|---|---|---|
| **디스플레이 광고** | 애드센스 등 (18장) | 성인·도박·혐오 글이 많으면 광고 정지 |
| **유료 멤버십** | 광고 제거, 전용 게시판, 배지 | "돈 낸 사람 vs 안 낸 사람" 갈등 관리 |
| **공동구매·제휴** | 회원 대상 할인 판매 | 회원 신뢰가 최우선, 이익 구조 공개 |
| **스폰서/브랜드 협업** | 업체 후원 이벤트 | 광고임을 반드시 표시 |
| **채용·중고장터 유료 게시** | 직군 커뮤니티에서 흔함 | |
| **오프라인 모임·행사** | 참가비 | |

> 💡 커뮤니티 수익의 원칙: **회원이 "운영자가 우리를 팔아먹는다"고 느끼는 순간 끝**입니다. 광고는 적게, 투명하게.

## 6. 커뮤니티 핵심 지표

| 지표 | 뜻 |
|---|---|
| **DAU / MAU** | 하루/한 달 방문 회원 수 |
| **DAU/MAU 비율** | "한 달에 온 사람 중 매일 오는 비율". 높을수록 습관이 된 커뮤니티 |
| 하루 새 글 수 / 댓글 수 | 살아 있는지 |
| **글 쓰는 회원 비율** | 1-9-90에서 1%가 유지되나 |
| 신고 건수, 처리 시간 | 관리가 되고 있나 |
| 재방문율 | 다시 오나 |

---

### 이 장 요약
1. 커뮤니티는 **좁은 주제 + 운영자의 초반 노력**으로 시작한다.
2. 운영의 핵심은 **명확한 규칙, 믿을 만한 관리자, 모든 제재의 기록**.
3. 신고·삭제·임시조치 의무를 알고, 수익화는 **회원 신뢰를 해치지 않게**.
