# 20. 게임 사이트 — 오목을 예로

> 롤·배그 같은 **실시간 멀티플레이 서버 구조**는 [40장](40-multiplayer-game-servers.md), **핵·어뷰징 대응**은 [41장](41-abuse-and-cheat-prevention.md)에 있어요.

웹에서 바로 하는 게임(브라우저 게임)이나 모바일 게임도 인터넷 사업이에요.
여기서는 **"온라인 오목 사이트"** 를 예로 들어 설계 → 운영 → 수익 → 법까지 봅니다.

---

## 1. 게임 사업의 종류

| 종류 | 예 | 특징 |
|---|---|---|
| **혼자 하는 캐주얼 게임** | 2048, 테트리스류, 퍼즐 | 서버 단순, 광고 수익 위주 |
| **1:1 대전 보드게임** | **오목**, 바둑, 체스, 장기 | 실시간 대전 서버, 실력 점수(레이팅) |
| **웹보드게임(고스톱·포커류)** | 맞고, 포커 | **사행성 규제가 매우 강함** (5절) |
| **멀티플레이 온라인 게임** | MMORPG, 배틀로얄 | 큰 팀·큰 서버 필요 |
| **모바일 게임** | 앱스토어·구글플레이 | 인앱결제, 마켓 수수료 |

---

## 2. 오목 사이트 설계 (MVP)

### Must 기능
1. **AI와 대전** (혼자 접속해도 바로 할 수 있게 — 초반엔 사람이 적으니까 가장 중요!)
2. **빠른 대전 (매칭)**: 버튼 누르면 비슷한 실력자와 연결
3. **친구 초대 대전**: 링크 공유로 친구와 한 판
4. **게임 기록·전적**
5. **기본 규칙 선택**: 자유룰 / **렌주룰**(흑의 3-3, 4-4, 장목 금지처럼 선공 유리함을 줄이는 규칙)

### Should / Could
- **레이팅(실력 점수)**: 체스에서 쓰는 **Elo 레이팅**처럼, 이기면 오르고 지면 내려가는 점수 → 비슷한 실력끼리 매칭
- 랭킹, 시즌, 배지
- 기보(대국 기록) 다시 보기, 관전
- 채팅 (→ 욕설 필터·신고 기능 필수, 16장)

### 기술 구조 (쉽게)
```
손님 브라우저 ──(실시간 연결: 웹소켓)── 게임 서버 ── DB(회원, 전적, 레이팅)
                                         │
                                     매칭 대기열
```
- **웹소켓(WebSocket)** = 서버와 손님 화면이 계속 연결돼 있어서, 상대가 돌을 두면 **바로** 내 화면에 나타나게 하는 기술.
- **중요한 원칙: 판정은 서버가 한다.** 승패·규칙 판단을 손님 브라우저에 맡기면 조작당해요.

## 3. 게임 운영에서만 생기는 일

| 운영 이슈 | 내용 | 대응 |
|---|---|---|
| **부정행위(치팅)** | 다른 창에 오목 AI를 켜 두고 그대로 따라 두기 | 수 두는 시간 패턴·AI 일치율 분석, 신고 제도, 레이팅 박탈 |
| **고의 패배·부계정** | 점수 조작 | 같은 기기/IP 반복 대전 감지 |
| **접속 끊김(탈주)** | 지는 판에서 나가 버림 | 일정 시간 미복귀 시 패배 처리 |
| **매칭 대기 시간** | 사람이 적은 시간엔 상대가 없음 | AI 대전으로 연결, 실력 범위 점점 넓히기 |
| **비매너 채팅** | 욕설 | 필터, 신고, 채팅 끄기 옵션 |
| **동시 접속 폭주** | 방송·커뮤니티에 소개되면 몰림 | 서버 확장 여유, 대기열 |
| **업데이트** | 게임 중인 사람이 있을 때 배포하면 판이 끊김 | **새 판 시작을 막고 → 진행 중인 판이 끝나면 배포** (점검 공지, 7장) |

### 게임 사이트 지표
| 지표 | 뜻 |
|---|---|
| **동시 접속자(CCU)** | 지금 이 순간 접속한 사람 수 |
| **DAU, 하루 판 수** | 얼마나 활발한가 |
| **리텐션 D1 / D7 / D30** | 처음 온 사람이 1일·7일·30일 뒤에도 오는 비율 (게임에서 가장 중요한 숫자 중 하나) |
| **평균 매칭 대기 시간** | 길면 사람이 떠남 |
| **ARPDAU** | 하루 이용자 1명당 평균 수익 |

## 4. 게임으로 돈 버는 법

| 방법 | 오목 사이트 예 | 주의 |
|---|---|---|
| **디스플레이 광고** | 대국 사이 화면에 배너 | 게임 중 화면을 가리면 이용자 이탈 |
| **보상형 광고** | 광고 보면 "무르기 1회", "힌트" | 강제하지 말고 선택하게 |
| **광고 제거 구독** | 월 몇천 원에 광고 없이 | 가장 깔끔한 모델 |
| **꾸미기 아이템** | 바둑판·돌 디자인, 프로필 테두리 | 실력에 영향 없는 것만 → 공정성 유지 |
| **유료 강좌·기보 분석** | AI 분석 리포트 | |
| **대회 스폰서** | 업체 후원 온라인 대회 | 상금 대회는 **참가비를 걷어 상금으로 주면 도박 문제**가 될 수 있으니 주의 |

> 앱 마켓(구글플레이·앱스토어)에서 인앱결제를 하면 **마켓 수수료**(일반적으로 매출의 15~30% 수준, 조건에 따라 다름)가 빠진다는 것도 계산에 넣으세요.

## 5. 게임 사이트의 법 — 꼭 알아야 할 3가지

> ⚠️ 2026년 10월 조사 기준. **게임산업진흥법**과 시행령, **게임물관리위원회** 공지에서 꼭 다시 확인하세요.

### ① 등급분류
- 한국에서 게임을 서비스하려면 원칙적으로 **등급분류**(전체이용가/12세/15세/청소년이용불가)를 받아야 해요.
- **구글플레이·앱스토어** 같은 오픈마켓에 올리면 보통 **마켓의 자체 등급분류**로 처리됩니다.
- **내 웹사이트에서 직접** 서비스하는 경우는 게임물관리위원회 등급분류 대상인지, 비영리·소규모 예외에 해당하는지 **직접 확인**이 필요해요. (광고·결제로 돈을 벌면 "영리"로 볼 가능성이 높아요.)

### ② 게임머니·아이템의 현금화(환전) 금지
- 게임 결과로 얻은 포인트·게임머니를 **현금으로 바꿔 주거나, 환전을 업으로 하면 불법**입니다.
- **"이기면 돈을 받는" 오목** = 게임이 아니라 **도박**이에요. 참가비 걷고 상금 주는 구조도 위험.
- 고스톱·포커 같은 **웹보드게임**은 별도로 결제 한도·1회 사용 한도 같은 **강한 사행성 규제**가 있어서 개인이 시작하기엔 적합하지 않아요.

### ③ 확률형 아이템 확률 공개 (2024년 3월 22일 시행)
- "뽑기(가챠)"처럼 **유료로 사서 무작위로 결과가 나오는 아이템**을 팔면, 아이템별 **확률을 백분율로 게임 화면과 홈페이지에 공개**해야 해요. 확률을 바꿀 땐 미리 공지.
- 연평균 매출 1억 원 이하 영세 게임사 등은 예외라고 보도됐지만, 처음부터 투명하게 공개하는 게 신뢰에도 좋아요.

## 6. 오목 사이트 1년 로드맵 (예시)

| 시기 | 할 일 |
|---|---|
| 1개월 | AI 대전 + 친구 초대 대전만으로 출시 (MVP). 광고 없이 반응 보기 |
| 2~3개월 | 빠른 대전·레이팅 추가. 오목 커뮤니티·유튜버에게 소개 |
| 4~6개월 | 광고 붙이기, 꾸미기 아이템. 부정행위 감지 시작 |
| 6~12개월 | 시즌 랭킹, 온라인 대회(상금은 운영자 부담, 참가비 없음), 모바일 앱 검토 |

---

### 이 장 요약
1. 1:1 게임은 **사람이 적어도 굴러가게(AI 대전)** 설계하는 게 첫 번째.
2. **판정은 서버가**, 부정행위·탈주·매칭 대기가 게임 운영의 핵심 이슈.
3. 법: **등급분류, 환전 금지(돈 걸면 도박), 확률형 아이템 공개**.
