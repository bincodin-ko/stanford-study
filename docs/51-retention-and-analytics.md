# 51. 단골 만들기와 데이터 분석 실습

새 손님을 데려오는 비용(CAC)은 점점 비싸져요. **이미 온 손님이 다시 오게 하는 것**이 1인 사업의 가장 싼 성장 방법이에요.
이 장은 **단골 만들기(리텐션·CRM)** 와 **내 데이터를 직접 분석해 보는 실습**이에요. (3·11장 지표와 이어져요)

> ([참고 자료 모음](sources.md))

---

## 1. 왜 단골인가 — 숫자로

```
손님 1명 데려오는 데 5,000원 (CAC)
첫 구매 이익 3,200원 → 첫 구매만으론 -1,800원 (2장 예시)
두 번째 구매(광고비 0원) 이익 3,200원 → 누적 +1,400원
세 번째 구매 → 누적 +4,600원
```
→ **재구매가 있어야 광고가 남는 장사가 돼요.** 구독 서비스는 이탈률(Churn)이 같은 역할을 해요.

---

## 2. 단골 만드는 장치

| 장치 | 예 | 주의 |
|---|---|---|
| **첫 경험(온보딩)** | 첫 구매 후 사용법 안내, 첫 주문에 손편지 | 첫 경험이 재방문을 가장 크게 좌우 |
| **재구매 알림** | 소모품이면 다 쓸 때쯤 "다시 주문하기" 알림 | 광고 메시지 규칙 (30장) |
| **적립금·등급** | 구매 금액에 따라 등급 | 너무 복잡하면 효과 ↓ |
| **정기 배송·구독** | 매달 자동 발송, 구독 할인 | 해지 쉽게 (43장) |
| **커뮤니티** | 손님끼리 후기·레시피 공유 (16장) | 운영 부담 |
| **콘텐츠** | 뉴스레터, 활용법 영상 | 꾸준함 |
| **CS로 감동** | 빠르고 친절한 해결 (30장) | 불만 손님이 단골이 되기도 |
| **휴면 손님 깨우기** | 3개월 안 온 손님에게 "보고 싶었어요" 쿠폰 | 수신 동의자만 |

---

## 3. 손님을 나눠 보기 — RFM

**RFM** = 손님을 세 가지 기준으로 나누는 방법이에요.

| 기준 | 질문 |
|---|---|
| **R (Recency, 최근성)** | 마지막 구매가 얼마나 최근인가 |
| **F (Frequency, 빈도)** | 몇 번 샀나 |
| **M (Monetary, 금액)** | 얼마나 썼나 |

| 그룹 | 특징 | 할 일 |
|---|---|---|
| **VIP** | 최근·자주·많이 | 감사 선물, 신제품 먼저 |
| **떠나려는 단골** | 예전엔 자주, 최근엔 안 옴 | 이유 묻기, 재방문 혜택 |
| **새 손님** | 최근 첫 구매 | 두 번째 구매 유도 (가장 중요한 순간) |
| **잠든 손님** | 오래전 한 번 | 과한 비용 쓰지 않기 |

---

## 4. 코호트로 보는 리텐션

**코호트** = 같은 시기에 처음 온 손님 묶음 (3장).

| 첫 구매 월 | 1개월 후 재구매 | 2개월 후 | 3개월 후 |
|---|---|---|---|
| 1월 손님 100명 | 20% | 12% | 9% |
| 2월 손님 120명 | 25% | 15% | — |
| 3월 손님 90명 | 30% | — | — |

→ 아래로 갈수록(최근 손님일수록) 재구매율이 오르면 **개선이 효과가 있는 것**이에요. 전체 평균만 보면 이런 변화가 안 보여요.

## 5. 데이터 분석 실습 — 엑셀·파이썬으로 직접

빌더·PG에서 **주문 내역을 CSV로 내려받아**(8장) 직접 분석해 볼 수 있어요.

### 실습 데이터 형태
```
주문번호,손님ID,주문일,금액
1001,A,2026-01-05,12900
1002,B,2026-01-07,25800
1003,A,2026-02-03,12900
...
```

### 파이썬으로 재구매율 구하기 ([코딩 5장](coding/05-basics-2.md) 실습과 연결)
```python
import csv
from collections import defaultdict

orders = defaultdict(list)                     # 손님별 주문 목록
with open("orders.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        orders[row["손님ID"]].append(int(row["금액"]))

customers = len(orders)
repeaters = sum(1 for amounts in orders.values() if len(amounts) >= 2)
print(f"전체 손님: {customers}명")
print(f"재구매 손님: {repeaters}명 ({repeaters / customers:.0%})")
print(f"손님당 평균 매출: {sum(map(sum, orders.values())) / customers:,.0f}원")
```
(예제 데이터로 실행해 확인한 코드예요.)

### 엑셀이라면
- **피벗 테이블**: 행 = 손님ID, 값 = 주문 수·금액 합계 → 2회 이상 손님 세기
- 월별 매출·주문 수 그래프

### 매달 보는 대시보드 (한 장)
| 지표 | 이번 달 | 지난달 |
|---|---|---|
| 방문자 · 전환율 · 객단가 (11장) | | |
| 신규 손님 · 재구매 손님 | | |
| 재구매율 · 코호트 1개월 리텐션 | | |
| CAC · ROAS (32장) | | |
| 문의 수 · 주요 문의 유형 (30장) | | |
| 손익 · 현금 (44장) | | |

- 구글 시트·루커 스튜디오 같은 무료 도구로 GA4·시트 데이터를 그래프로 묶을 수 있어요.
- AI에게 "이 CSV에서 재구매율·코호트 표를 만들어 줘"라고 할 수 있지만, **개인정보는 지우고(손님ID만)** 넘기세요 (10장).

## 6. 숫자를 볼 때 흔한 착각

| 착각 | 설명 |
|---|---|
| **평균의 함정** | 큰손 한 명이 평균을 끌어올림 → 중간값도 보기 |
| **상관 ≠ 원인** | "앱 쓰는 손님이 더 산다" → 앱 때문인지, 원래 열성 손님이 앱을 깐 건지 |
| **적은 숫자** | 방문자 50명에서 전환율 차이는 우연일 수 있음 (11장 A/B) |
| **허영 지표** | 누적 가입자·팔로워는 늘기만 함 → **활성 사용자·재구매** 같은 행동 지표를 보기 (32장) |

### 이 장 요약
1. **재구매가 있어야 광고비가 남는다.** 첫 경험·재구매 알림·구독·커뮤니티·CS로 단골을 만든다.
2. 손님은 **RFM**으로 나누고, 리텐션은 **코호트 표**로 본다.
3. 주문 CSV를 내려받아 **직접 재구매율을 계산**해 보고, 매달 **한 장짜리 대시보드**로 판단한다.
