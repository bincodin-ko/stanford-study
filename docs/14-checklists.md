# 14. 체크리스트 모음

복사해서 그대로 쓰세요. `[ ]` 를 `[x]` 로 바꾸며 체크하면 됩니다.

---

## 1. 출시 전 체크리스트

**사업·법**
- [ ] 사업자등록 완료
- [ ] 통신판매업 신고 (또는 면제 여부를 구청/정부24에 확인)
- [ ] PG 결제 연동, 구매안전서비스 가입
- [ ] 사이트 하단: 상호·대표자·사업자번호·통신판매업 번호·주소·연락처
- [ ] 이용약관, 개인정보처리방침 게시
- [ ] 회원가입 동의: 필수 / 선택 / 마케팅 수신 **분리**
- [ ] 교환·반품·환불 규정 안내

**사이트**
- [ ] 휴대폰(아이폰·안드로이드)·PC에서 가입 → 구매 → 취소 테스트
- [ ] 실제 카드 소액 결제 후 환불 테스트
- [ ] 주문·배송 알림(메일/문자) 수신 확인
- [ ] HTTPS(자물쇠) 확인
- [ ] 404(없는 페이지) 화면 확인
- [ ] 페이지 속도 확인, 사진 용량 줄이기
- [ ] 페이지 제목·설명(SEO), 파비콘(탭 아이콘)

**운영 준비**
- [ ] 도메인 **내 명의**, **자동 갱신 ON**
- [ ] 모든 관리자 계정 **2단계 인증**
- [ ] 계정 목록 문서 (서비스명, 관리자, 갱신일)
- [ ] 백업 설정 및 첫 백업 확인
- [ ] 모니터링(업타임) 알림 설정
- [ ] GA4 / 서치 콘솔 / 네이버 서치어드바이저 등록
- [ ] FAQ, 답변 템플릿 준비
- [ ] 도메인 이메일(help@ 등) + 문의 폼 설정, SPF·DKIM·DMARC 기록 확인 (30장)
- [ ] 광고 메일을 보낼 거라면: 마케팅 수신 동의(선택) 따로 받기, (광고) 표시·수신거부 넣기 (30장)

## 2. 배포(업데이트) 전후 체크리스트

**배포 전**
- [ ] 무엇을 왜 바꾸는지 한 줄 기록
- [ ] DB(또는 데이터 내보내기) 백업
- [ ] 현재 버전 기록 / 기존 스킨 복사
- [ ] 스테이징(테스트 스킨)에서 핵심 흐름 확인: 가입 → 장바구니 → 결제
- [ ] 되돌리는 방법 확인 (어떻게 롤백하지?)
- [ ] 배포 시간: 손님 적은 시간, **금요일 저녁·이벤트 직전 아님**
- [ ] 필요하면 손님 공지

**배포 후**
- [ ] 운영 사이트에서 직접 핵심 흐름 다시 확인
- [ ] 10~30분간 주문·오류 모니터링
- [ ] 변경 이력(릴리스 노트) 작성
- [ ] 문제 시: **먼저 롤백**, 원인은 그다음

## 3. 정기 점검표

**매일 (10분)**
- [ ] 신규 주문·결제 확인
- [ ] 문의·리뷰 답변
- [ ] 모니터링 알림 확인
- [ ] 어제 매출·광고비·ROAS

**매주**
- [ ] 백업 성공 여부 확인
- [ ] 상품·회원·주문 데이터 내보내기 (빌더 사용 시)
- [ ] 플러그인·프로그램 보안 업데이트 확인
- [ ] 주간 지표: 방문자, 전환율, 객단가, 재구매율
- [ ] 문의 내용 분류 → 개선 아이디어 목록

**매월**
- [ ] 도메인·SSL·결제 카드 만료일 확인
- [ ] 안 쓰는 계정·권한 삭제
- [ ] PG 정산 금액 대조
- [ ] 월간 손익 (매출 − 원가 − 광고비 − 고정비)
- [ ] 보관 기간 지난 개인정보 파기
- [ ] 답 못 한 문의가 없는지 확인, 자주 온 문의로 FAQ 보강 (30장)

**분기**
- [ ] **복구 훈련** (백업 → 스테이징 복구 → 확인 → 시간 측정)
- [ ] 관리자 비밀번호·API 키 교체
- [ ] 약관·개인정보처리방침 최신 법 반영 확인
- [ ] 경쟁사 사이트 둘러보기

**매년**
- [ ] 1월·7월 부가세, 5월 종합소득세
- [ ] 도메인·호스팅 연간 갱신
- [ ] 사업 목표·수익 모델 재점검

## 4. 장애 대응 카드 (벽에 붙여 두기)

```
1. 침착하게: 무엇이 안 되나? (전체 / 결제만 / 일부)
2. 1급인가? (사이트 다운, 결제 불가, 개인정보 유출 의심 → 즉시)
3. 최근에 바꾼 게 있나? → 있으면 먼저 되돌리기(롤백)
4. 손님 공지 (배너/공지사항)
5. 외부 원인 확인: 호스팅·PG·빌더 상태 페이지, 고객센터
6. 복구 후 확인: 실제 주문 테스트
7. 포스트모템: 언제, 무엇, 영향, 원인, 해결, 재발 방지
```
