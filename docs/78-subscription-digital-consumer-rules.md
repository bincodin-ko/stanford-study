# 78. 구독·디지털 상품의 소비자 규칙 — 다크패턴 규제법, 환불, 미성년자 결제

> 청약철회(반품·환불) 기본은 [10장](10-security-and-law.md), 다크 패턴 디자인은 [48장](48-ux-ui-copywriting.md), 요금제·무료 체험은 [43장](43-pricing-strategy.md), 정기 결제 구현은 [39장](39-payments-and-settlement.md)에 있어요.

SaaS·구독·앱·전자책·강의·게임 아이템처럼 **디지털 상품이나 정기 결제**를 팔면 꼭 알아야 할 규칙이에요. 1인 사업자도 **실제로 제재받은 사례**가 나오고 있어요.

> ⚠️ 법 해설은 기사·법률사무소 자료 기준이에요. 정확한 조문과 기간은 국가법령정보센터의 전자상거래법 원문과 공정거래위원회 안내(다크패턴 가이드라인·문답서)를 확인하세요. ([참고 자료 모음](sources.md))

## 1. 온라인 다크패턴 규제 — 2025년 2월 14일 시행

전자상거래법이 바뀌어 **6가지 다크패턴**이 법으로 금지됐어요. 48장에서 "하지 말 것"으로 배운 것이 이제 **과태료 대상**이에요.

| 유형 | 금지되는 것 | 내 서비스에서 지킬 것 |
|---|---|---|
| **① 숨은 갱신** | 무료 체험이 **몰래 유료로** 바뀌거나, 정기 결제 금액을 **몰래 올리기** | 유료 전환·가격 인상 **전에 미리 알리고 동의** 받기 (기사·해설에서는 30일 전 고지·동의로 설명 — 원문 확인) |
| **② 순차공개 가격책정** | 첫 화면엔 싼 가격만, 결제 직전에 **추가 비용** 공개 | **총 금액**(필수 수수료·배송비 포함)을 처음부터 표시 |
| **③ 특정 옵션 사전 선택** | 유료 옵션·추가 상품에 **미리 체크** | 추가 상품은 **기본값 해제**, 손님이 직접 선택 |
| **④ 잘못된 계층 구조** | "구독 유지" 버튼은 크게, "해지"는 작고 흐리게 | 선택지를 **같은 크기·같은 눈에 띄는 정도**로 |
| **⑤ 취소·탈퇴 방해** | 가입은 쉬운데 해지·탈퇴는 **숨기거나 복잡하게** | **가입한 방법만큼 쉽게** 해지 (온라인 가입 → 온라인 해지) |
| **⑥ 반복 간섭** | 거절했는데 **팝업을 계속** 띄우기 | 거절하면 **일정 기간 다시 묻지 않기** |

### 실제 제재와 과태료
- 공정위 모니터링(2025년 2~7월)에서 의심 사례 45건, 가장 많은 유형은 **취소·탈퇴 방해**(15건), **숨은 갱신**(9건)이었다고 보도됐어요.
- 2025년 10월, 음원·OTT·쇼핑 회사 4곳이 **첫 제재**(시정명령 + 과태료)를 받았어요.
- 과태료는 위반 횟수에 따라 늘고, 반복하면 영업정지까지 가능하다고 보도됐어요(금액 기준은 자료마다 달라 원문 확인).
- 순차공개 가격책정은 6개월 계도 기간이 있었고 **2025년 8월에 끝났어요.**

### 구독 서비스 체크리스트
```
□ 무료 체험 신청 화면에: 끝나는 날짜, 그 뒤 금액, 해지 방법을 한눈에
□ 유료 전환 전 안내 메일·알림 (64장 정보성 메시지) + 필요한 동의
□ 가격 인상: 기존 구독자에게 미리 알리고 동의 받기 (43장 그랜드파더링도 고려)
□ 가격 표시는 부가세·수수료 포함 총액
□ 해지 버튼: 설정 화면에서 2~3번 클릭 안에, "상담원 연결해야 해지" 금지
□ 해지 화면: "정말요?" 한 번은 괜찮지만 해지·유지 버튼은 같은 크기
□ 거절한 업셀 팝업은 일정 기간 다시 안 띄우기
□ 앱스토어 구독이면 스토어 구독 관리로 가는 길 안내
```

> 💡 Claude에게: "우리 가입·결제·해지 화면을 보고, 전자상거래법의 다크패턴 6유형(숨은 갱신, 순차공개 가격, 사전 선택, 잘못된 계층, 취소 방해, 반복 간섭)에 해당할 수 있는 곳을 표로 찾아 줘."

## 2. 디지털 상품의 환불 (청약철회)

- 온라인으로 산 상품은 원칙적으로 **7일 안에 청약철회**(환불)할 수 있어요(10장).
- **디지털 콘텐츠**(전자책, 강의 영상, 앱 아이템, 다운로드 파일)는 **이미 제공이 시작된 경우** 청약철회를 제한할 수 있어요. 단, **사업자가 미리 조치**를 했어야 해요(전자상거래법 17조 해설 기준):
  1. "**청약철회가 안 된다**"는 사실을 **잘 보이게 표시**
  2. **미리 써 볼 수 있는 것**(맛보기 강의, 샘플 페이지, 체험판 등) 제공
- 이 조치 없이 "디지털 상품은 무조건 환불 불가"라고만 적으면 **소비자에게 불리한 약관은 무효**가 될 수 있어요.
- **아직 쓰지 않은 부분**(열어 보지 않은 강의, 쓰지 않은 아이템)은 환불 대상이 될 수 있어요. 기준을 약관과 상세 페이지에 분명히.
- 구독은 **해지 시 남은 기간 처리**(남은 날 환불 / 기간 끝까지 이용)를 미리 정해 공지하세요.

### 디지털 상품 상세 페이지에 넣을 것
```
□ 무엇을, 어떤 형식으로, 언제까지 이용 가능한지
□ 미리보기·맛보기 (청약철회 제한의 조건)
□ 청약철회가 제한되는 경우와 제한되지 않는 경우
□ 환불 방법·기간·계산 방식
□ 이용 기기·환경 (안 열리면 환불 사유)
```

## 3. 미성년자 결제

- 민법상 **미성년자가 법정대리인(부모 등) 동의 없이 한 계약은 취소할 수 있는 게 원칙**이에요(일반적인 법 원칙 — 세부 예외는 원문 확인). 게임·앱 결제에서 분쟁이 자주 생겨요.
- 그래서 미성년자가 쓸 수 있는 서비스는:
  - 가입 때 **나이 확인**, 만 14세 미만은 법정대리인 동의 (10·65장)
  - 미성년자 **결제 한도** 또는 결제 전 법정대리인 동의 절차
  - 부모가 취소를 요청하면 처리할 **절차와 담당 창구** (30장)
- 앱스토어 결제는 스토어의 **가족 결제·환불 정책**도 함께 적용돼요.
- 확률형 아이템(20장)은 **확률 공개 의무**도 따로 있어요.

## 4. 정기 결제 운영 실무 (39장 보강)

| 상황 | 할 것 |
|---|---|
| **결제 실패** (카드 만료·잔액 부족) | 바로 끊지 말고 **재시도 + 안내 메일**(며칠 간격 2~3회), 유예 기간 후 이용 정지 |
| **결제 예정 알림** | 연간 구독은 결제 며칠 전 알림 → 원치 않는 갱신 분쟁 줄이기 |
| **영수증·세금계산서** | 매번 자동 발송, B2B는 세금계산서 (71장) |
| **가격 변경** | 1절 숨은 갱신 규칙대로 사전 고지·동의 |
| **해지 사유 묻기** | 선택 질문 하나로 (51·73장 개선 자료). 답하지 않아도 해지되게 |
| **환불 요청** | 처리 기한·방법 템플릿 (30장) |

---

### 이 장 요약
1. 2025년 2월부터 **다크패턴 6유형이 법으로 금지**: 숨은 갱신, 순차공개 가격, 사전 선택, 잘못된 계층, 취소·탈퇴 방해, 반복 간섭. **해지는 가입만큼 쉽게**, 유료 전환·가격 인상은 **미리 알리고 동의**.
2. 디지털 상품의 환불 제한은 **"철회 불가" 표시 + 미리보기 제공**을 했을 때만. 그냥 "환불 불가"는 무효가 될 수 있다.
3. 미성년자 결제는 **취소될 수 있다**는 전제로 나이 확인·한도·취소 창구를 준비.
