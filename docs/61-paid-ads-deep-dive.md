# 61. 유료 광고 심화 — 채널별 세팅, 소재 테스트, 측정

> 메타(인스타·페이스북) 광고 기초와 네이버 검색광고 기초는 [32장](32-marketing-channels.md), 숫자(ROAS·CAC) 기초는 [11장](11-growth-and-data.md)에 있어요. 이 장은 그다음 단계예요.

> ⚠️ 광고 플랫폼은 **메뉴 이름·캠페인 종류·최소 금액이 자주 바뀌어요.** 이 장은 2026년 11월에 조사한 내용이고, 대부분 광고 대행사 블로그 기준이에요. 실제로 돈을 쓰기 전에 각 플랫폼의 공식 도움말을 확인하세요. ([참고 자료 모음](sources.md))

## 1. 광고를 켜기 전에 — 이 3가지가 없으면 돈만 나가요

| 준비물 | 왜 | 관련 장 |
|---|---|---|
| **① 손님이 사는 상세 페이지** | 광고는 사람을 **데려올** 뿐, 파는 건 페이지. 전환율 1% 미만이면 광고보다 페이지부터 | 48장 |
| **② 전환 추적** | "광고로 몇 명이 샀나"를 모르면 좋은 광고를 구분할 수 없어요. GA4·픽셀·전환 API 설정 | 38장, 이 장 6절 |
| **③ 손익분기 ROAS** | 광고비를 빼고 **0원이 남는 선**. 이보다 낮으면 팔수록 손해 | 이 장 2절 |

**리뷰도 먼저**: 리뷰가 0개인 상품에 광고하면 클릭은 나와도 잘 안 사요. 지인·소프트 런칭으로 진짜 후기를 먼저 모으세요(가짜 후기는 불법, 10장).

## 2. 손익분기 ROAS 계산 — 내 광고의 합격선

**ROAS** = 광고비 대비 매출. 광고비 1만 원으로 5만 원 팔면 500%.

"ROAS 300%면 좋다" 같은 말은 **상품마다 다르기 때문에** 그대로 믿으면 안 돼요. 내 상품의 합격선을 직접 계산하세요.

> **손익분기 ROAS = 판매가 ÷ (판매가 − 원가·배송비·수수료 등) × 100**
> = 1 ÷ 마진율

```python
def break_even_roas(price, cost):
    """광고비를 빼고 0원이 남는 ROAS(%)를 계산해요."""
    margin = price - cost            # 1개 팔면 광고 전에 남는 돈
    return price / margin * 100      # = 1 ÷ 마진율

price = 30000                         # 판매가
cost = 12000 + 3500 + 1500 + 1000     # 원가 + 배송비 + 결제·플랫폼 수수료 + 포장
be = break_even_roas(price, cost)
print(f"마진율 {(price - cost) / price:.0%}, 손익분기 ROAS {be:.0f}%")

for roas in [200, 300, 400]:
    ad = 100000                       # 광고비 10만 원
    sales = ad * roas / 100
    profit = sales * (price - cost) / price - ad
    print(f"ROAS {roas}%: 매출 {sales:,.0f}원, 광고비 빼고 남는 돈 {profit:,.0f}원")
```

실행 결과 (직접 돌려 확인했어요):
```
마진율 40%, 손익분기 ROAS 250%
ROAS 200%: 매출 200,000원, 광고비 빼고 남는 돈 -20,000원
ROAS 300%: 매출 300,000원, 광고비 빼고 남는 돈 20,000원
ROAS 400%: 매출 400,000원, 광고비 빼고 남는 돈 60,000원
```

- 이 상품은 **ROAS 250%가 합격선**이에요. 200%면 **팔수록 손해**예요.
- 마진율이 20%인 상품은 합격선이 500%예요. **마진이 낮을수록 광고가 어려워요** → 43장 가격, 세트 상품으로 객단가 올리기.
- 첫 구매는 손해여도 **재구매**로 이익이 나면 괜찮을 수 있어요. 그때는 LTV(손님 1명이 평생 주는 이익)로 봐요(11·51장).

## 3. 채널별 광고 — 어디에 무엇을

| 채널 | 손님 상태 | 잘 맞는 사업 | 시작 팁 |
|---|---|---|---|
| **네이버 검색광고** | 이미 **찾고 있음** | 국내 거의 모든 사업, 지역 가게 | 32장. 세부 키워드부터 |
| **구글 검색 광고** | 이미 **찾고 있음** | B2B, 해외, IT·개발 관련, 외주 | 아래 3-1 |
| **유튜브 광고** | 둘러보는 중 | 보여 줘야 이해되는 상품, 앱, 교육 | 아래 3-2 |
| **메타(인스타·페북)** | 둘러보는 중 | 눈에 띄는 소비재, 패션·뷰티·식품 | 32장 |
| **카카오 광고** | 둘러보는 중 | 국내 대중 상품, 지역·생활 서비스 | 아래 3-3 |
| **쿠팡·스마트스토어 광고** | **사려고 들어옴** | 오픈마켓에서 파는 실물 상품 | 아래 3-4 |

> 💡 처음에는 **"이미 찾고 있는 사람"에게 보이는 광고(검색·쇼핑)**가 성공하기 쉬워요. 둘러보는 사람에게 보이는 광고(SNS·영상)는 **소재 실력**이 필요해요.

### 3-1. 구글 광고 (Google Ads)

| 캠페인 종류 | 어디에 나오나 | 초보자에게 |
|---|---|---|
| **검색** | 구글 검색 결과 위 | ✅ **여기서 시작**. 키워드를 직접 고를 수 있어요 |
| **실적 최대화 (PMax)** | 검색·유튜브·지메일·디스플레이 등 자동 | 자동이라 편하지만 **어디에 나왔는지 통제가 어려워요**. 검색에서 데이터가 쌓인 뒤 추가 |
| **디맨드젠** | 유튜브·디스커버·지메일 피드 | 2026년부터 디스플레이·동영상 캠페인 일부가 이쪽으로 옮겨지는 중이라고 해요 |
| **쇼핑** | 상품 사진+가격 | 해외 쇼핑몰 |
| **동영상** | 유튜브 | 3-2 |
| **앱** | 앱 설치 | 25장 |

시작 순서:
1. **GA4로 전환 추적** 연결 (구매·문의·가입)
2. **검색 캠페인** 하나, 세부 키워드 10~20개 ("홈페이지 제작" ✕ → "미용실 홈페이지 제작 비용" ○)
3. **제외 키워드** 등록 ("무료", "강의", "채용" 등 안 살 사람)
4. 1~2주 후 **검색어 보고서**에서 실제로 어떤 검색에 나왔는지 보고 정리

### 3-2. 유튜브 광고
- **처음 몇 초 안에 건너뛸 수 있어요.** 그래서 **첫 3초**에 손님의 문제나 결과를 보여 줘야 해요(4절).
- 스마트폰 세로 영상(쇼츠)도 광고로 쓸 수 있어요. 인스타 릴스와 **같은 영상을 재활용**하세요.
- 목적이 "구매"면 전환 추적이 필수예요. 없으면 조회수만 늘어요.

### 3-3. 카카오 광고 (카카오모먼트)
- 카카오톡 채팅 목록 위의 배너(**비즈보드**), 카카오 서비스와 제휴 지면에 나와요.
- 대행사 자료(2023년 기준) 예시: 클릭당 과금 최소 입찰 10원, 1,000회 노출당 과금 최소 1,000원. **실시간 입찰이라 단가는 고정이 아니에요.** 최신 금액은 카카오 비즈니스 도움말에서 확인하세요.
- **카카오톡 채널 친구 모으기**와 함께 쓰면 좋아요(64장 메시지 마케팅).

### 3-4. 쿠팡·스마트스토어 광고
- **쿠팡**: 셀러 관리 화면(윙)의 광고센터에서 해요.
  - 자동 광고(매출 최적화 등): 키워드를 안 넣어도 쿠팡이 알아서 노출해요. 편하지만 **관련 없는 키워드에 돈이 나갈 수 있어** 보고서 확인 필요.
  - 수동 광고: 효율 좋은 키워드만 골라서.
  - 셀러 자료에서 자주 나오는 시작점: 하루 1만 원 정도, **목표 ROAS는 내 손익분기보다 약간 높게.** 목표 ROAS를 **너무 높게 잡으면 입찰가가 낮아져 노출이 거의 안 돼요.**
- **스마트스토어**: 네이버 검색광고의 **쇼핑검색광고**로 상품을 검색 결과에 올려요.
- 공통: **썸네일·가격·리뷰**가 광고 성과를 거의 결정해요. 광고 전에 상품 페이지부터.
- 매주 광고 보고서에서 **돈만 쓰고 안 팔린 키워드**를 빼요.

## 4. 광고 소재(크리에이티브) — 무엇을 보여 줄까

**소재** = 광고에 쓰는 사진·영상·문구. SNS·영상 광고는 **소재가 성과의 대부분**을 결정한다고 업계에서 말해요.

### 좋은 소재의 구조
```
① 훅 (첫 1~3초 / 첫 줄): 손님의 문제나 놀라운 결과 → "아침 5분, 아직도 굶고 출근하세요?"
② 본문: 해결 방법을 보여 주기 → 실제로 먹는 장면, 성분표
③ 증거: 후기, 숫자 → "재구매율 38%"(진짜 숫자만)
④ 행동 유도: 할 일 하나 → "첫 구매 20% 할인 받기"
```

### 소재 아이디어 7가지 (돌려 가며 쓰기)
| 유형 | 예 |
|---|---|
| 문제 → 해결 | "엑셀 정리 3시간 → 3분" |
| 전후 비교 | 사용 전·후 화면 |
| 손님 후기 | 진짜 후기 캡처·영상 (동의받고) |
| 만드는 과정 | 공장·주방·코딩 화면 (57장 빌드 인 퍼블릭) |
| 자주 묻는 질문 답변 | "가격이 왜 이래요?"에 답하는 영상 |
| 비교 | 다른 방법과 비교 (경쟁사 비방은 금지) |
| 창업자 이야기 | 왜 만들었나 |

### 테스트하는 법
1. **한 번에 하나만 바꿔요.** 본문·행동 유도는 그대로 두고 **훅(첫 부분)만 3~5개** 바꿔서 비교.
2. 이긴 훅을 고정하고 → 본문 바꿔 보기 → 행동 유도 바꿔 보기.
3. 비교할 숫자:
   - **클릭률(CTR)**: 보여 준 사람 중 누른 비율
   - **훅 비율**: 영상 첫 3초까지 본 비율 (업계 자료에서 메타 기준 25~35%를 참고선으로 많이 써요)
   - **구매당 비용(CPA)** 과 **ROAS**: 결국 이게 기준
4. 업계 자료에 따르면, 메타 자동 소재 보정 기능(어드밴티지+ 크리에이티브)을 켜 두면 **무엇이 이겼는지 구분하기 어려울 수 있어서** 테스트할 땐 끄는 경우가 많아요(메타 공식 권장은 아님).

### 소재 피로 — 같은 광고를 너무 많이 보면
- 같은 사람이 같은 광고를 여러 번 보면 클릭률이 떨어져요.
- 신호: **빈도(1인당 본 횟수)가 오르고, 클릭률이 처음보다 20~30% 떨어짐.** 빈도 기준은 자료마다 2.5~4회로 달라요.
- 대응: **새 소재 추가**, 2~3주마다 새 훅 준비.

> 💡 Claude에게: "우리 상품 설명과 후기 5개를 줄게. 위 7가지 유형별로 훅 문장 3개씩, 15초 영상 대본 2개를 써 줘. 효능을 과장하거나 없는 숫자는 넣지 마."

## 5. 리타기팅 — 왔다 간 사람에게 다시

**리타기팅** = 내 사이트에 왔지만 **사지 않고 나간 사람**에게 다시 광고를 보여 주는 것이에요.

| 대상 | 보여 줄 것 |
|---|---|
| 상품을 봤지만 장바구니 안 담음 | 그 상품 + 후기 |
| 장바구니에 담고 안 삼 | "아직 장바구니에 있어요" + 배송 정보 |
| 이미 산 사람 | **제외**하거나, 함께 쓰는 상품·재구매 |

- 처음 보는 사람보다 **구매 확률이 높아서** 적은 예산으로도 효과가 나요.
- 너무 자주, 너무 오래 따라다니면 **불쾌감**을 줘요. 기간(예: 7~14일)과 빈도를 제한하세요.
- 방문 기록을 광고에 쓰려면 **개인정보처리방침에 적고**, 필요한 경우 동의를 받아야 해요(10·37장, 해외는 52장 GDPR).

## 6. 측정 — 광고가 진짜 팔았나

### 픽셀과 전환 API
| 도구 | 방식 | 약점 |
|---|---|---|
| **픽셀(태그)** | 손님 **브라우저**가 "구매했어요"를 광고 회사에 알림 | 광고 차단기, 아이폰 추적 제한(iOS 14.5 이후), 쿠키 제한에 막힘 |
| **전환 API (서버 연동)** | 내 **서버**가 광고 회사에 직접 알림 | 설정이 조금 어려움 (쇼핑몰 빌더는 연동 기능 제공이 많음) |

- 메타는 **픽셀과 전환 API를 같이 쓰고, 같은 구매가 두 번 세어지지 않게 "이벤트 ID"로 중복 제거**하라고 권해요.
- 서버에서 보내기 때문에 **39장 결제 웹훅**(결제 확정 알림)과 같은 자리에 붙이면 정확해요.

### 숫자를 그대로 믿지 않기
- 메타·구글·네이버는 **각자 자기 덕분에 팔렸다고** 세요. 플랫폼 숫자를 다 더하면 실제 주문보다 많아지는 일이 흔해요.
- 진짜 기준은 **내 쇼핑몰·통장의 실제 주문과 매출**이에요.
- 간단한 확인법:
  1. 링크마다 **UTM**(38장)을 붙여 GA4에서 채널별로 보기
  2. **"광고를 끈 주"와 켠 주의 전체 매출 비교** (가장 단순한 실험)
  3. 주문서에 "어떻게 알고 오셨어요?" 선택 질문 넣기

## 7. 예산과 운영 루틴

| 단계 | 하루 예산 (예시) | 목표 |
|---|---|---|
| **테스트** (2~4주) | 1~3만 원 | 손익분기 ROAS를 넘는 **소재·키워드 찾기** |
| **확대** | 20~30%씩 천천히 | 이긴 광고에만 돈을 더. 갑자기 몇 배로 올리면 성과가 흔들리기 쉬워요 |
| **유지** | — | 매주 소재 교체, 매달 손익 확인 |

**주간 광고 점검 (30분)**
```
□ 채널별 광고비 · 매출 · ROAS — 손익분기 넘나?
□ 돈만 쓰고 안 팔린 키워드 · 광고 끄기
□ 빈도 오르고 클릭률 떨어진 소재 → 새 소재
□ 검색어 보고서에서 제외 키워드 추가
□ 실제 주문 수와 플랫폼 숫자 비교
```

**하지 말 것**
- 손익분기를 모르고 "ROAS 높아 보인다"로 판단
- 하루 이틀 결과로 끄고 켜기 반복 (데이터가 쌓일 시간 필요)
- 효능 과장·"최저가" 같은 근거 없는 표현 (표시광고법, 29장)
- 경쟁사 상표를 검색 키워드·문구에 함부로 쓰기 (47장)

---

### 이 장 요약
1. 광고 전에 **상세 페이지·전환 추적·손익분기 ROAS**. 내 합격선 = 1 ÷ 마진율.
2. 처음엔 **찾고 있는 사람에게 보이는 광고(검색·쇼핑)**부터. SNS·영상 광고는 **훅 3~5개 테스트**로 소재 실력을 쌓는다.
3. **픽셀 + 전환 API**로 측정하되, 진짜 기준은 **내 실제 주문과 통장**.
