# 인터넷 사업 공부 노트 (입문 → 실전)

사이트를 하나 만들어서 **실제로 돈을 벌며 운영한다**고 생각하고,
"무슨 사업이 있나 → 어떻게 설계하나 → 어떻게 업데이트·백업·관리하나"를 순서대로 공부하는 자료입니다.

**공부 목표**: 혼자 또는 작은 팀으로 인터넷 서비스를 **기획하고, AI(Claude)와 직접 만들고, 출시·운영·마케팅·수익화까지** 해내는 **1인 창업가 겸 개발자**.

**추천 순서**: 1~15장(기본) → 57장(실제 수익 사례로 감 잡기) → 42~47장(창업가의 기본기) → 코딩 노트 → 48~50장·58~60장(만들기·설계) → **55장 실습 프로젝트로 직접 한 바퀴** → 나머지 장은 필요할 때 찾아보기.

> 모르는 단어는 [3장 용어 사전](docs/03-glossary.md)에서 바로 찾을 수 있어요.
> 한눈에 보고 싶으면 [요약 슬라이드](slides/internet-business-101.pptx)를 먼저 넘겨 보세요.
