## 이 자료를 읽을 때 주의할 점

- 법·세금 내용(10·16·19·20·23~41장)은 **2026년 10월 기준으로 조사한 것**이고, 법은 자주 바뀝니다. 실제로 사업을 시작할 때는 꼭 공식 사이트(국세청 홈택스, 정부24, 개인정보보호위원회, 국가법령정보센터)에서 다시 확인하세요.
- 조사할 때 본 **출처**와, 조사 중 **직접 확인하지 못한 부분**은 [참고 자료 모음](docs/sources.md)에 장별로 정리해 두었어요.
- 기술 도구 이름(서비스 이름)은 "예시"입니다. 같은 역할을 하는 다른 서비스도 많아요.
