# 01. 기획서 (PRD) — 만들면서 배우는 1인 창업 가이드

> 가제: **"한 바퀴"** — 아이디어에서 첫 손님까지 한 바퀴를 같이 돌아 주는 코치
> 이름은 나중에 상표 검색 후 확정해요([47장](../../docs/47-trademark-copyright-license.md)).

---

## 1. 왜 만드나 (문제)

- 1인 창업 지식은 너무 많아요. 이 저장소만 해도 74장 + 코딩 13장, PDF로 384쪽이에요. **다 외우는 건 불가능**해요.
- 실제로 필요한 건 "지금 내 단계에서 **무엇을 해야 하고**, **무엇을 봐야 하고**, **AI에게 뭐라고 시켜야 하는지**"예요.
- 초보자는 **순서**를 몰라서 만들기부터 시작하고(검증 생략), 출시 직전에 법·보안을 놓쳐요(57장 실패 사례).

## 2. 누구를 위한 것인가

| 순서 | 사용자 | 설명 |
|---|---|---|
| 1단계 | **나** | 이 가이드로 이 가이드를 만들며 직접 써 보기 (도그푸딩) |
| 2단계 | **초보 1인 창업 지망생** | 코딩·사업 경험이 거의 없고, AI로 혼자 만들어 보고 싶은 사람 |

**페르소나**: "29세 회사원. 퇴근 후 주 5~8시간. 클로드·챗GPT는 써 봤지만 사업은 처음. 유튜브 강의는 봤는데 막상 뭘부터 할지 모름. 실패해서 돈 날리는 게 무서움."

## 3. 대안 (손님이 지금 쓰는 것 — 62장 포지셔닝)

| 대안 | 부족한 점 |
|---|---|
| 챗GPT·클로드에 그냥 물어보기 | 순서·진행 상황을 기억 못 함, 매번 처음부터 설명, 한국 법·세금 빠뜨림 |
| 온라인 강의 | 듣고 끝, 내 프로젝트에 적용은 혼자 |
| 책·블로그 | 흩어져 있고 오래된 정보 섞임 |
| 노션 템플릿 | 체크리스트만 있고 "왜·어떻게"와 AI 도움이 없음 |

## 4. 포지셔닝 한 문장 (62장)

> **AI로 혼자 첫 서비스를 만들고 싶은 초보자**를 위한 **단계별 창업 코치**예요.
> 그냥 AI에게 묻는 것과 달리, **내 진행 단계를 기억하고 한국 법·세금·출시 체크리스트까지 순서대로 챙겨 줘서** 빠뜨리지 않고 첫 손님까지 갈 수 있어요.

## 5. 핵심 기능 (MVP — MoSCoW, 4장)

### Must (나만 쓰는 첫 버전에 꼭)
| # | 기능 | 설명 |
|---|---|---|
| M1 | **프로젝트 만들기** | 아이디어·손님·주당 가능 시간 입력 |
| M2 | **진행표** | 0~7단계, 약 51개 스텝 ([02-roadmap-steps](02-roadmap-steps.md)). 지금 단계 표시 |
| M3 | **스텝 화면** | 목표 · 할 일 체크 · 완료 기준 · 관련 장 바로 읽기 · **복사용 Claude 요청문** · 산출물 메모 칸 |
| M4 | **장 읽기** | 이 저장소의 docs를 앱 안에서 읽기 |
| M5 | **AI 코치** | 현재 스텝과 내 프로젝트 정보, 관련 장 내용을 알고 답함. "다음에 뭐 해?"에 답함 |
| M6 | **로그인** | 내 진행 상황 저장 (65장) |

### Should (판매 전에)
| # | 기능 |
|---|---|
| S1 | 주간 계획: "이번 주 5시간이면 이것만" (54장) |
| S2 | 산출물 모아 보기 (페르소나, 가격 계산, 기획서) → PDF 내보내기 |
| S3 | AI 사용 한도·비용 표시 (67장) |
| S4 | 카카오 로그인 |
| S5 | 소개 페이지 + 사전 신청 (42장 검증용) |

### Could (나중에)
- 결제·구독 (39장), 여러 프로젝트, 커뮤니티, 진행 알림 메일 (64장), 모바일 앱

### Won't (이번엔 안 함)
- 코드를 대신 짜 주는 기능 (Claude Code가 이미 잘함 — 우리는 **"무엇을 시킬지"**를 알려 줌)
- 법률·세무 확정 답변 (항상 "공식 확인 필요" 표시)

## 6. 성공 기준 (11·42장)

| 단계 | 기준 |
|---|---|
| 나만 쓰는 버전 | 내가 이 앱으로 **이 앱의 0~4단계를 실제로 완료** (출시 직전까지) |
| 판매 검증 | 소개 페이지 방문자 중 **사전 신청 10% 이상**, 초보자 5명 인터뷰에서 "써 보고 싶다" 3명 이상 |
| 유료 전환 검증 | 베타 사용자 중 "못 쓰게 되면 매우 실망" **40% 이상** (42장 PMF 테스트) |

## 7. 위험과 대응

| 위험 | 대응 |
|---|---|
| 법·세금 정보가 틀리거나 낡음 | 모든 법·세금 스텝에 **확인일 + 공식 확인 링크**, "확인하지 못한 것" 표시 유지, 분기별 재확인 (74장) |
| AI 코치가 틀린 말 | 답에 관련 장 근거 표시, 법·돈 관련은 "공식 확인" 안내 고정 (67장) |
| AI 비용 | 사용 한도, 작은 모델 우선, 관련 장만 넣기 (67장) |
| 혼자 만들다 지침 | 스텝을 작게(2시간 이내), 주간 계획 (54장) |
| 대안(그냥 AI)이 너무 강함 | "진행 기억 + 한국 실무 체크리스트 + 요청문 템플릿"에 집중, 기능 욕심 금지 |

## 8. 일정 (나만 쓰는 버전)

| 주 | 할 일 | 끝나면 |
|---|---|---|
| 0주 | 이 기획서·설계 확정 (언어: Rust), 새 저장소 만들기 | 승인된 문서 |
| 1주 | 진행표 + 스텝 화면 + 장 읽기 (로그인 없이 내 PC에서) + 테스트·CI·상태 확인 주소 | 스텝을 따라갈 수 있음 |
| 2주 | 로그인 + 진행 저장 (수파베이스) + 도커로 배포 + 오류 추적 | 휴대폰에서도 내 진행 확인 |
| 3주 | AI 코치 | "다음에 뭐 해?" 질문 가능 |
| 4주~ | 이 앱으로 이 앱의 검증·출시 단계 진행 + 소개 페이지로 판매 검증 | 판매 여부 결정 |
