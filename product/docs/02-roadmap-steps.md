# 02. 진행표 — 단계와 스텝 (앱의 핵심 콘텐츠)

이 표가 앱의 **뼈대**예요. 74장짜리 교재를 "순서대로 하는 일"로 다시 묶은 거예요. 앱에서는 이 내용이 데이터 파일(`roadmap.json` 등)로 들어가요.

각 스텝은 이렇게 생겼어요.
```
제목 · 목표(한 줄) · 할 일 체크리스트 · 완료 기준(산출물) · 관련 장 · 복사용 Claude 요청문 · 예상 시간
```
- 스텝 하나는 **2시간 안팎**으로 끝나게 쪼개요 (54장, 퇴근 후 1~2회).
- **[선택]** 스텝은 프로젝트 종류에 따라 건너뛰어요 (결제 없는 사이트, AI 기능 없는 서비스 등).

## 스텝 예시 하나 (앱에 들어갈 실제 모양)

```yaml
id: "1-2"
title: "손님 후보 5명 인터뷰"
goal: "내가 생각한 문제가 진짜 있는지, 사람들이 지금 어떻게 해결하는지 듣기"
estimate: "2시간 (인터뷰 1명당 20분)"
checklist:
  - 페르소나에 맞는 사람 5명 찾기 (지인의 지인, 관련 커뮤니티)
  - 질문 5개 준비 — "쓰실래요?" 대신 "지난번엔 어떻게 하셨어요?"
  - 인터뷰하고 바로 메모 (그 사람이 쓴 말 그대로)
  - 공통으로 나온 불편 3가지 정리
done_when: "인터뷰 메모 5개 + 공통 불편 3가지"
chapters: ["42-idea-validation#2-손님-인터뷰"]
claude_prompt: |
  내 페르소나는 [붙여 넣기]야. 이 사람에게 할 인터뷰 질문 5개를 만들어 줘.
  미래 의견("쓰실래요?")이 아니라 과거 행동("지난번엔 어떻게 했나요?")을 묻게 해 줘.
artifact_fields: ["interview_notes", "top_3_pains"]
warning: null
```
